## 二、逐条复核结果

### C1 —— 部分成立，但主 Agent 的因果解释错了

**复核确认：**
- "塞德里克，不要怪我使手段，我这是在救你"——**逐字存在**
- 手段②"远程启动魔法，遇怪几率大大增加"——存在
- 手段③混淆咒——原文是"**说不得就得**用混淆咒伺候了"，属**备而未定**，不是"备好"
- 手段①"护身符遇险撑起铁甲咒"——存在

**复核指出的三处问题：**

1. **护身符不是给塞德里克的专属保护，是通用装置，而且是门钥匙。**
   - 328：主角"用手摸了一下脖子"，**塞德里克和哈利都点头**——两人各有一枚
   - 329 明说："赛恩斯送给哈利的那个护身符**也是一个门钥匙**"
   - 330：主角当场"接过来消除了它门钥匙的用途"
   - **哈利戴着同一装置，照样被抓走。** 所以"护身符保护了塞德里克"这个读法，与"哈利戴着它仍被传送"直接冲突

2. **同章第2页给出了主角的真实优先级，与"救人"不同：**
   > "若是现在把哈利救走，伏地魔要肯定要裂开，但是**这不符合赛某人的谋划**……就是为了让他成功复活"

   即：把塞德里克挡在奖杯外，同时服务于"**墓地里只有哈利一个勇士**"这一可控性目标

3. "**避免其原著中的死亡**"是主 Agent 用自己的原著知识补的，**328 全章没有一句提到"死亡"或"原著结局"**

**复核给出的更合理解释：** "控制变量"——塞德里克是必须被排除的干扰项，"我这是在救你"是对手段的事后合理化。

**复核定级：B**（全部证据集中在 328 一个场景；同一次战役拆章不算独立证据）

**主 Agent 处理：接受。** 结论改为：主角自陈"救你"，但同章表明更高优先级是"让伏地魔成功复活、把墓地控制在只有哈利一人"。护身符为通用装置且是门钥匙，哈利使用同一装置仍被传送，故"保护"读法不成立。等级 B。

### C2 —— 核心引文成立，"整体判断"不成立

**复核确认：**
- "现场的情况与原轨别无二致"——**逐字存在**（329 第1页）
- 哈利被主角救走——属实（330）
- 石化咒擒获穆迪——属实（330："直接一个石化咒放倒了他……又是几个束缚魔法"）

**复核指出的问题：**

1. **"假"字在两章正文中从未出现**。全篇只称"穆迪""穆迪教授"，没有小巴蒂·克劳奇、没有复方汤剂、没有身份揭穿。可确证的只是"主角在揭穿前抢先动手"。**"假穆迪"是主 Agent 的外部信息。**
2. 更棘手的歧义：主角对穆迪说"**我早就想这么干了**"——字面上可读成"对真穆迪动手"，与"识破假货"相反。
3. **"结局未变"只在取血环节成立。** 那句话的上下文是"虫尾巴仍然只取了哈利一点血投入坩埚"，是**局部限定语**，被主 Agent 升格成了全局判断。
4. **本章实际改动很大**：三名食死徒被石化、哈利束缚被割断、邓布利多被提前叫来、穆迪赛后即被缴械。第四部原著结局（塞德里克死、福吉否认）已被改掉。
5. 反例：329 主角承认有杀意（"若非想着以后还得与老邓头共事，刚才那三个人肯定不只是被石化"）——是**主动克制**，不是"没能力改"。

**复核定级：B**（329+330 是同一场战役的连续叙事，不互证）

**主 Agent 处理：接受。** 撤回"改代价不改结局"这一整体判断。改为分项陈述：仪式环节复刻原著；其余代价显著增加（食死徒被石化、穆迪被无程序处置）。删去"假"或明确标注为外部信息。

### C3 —— **不成立，主 Agent 的判断被自己的引文推翻**

**复核结论：三个样本只有"1 个半"成立。**

| 章 | 复核发现 |
|---|---|
| 25 | 课堂那段确是三连问。但**本章主戏（宿舍夜谈）不是提问链**，是示弱+愧疚诱导，且叙述者自评"**谈判技巧之一，偷换概念**"；章名即"安慰（**忽悠**）室友" |
| 292 | 先抛**既有口号**"我们是一个整体"，最终仍由主角给结论："方法很简单，只要跳出三强的圈子，变成四强争霸赛，就行了！"且艾丽娅直接说"**你就直说了吧**"——是众人催他给结论 |
| 297 | **基本相反**：全章是主角直接下判断、直接下指令（"你的这个SPEW是**注定要失败的**""你的短期目标**应该是**……"），只有两句形式提问，之后全是单向讲授 |

**复核定级：C**

**复核给出的更合理解释：** "**分层说服**"——对同辈用设问（低成本、给面子），对晚辈/被说服对象直接给结论与方案（效率优先），对被操纵者用示弱与偷换概念。这比"一律提问链"更贴合三个样本的差异。

**主 Agent 处理：接受，这是本阶段最重要的一次自我纠错。** "一律提问链"的说法撤回。观察索引 O-01 需重写（见第五节）。

### C4 —— **核心机制不成立，"改不回来"是错的**

**复核发现：两个样本里"改不回来"都不成立，两次都是当场改回。**

- 301 塞德里克："穆迪教授，海格教授，奥特姆助教你们好"——是**对三人统一改口**的礼节性招呼；主角纠正"**你以前都叫我赛恩斯的**"，塞德里克立刻"**对不起，赛恩斯**"
- 495 哈利："奥特姆教授！"→ 主角"什么时候这么生分了？"→ 哈利"**赛……赛恩斯**，我只是以为还在上课"

**复核还指出一个反向证据（27章）：** 本书自陈的称呼逻辑是"**亲切则称名**"——

> "按照称呼习惯，宾斯教授，似乎应该被称为卡斯伯特教授才对，但是……人们似乎都称他为宾斯教授。从称呼上，赛恩斯推测，宾斯教授生前一定特别受人欢迎，并且为人特别的亲切。"

这个方向与主 Agent 的"身份差 → 用头衔"并不矛盾，但说明**本书把"称名"解释为亲切，而不是"身份差消失"**。

**复核定级：C**

**复核给出的替代读法：** "场合切换"——两次改口都发生在公开/半公开场合，两人都自陈是"以为还在上课"。真正可写的现象是：**职衔升格使旧称呼在公开场合出现语用摩擦，需要一次解释**。

**主 Agent 处理：接受。** 删掉"改不回来"，机制降级为弱版本。

### C5 —— 情节属实但表述失真；**断点定位应前移至第330章**

**复核确认：**
- 关门、定身、缴械、威胁烧手——全部存在
- **但 362 第2页主角实际动了手**：挑出顺手魔杖"麻花"，"默念'钻心剜骨！'"，乌姆里奇"剧烈颤抖……缩成一团，同时身下传来一股恶臭"
- 主 Agent 写成"威胁烧手"，是把**已完成的酷刑降格成了口头恐吓**

**复核指出的要害：**

1. **27章的自我约束带条件**——原文是"**在自己确实有一定水平之前**，还是老老实实的学习教材上的标准咒语"。主 Agent 把一条**临时性、自我设限**的规矩当成了恒定行为逻辑，再据此判"矛盾"
2. **更早、更硬的越界在 330 章**：石化穆迪后"变出一个夹子粗鲁地伸进眼眶把那只魔眼**抠**了出来"，洗清后**挖掉自己一只眼睛、把魔眼装进眼眶**，并自陈"我早就想这么干了"。无程序、无第三方、对活体不可逆处置——**比 362 更彻底**
3. **更早的前兆在 328 章**：遥控迷宫、给勇士配自制非法门钥匙、明知奖杯是门钥匙仍放任哈利被传送、在墓地按兵不动看着取血
4. **但 329 有反向证据**：他仍在意"不给魔法部留把柄"、仍传音请示邓布利多——**程序意识没断，断的是伦理阈值**

**复核定级：B**

**复核给出的替代读法：** "**阈值单调下移**"——27（限用标准咒语，附条件）→ 328（隐蔽操控、放任）→ 330（无程序处置+自我身体改造）→ 362（私刑+钻心咒）→ 494/495（屠杀）。这是一条**单调递增的滑坡，中间没有拐点**。把断点钉在 362，等于忽略了前面两级更硬的台阶。

**主 Agent 处理：接受。** 撤回"断裂起于362"，改为"阈值单调下移，可定位的最早节点是328，最硬的节点是330"。

## 三、复核 Agent 指出的、主 Agent 漏掉的三条

1. **护身符是通用装置且是门钥匙，哈利带同一装置仍被抓走。** 主 Agent 把它读成"给塞德里克的保护"，漏掉了装置的双重用途与**失败案例**。
2. **330章的"抠眼+自植"是全书最早也最硬的越界**，比 362 更早更彻底。任何关于"断裂节点"的排序都必须先处理这一处。
3. **495章已给出断裂的"终点"**：朋友说"我们只是还没想到要如何与一个'**神**'相处"；主角对伏地魔"我唯一想从你们这里得到的，就是你们的**命**"；四周"成百上千的好似杂草一样随地倒伏的焦黑死尸"；对塞德里克"我与他们不熟，来不来的我并不在意"。主 Agent 只取了"奥特姆教授"四个字，**舍近求远**。

## 四、复核总体评价

| 项 | 结果 |
|---|---|
| 完全成立的结论 | **0 条** |
| 部分成立（需改措辞/降级） | 3 条（C1、C2、C5） |
| 核心机制不成立 | 2 条（C3、C4） |
| 主 Agent 表述失真处 | 2 处（"备好混淆咒"应为"备而未定"；"威胁烧手"应为"实际施展钻心剜骨"） |
| 主 Agent 用外部知识补齐处 | 3 处（"避免原著死亡""假穆迪""改代价不改结局"框架） |

**这次复核的价值：** 主 Agent 的三条结论（C3、C4、C5）都有"把 1–2 个样本当成规律"的问题，而且是同一类错误——**先有观察，再去找支持它的章节，找到了就写成规律**。复核 Agent 因为不看笔记，反而更容易发现"第二次改口明明改回来了"这种被忽略的反向细节。

**保留的分歧：**
- 关于 C1，主 Agent 仍认为"救人"的成分存在（主角确实提高了塞德里克的存活率），只是**不能把它写成主因**。复核 Agent 倾向"控制变量"为唯一动机。两种读法并存，不强行统一。
- 关于 C5，主 Agent 认为 330 的抠眼是**对敌人/对自身**的处置，362 是对**同事**的处置，性质不同，不宜简单按时间排序。复核 Agent 认为伦理阈值是连续的。此分歧保留。
