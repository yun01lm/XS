## 二、逐条复核结果

### C1 —— 部分成立，需缩小范围

**复核判定**：部分成立需缩小范围。

**复核 Agent 找到的反例**：

| 章 | 情节 | 为什么构成反例 |
|---|---|---|
| **469** | 邓布利多昏迷不醒后，主角的目标升级："既然你们不愿意既定的规则运行，那就按照赛某人的规则来运行吧。这个时代，该赛某人说了算了！" | 主角的**长期目标清单增加了"秩序主导权"**，而这是被一个配角的处境催出来的 |
| **470** | 配角巴布吉的固执逼主角改变行程去蹲守救人 | 配角改变了主角的**行动优先级** |
| **417** | 主角推演出邓布利多会去岩洞喝药，盘算后决定"算了，既然老邓头没有死劫，且不去管它吧" | 主角的行动被配角的命运牵着走，只是选择了"不救" |

**复核 Agent 还指出一处证据选择错误**：

> "把 184 的日记本小伏当'配角拒绝'的代表证据不妥——原文是'并没有从他那里套出厉火咒''也就对它失去了兴趣'，是主角自己收手，而且那是个魂器敌人，不是配角。这条证据撑不起'配角有方向盘'。"

**复核 Agent 给出的替代模型**：

> "不是'有手脚没方向盘'，而是**方向盘焊死在主角手里、油门由配角踩**。配角能决定他先去哪儿、先救谁，不能决定他去哪。"

**复核 Agent 提供的、主 Agent 从未读过的强支持证据（227 章）**：

> 邓布利多连续两次拒绝主角留校（"那可不一定""我可不是个会心软的人"），主角直接掀桌："若是我向魔法部捐献三万加隆……若是不行的话，五万也是可以的""学校不是有董事会吗，实在不行我就只能破财收购学校了"。邓布利多只能回一个"滚！"。

这条证据的价值在于：它同时说明**配角的否决权可以被主角用资源强行碾过**——这比"配角会拒绝"更能说明权力结构。

**主 Agent 处理：接受，但保留一处不同意见。**

接受的部分：
1. 撤回"没有一个人能改变主角的长期目标"，改为"**能改变阶段目标与行动排序，不能改变底盘（容器/长生/自主）**"。
2. 撤回 184 章日记本小伏作为"配角拒绝"的代表证据，降为"**对手阻断信息**"一类，且注明"主角主动收手，不是被迫放弃"。
3. 采纳"油门由配角踩、方向盘焊死"这个提法，比我的更准确。
4. 补入 227 章（逼宫留校）作为"权力结构"证据。

保留的分歧：**469 章究竟算"配角改变目标"还是"事件改变目标"**。主 Agent 认为邓布利多昏迷是一个**事件状态**（且这个状态部分源于主角自己选择不干预，417 章），把它计为"配角推动"会高估人物作用。但同类现象（配角处境 → 主角调整优先级）确实存在，故接受"阶段目标可被推动"的表述。

### C2 —— "不靠关系驱动剧情"成立，"关系平移"不成立

**复核判定**：部分成立需缩小范围——"不靠关系驱动剧情"成立，"关系平移"不成立。

**复核 Agent 找到的反例**：

| 章 | 情节 | 为什么构成反例 |
|---|---|---|
| **195** | 赫敏"粉转黑"：被主角当面怼翻后"头也不回地跑掉了，好久没有出现在他面前"，再出现时"表情像是做了什么重大决定一样"回来追问 | **断裂—修复**的完整弧，不是平移 |
| **226** | 邓布利多当面说"我们所有人都被你骗了""你摸清了所有人的性格""才让我觉得更加不安" | 师生关系质变为"亲密＋戒备"，且 227 紧接以金钱胁迫收场 |
| **496** | 战后赫敏"有点儿不太敢看赛恩斯的眼睛，似乎他是一个张口噬人的荒莽凶兽一般"；麦格"对自己的做法很不满，不愿来见他" | **整条关系网在战后统一降级为畏惧** |

**复核 Agent 的替代模型**：

> "关系不是平移，是**结算制**。主角按功能维护关系（情报、掩护、退路、背书），到期结算；结算那一刻关系发生不可逆的固化或降级。所以看起来'不推动剧情'，实际是'只在结算点推动一次'。"

**复核 Agent 还修正了我的一处分类**："'两组变好（室友、邓布利多）'里，邓布利多一组应是'**变近且变警惕**'，不是单纯变好。"

**主 Agent 处理：全部接受。**

这是四条里我错得最"结构性"的一条。我用"平转"这个词，掩盖了三个关键节点上的关系质变，而且这三个节点分别在二、五、七年级——**恰好是全书的三次关系结算**。"结算制"这个说法比我原来的"平移"准确得多，且能解释为什么读者感觉关系"不动"：因为它确实大部分时间不动，只在几个点上一动到底。

### C3 —— 不成立，需重新建模（本阶段最重要的一次推翻）

**复核判定**：不成立需撤回，或需重新建模。

**复核 Agent 的反例（全部是主 Agent 没读的章节）**：

**复核 Agent 的替代模型**：

> "真实的轴不是朋友／敌人，是'**有没有用＋妨不妨碍目标**'。对有用者走程序（273 与家养小精灵协商、204 阻止孔蒂自罚），对无用或妨碍者走效率。**伦理是成本函数的输出，不是对象的属性。**"

**复核 Agent 对 374 章的定性（最刺人的一句）**：

> "374 明写'是否接受救治是海格的自由'这类句子，只能证明他在**自己不需要付出代价时**讲程序。一旦涉及核心利益（哈利的魂器身份、秘密基地坐标），这套程序立刻作废。把'分层'说成稳定的伦理结构，是把**礼貌**当成了**原则**。"

**主 Agent 处理：接受主体判断，保留一处分歧。**

接受：
1. 撤回"**分层伦理**（对友守界/对敌无界）"这个稳定结构。
2. 采纳"**有用性＋妨碍度**"作为主轴，伦理是成本函数的输出。
3. 补入 498、468、460、415、449、472 六章作为反例。
4. 承认 374 章的"自由"表述**不能**当作稳定原则的证据——它只在低成本时成立。

保留的分歧：**498 章"强行告知哈利是魂器"是否等于"对朋友无情"**。主 Agent 认为这一行为仍可读作"为他好"的极端形式（让哈利知道自己是什么，以便他做选择），属于**善意与强制同源**，而不是纯粹的效率计算。两种读法并存，不强行统一。这一点会影响后续方法卡怎么写，故必须保留。

**这是本阶段最重要的一次自我推翻**：我在 374 章读到一个漂亮的句子，就把它当成了模型；复核 Agent 用 498 章证明那只是低成本时的礼貌。**这与我第三阶段犯的错是同一个：拿一句好话当规律。**

### C4 —— "总规则"不成立，改为"单向套利"

**复核判定**：部分成立需缩小范围，"总规则"不成立。

**复核 Agent 找到的反例**：

| 章 | 情节 | 打穿了什么 |
|---|---|---|
| **463／464** | 邓布利多**没死**（原著里死了），伏地魔被切掉一只手、丢了魔杖 | "原轨回归"不成立，偏差**不可逆** |
| **472** | 马尔福庄园被厉火烧毁、近二十人死亡 | 同上，且规模巨大 |
| **184（同章内）** | 叙述者先断言"根本就没什么'剧情修正之力'"，几页后又惊问"怎么地？'剧情修正力'这么牛逼的吗？" | **作者自己没把这句话当法则** |

**复核 Agent 的替代模型**：

> "不是双向因果，是**单向套利**。原著线提供时间表和信息差，主角据此下注；他不动的地方看起来'照原轨迹'，他动过的地方（岩洞、马尔福庄园、邓布利多的命）就永久分叉。"

**复核 Agent 提供的支持证据（209、417 章）**：

- 209：主角**刻意维护**原著节点——"之所以没在前些年把老鼠揭破……就是想着要等小天狼星越狱，好让摄魂怪跟出来"
- 417：明知邓布利多会去岩洞喝药，因为"实在说不清赛某人是怎么知道山洞的事情的"而放弃干预

**这两条合起来给出一个更冷的解释**：原著之所以"照原轨"，**不是宇宙有修正力，而是主角捂着信息不动手**。

**主 Agent 处理：接受。**

1. 撤回"总规则"的提法，改为"**作者在 184 章提出过这条规则，但全书没有贯彻**"。
2. 采纳"单向套利"作为主模型。
3. 补入 463/464/472 三章作为"永久分叉"的证据。
4. 保留"原著线→原创线确有反向影响"的部分（209、417、469），但把它的性质从"因果"降为"**套利机会**"。
