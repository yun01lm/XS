## 四、新增研究发现（按重要性排序）

### 4.1 同人因果的真实机制是"单向套利"，不是"历史惯性"（A 级）

184 章叙述者写过"没有外力干涉，后续的事情仍如原轨迹一般发展"，我一度当总规则。复核用 463/464（邓布利多没死、伏地魔断手）、472（马尔福庄园被烧、近二十人死亡）证伪。

**真正的机制**（209、417 章）：
- 209：**刻意维护**原著节点——"想着要等小天狼星越狱，好让摄魂怪跟出来"
- 417：明知邓布利多会去岩洞喝药，仍"且不去管它"，理由是"说不清怎么知道山洞的事"

**结论**：原著"照原轨"不是宇宙有修正力，是**主角捂着信息不动手**。历史惯性是他的策略，不是世界的规律。

### 4.2 伦理不是"分层"，是成本函数（B 级，本阶段最大修正）

我据 374 章"是否接受救治是海格的自由"推出"对友守界、对敌无界"。复核用六章推翻：

| 章 | 事实 |
|---|---|
| 498 | 赫敏哭求"我们走吧"，主角仍强行公布"哈利是魂器" |
| 468 | 把亚当的旅行当情报渠道（"有门！"） |
| 460 | 对朋友信息管控，顺手拆壁炉 |
| 415 | 对黑巫师做摄魂怪之吻活体实验，配护理床、鼻饲、按摩，"暂定2年" |
| 449 | "除了这个家伙以外，全部杀掉"；"给你个痛快，也算一点儿心意" |
| 472 | 厉火焚庄园，烧死近二十人，纳西莎骂"你就是一个疯子" |

**修正**：主轴是"**有用性＋妨碍度**"。伦理是成本函数的输出，不是对象的属性。374 那句"自由"，只在**不花钱、不碍事**时成立。

### 4.3 配角能改阶段目标，改不了底盘（B 级）

- **469**：邓布利多昏迷 → 主角宣布"这个时代，该赛某人说了算了"（长期目标**加了一项**）
- **470**：巴布吉的固执逼他改行程救人
- **417**：因邓布利多的"死劫"重新盘算

**但三项底盘（容器/长生/自主）未被触动**。复核 Agent 的提法更准：**方向盘焊死，油门由配角踩**。

### 4.4 配角的否决权取决于主角有多想要（B 级）

| 场景 | 配角拒绝 | 主角处理 | 结果 |
|---|---|---|---|
| 374 海格 | 拒说伤因 | 不追问 | 配角赢 |
| 186 洛哈特 | 两次推脱 | 换话术 | 各让一步 |
| **227 邓布利多** | 两次拒绝 | **砸五万加隆 + 威胁收购董事会** | **主角赢** |

### 4.5 关系不是"平移"，是"结算制"（B 级）

195（赫敏粉转黑→修复）、226（邓布利多"我们所有人都被你骗了"）、496（战后全体降级为畏惧）。**大部分时间不动，只在二、五、七年级三个结算点上一动到底。**

### 4.6 研究型主角的可读性来自"错误的可见性"（A 级，4 场景）

181、211、272、299 四章的解题流程一致：**卡住 → 停止蛮干 → 重列条件 → 找出错误前提 → 反转假设 → 换问题 → 提出两种可能 → 选一种**。

299 章最完整：卡了一个多月，最后发现"守护神是特殊的、被纯化过的"，而不是"记忆需要纯化"。**读者能看到他走错、承认走错、然后改**——这是让设定说明变成剧情的关键。

### 4.7 关系戏常由配角的情绪发起（B 级）

167 章：本和亚当先焦虑（"我们还以为你会换宿舍"），主角回应。25 章：室友先有压力，主角才带苹果派来谈。**不是主角经营关系，是配角先在意的。**

## 八、本阶段的一句话

**我这一阶段最大的收获，是发现自己两次犯同一个错：读到一句漂亮的话，就把它当成规律。**

第三阶段是"现场的情况与原轨别无二致"，第四阶段是"是否接受救治是海格的自由"。两次都是同一类错误——**用一句台词替代了对整本书的检索**。

这也是为什么复核必须由不看笔记的人来做：他读 498 章时，不知道我正在用 374 章建模型。
