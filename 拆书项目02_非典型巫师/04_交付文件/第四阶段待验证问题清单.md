## 一、A 类：可直接推翻现有模型的（优先补读）

### V-01｜配角能否改变主角的长期目标
- **现有判断**：能改阶段目标（469、470），不能改三项底盘
- **矛盾点**：469 章主角新增了"秩序主导权"，这本身就是在底盘上加项
- **需要读**：400–470 段选 8–10 章
- **判断标准**：如果找到"主角为了某个人放弃长生/放弃容器"的段落，现有模型作废

### V-02｜498 章"强行告知哈利是魂器"该怎么定性
- **两种读法**：① 善意与强制同源（主 Agent）② 对朋友也不守边界（复核 Agent）
- **需要读**：496–498 全章（主 Agent 只由复核 Agent 转述，自己未读）
- **判断标准**：主角事后有没有为此付出关系代价？有没有自我怀疑？有 → 读法①；没有 → 读法②

### V-03｜374 章的"自由"是原则还是礼貌
- **现有判断**：只在低成本时成立（已降级）
- **需要读**：415、449、460、468、472 全章
- **判断标准**：找一个"主角付出重大代价仍然给对方选择权"的场景，有 → 原则；无 → 礼貌

### V-04｜"有用性＋妨碍度"是不是真正的轴
- **现有判断**：伦理是成本函数的输出
- **反例风险**：如果存在"对无用之人也给予照顾"的章节（如对造物、对家养小精灵），轴要改
- **需要读**：204、273 全章；孔蒂/金铃相关章节
- **判断标准**：照顾一个对自己完全无用的人，且要付代价

## 四、D 类：方法论层面的待决问题

- **现状**：本项目 24 条观察里，A 级 4 条，其余 B/C

### V-17｜跨源文本差异要不要核
- **现状**：8novel（繁体）、58小说网（简体）、56书库 三个源，未互校
- **风险**：同一章的引文可能不同
- **建议**：至少在写方法卡引用原句时，抽 10 句做三源比对

## 八、V4.1 新增发现的问题

### V-18｜"配角实际阻断"（R2）一手样本为零

- **现象**：184、374、186 三个"没拿到"的案例，主角全部**还有别的手段却自行收手**
- **风险**：如果全书都没有真正的 R2，那"配角有独立性"这一命题的**强度要下调**——辅角只是"能说不"，不是"能挡住"
- **需要读**：400–489 段选 8 章，专门找"主角反复尝试仍失败"的场景
- **判断标准**：找到 1 处主角**用尽手段仍失败**的段落 → R2 成立；找不到 → 只能写"辅角可拒绝，不可阻断"
- **优先级**：P0

### V-19｜272 与 299 属同一条研究线，O-23 的"4 个独立场景"不成立

- **现象**：272（方向验证）与 299（方法成型）同属**冥想盆研究**，按"同一事件拆多章只算 1 场景"规则不能互证
- **处置**：O-23 已由 A 降为 B，独立证据改记"3 条研究线"（蛇怪/摄魂怪/冥想盆）
- **需要读**：另找 1–2 条**不同主题**的研究线章节（如空间柜、时间转换器实验），补足独立场景数
- **判断标准**：凑到 3 条以上**互不相干**的研究线且都呈现"卡住→推翻前提"→ 可恢复 A
- **优先级**：P1

### V-20｜关键结论过度依赖【转引】证据

- **现象**：涉及"长期目标"与"伦理模型"的核心章节——227、417、415、449、460、468、469、470、472、498——**主 Agent 全部未一手读过**，仅有复核 Agent 的引述
- **风险**：复核 Agent 的引述若有偏差，本项目的两个核心结论同时失效
- **需要读**：至少一手补读 **498、469、227** 三章（各 2 页）
- **判断标准**：一手读完后，引文与复核引述一致 → 风险解除；不一致 → 以一手为准重写
- **优先级**：**P0（最高）**

### V-21｜六维框架中"因果独立性"与"关系反作用"边界过薄

- **现象**：前者指"世界变了"，后者指"主角变了"，但同一事件常同时满足两者（如 384 蒙太失踪既改变世界也影响主角判断）
- **风险**：容易把一件事在两维各记一次，人为抬高人物"独立性"
- **处置**：专题C 已加判定要求——"必须写明改变的是世界还是主角"
- **是否需要补读**：不需要，属框架内部问题；需在写方法卡前定稿
- **优先级**：P1

### V-22｜58小说网标"共510章"与官方 517 章差 7 章，未核

- **现象**：该站目录页标注 510 章，官方 517 章
