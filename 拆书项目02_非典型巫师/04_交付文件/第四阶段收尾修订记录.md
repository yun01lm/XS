1. **367 行未更新**：证据笔记里 `ggdaed`（第1页）与 `ggdaed_2`（第2页）两条记录俱在，说明两页全读；但档案 4.2 表内仍写"仅第1页"，且 4.1 的"部分"清单里**没有** 367——**表格与清单互相矛盾**。按清单算得 65/10，按表格算得 64/11。
2. **272 行无正文**：表内记"部分（仅第1页）"，但证据笔记只有一条"读取失败"。**这一章被计入"已读"，却没有任何内容留档**，而 O-23 又把它列作 A 级证据之一。

**核对方法**（可复现）：

```bash
# 1. 逐章标题与状态标记
grep -n "^## 第\|^### 第" 02_章节笔记/已读章节证据笔记.md
# 2. 章节号出现次数（>1 表示有二次记录，取时间最晚者）
grep -o "^## 第[0-9]*章" 02_章节笔记/已读章节证据笔记.md | sed 's/## 第//;s/章//' | sort -n | uniq -c
# 3. 部分阅读标记
grep -c "⚠️ 部分阅读\|仅第1页" 02_章节笔记/已读章节证据笔记.md
```
