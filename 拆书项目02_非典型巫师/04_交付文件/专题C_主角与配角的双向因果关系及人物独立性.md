# 专题报告 C：主角与配角的双向因果关系及人物独立性

> 项目：《霍格沃茨与非典型巫师》独立拆书研究（第四阶段）
> 依据：本项目实读正文 **65 章完整 + 10 章部分（已读 75 章）** / 517 章（完整率 12.6%）
> 证据等级：**A**=多个独立场景/章节支持；**B**=有正文依据但样本有限；**C**=推测或待验证
> **本报告的核心问题：不是"主角如何影响配角"，而是"配角能不能影响主角"。**

## 零、先给结论

> **【V2 修订，经第四阶段独立复核】** 本节初版结论为"配角有手脚、没有方向盘"。复核 Agent 读了我从未接触的 195–498 段后，用 469、470、417 三章证明"没有一个人能改变主角的长期目标"说过头了。**已按复核结果改写。** 复核报告见 `03_子代理报告/第四阶段独立复核报告.md`，分歧见其第六节。

**配角的反作用存在，但作用点在"路径"上，不在"目的地"上。**

复核 Agent 的提法比我的准确，直接采用：**方向盘焊死在主角手里，油门由配角踩。配角能决定他先去哪儿、先救谁，不能决定他去哪。**

| 反作用类型 | 是否存在 | 代表章节 | 证据等级 |
|---|---|---|---|
| **阻断具体计划**（让他拿不到想要的东西） | ✅ 有 | 374（海格拒说伤因）、186（洛哈特两次推脱）、184（日记本小伏拒教厉火咒，**但主角是主动收手**） | A（3 场景，其中 1 处性质需修正） |
| **产生主角无法控制的后果** | ✅ 有 | 384（双胞胎制裁蒙太致其失踪）、314（海格误解致曝光） | B（2 场景） |
| **改变主角的做法/节奏** | ✅ 有 | 262（因艾丽娅处境而设计"不羞辱人"的资助）、381（提醒 DA 后主动收手）、**470（巴布吉的固执逼他改行程去救人）** | A（3 场景） |
| **改变阶段目标与行动优先级** | ✅ 有（**初版否认，复核推翻**） | **469（邓布利多昏迷 → 主角宣布"这个时代，该赛某人说了算了"）**、417（因邓布利多"死劫"而重新盘算） | B（2 场景） |
| **改变长期底盘**（造容器/长生/自主） | ❌ **未观察到** | — | C |

**一句话修正版**：配角能改他的**日程表和阶段任务**，改不了他的**三项底盘**（容器、长生、不受制于人）。而 469 章之后，底盘上还要加第四项——**秩序主导权**。这一项恰恰是被配角的处境催出来的，所以"底盘不可动"这个说法本身也要打折。

**适用范围**：已读 75 章 + 复核补充的 20 章（195–273、415–498 段抽样）。**402–489 段仍然几乎全空**，不能排除那里有更硬的反例。

## 一、分析框架：五个维度，不是一个等级

之前的报告用"核心圈/边缘人"这种单一维度分类，结果同一个人被放进三个不同位置。本报告改用**五个独立维度**，一个人可以同时在每个维度上取不同值。

| 维度 | 问的问题 | 取值 |
|---|---|---|
| **存在感** | 出场多不多 | 高／中／低 |
| **功能性** | 是否承担剧情或信息功能 | 强／弱 |
| **行动独立性** | 是否主动做自己的事（不是主角让他做的） | 有／无 |
| **目标独立性** | 是否有不依赖主角的目标 | 有／部分／无 |
| **因果独立性** | 能否产生主角无法完全控制的后果 | 有／无 |
| **关系反作用** | 能否改变主角的计划、判断或行为 | 有／无 |

**重要提醒**：这六个维度**不能加总**。"出场多 + 功能强"不等于"人物独立"。乌姆里奇出场多、功能强（她是五年级的主要冲突源），但**六个维度里只有前两个成立**——她从头到尾没有一次自主行动能改变任何事，到 365 章连身体控制权都失去了。

## 二、逐人判定（只写有正文依据的）

### 2.1 海格——独立性最高，且直接影响过主角

| 维度 | 判定 | 依据 |
|---|---|---|
| 存在感 | 高 | 12、186、190、263、314、374 等多章 |
| 功能性 | 强 | 禁林入口、神奇生物知识、教职更替 |
| **行动独立性** | **有** | 自行加班去围栏（186）；自行去找巨人（374） |
| **目标独立性** | **有** | 想当保护神奇动物课教授（186 主角只能"猜"）；想和巨人建交（374） |
| **因果独立性** | **有** | 不听劝 → 身份被斯基特曝光 → 失去教职（314–315） |
| **关系反作用** | **有** | 拒绝说明伤因，主角拿不到信息（374） |

**关键样本（374 章，2 页全读）**

主角追问伤因，海格的回答是明确拒绝：

> "不能说……即便是拿我的工作都抵不了这份责任，这是机密。"

**这是全书对"配角独立性"最硬的一段**：海格宁愿承担失去工作的风险，也不告诉主角。而且他不是被动沉默——他先否认（"什么巨人，哪里有巨人"），再怀疑是主角泄密（"他转头看向赛恩斯"），最后才给出"机密"这个理由。

**主角的反应同样重要**：

> "但是他却没想着因为这个就去强迫海格治疗，**是否接受救治是海格的自由**。既然海格同意了，他当然不介意在治疗的同时得到一些模糊的数据。"

一边是功利（测混血巨人魔法抗性），一边是边界（不强迫）。两者同段并存，作者没有做道德修饰。

> **【V2 修正，重要】** 我最初据这一句把主角的伦理定为"对朋友守边界"。**复核 Agent 用 498 章推翻了它**（赫敏哭求离开，主角仍强行公布"哈利是魂器"）。详见本报告 5.5 节。
> **374 章真正能证明的**：在这件**不花钱、不碍事**的事情上，他给了对方选择权。**不能**推广为"他对朋友守边界"。

**另一处（186 章）**：海格主动加班，主角只能推测动机——

> "赛恩斯心中一动，大概猜到了海格这么积极的原因。莫非保护神奇动物课教授已经透露出了他想退休的意思？"

**"大概猜到了"这四个字是写法要点**：配角的目标由主角**推断**得出，而不是由配角说出来。读者因此知道"主角并不掌握一切"。

### 2.2 双胞胎——独立性最高，且制造了主角无法控制的后果

| 维度 | 判定 | 依据 |
|---|---|---|
| 存在感 | 高 | 11、19、262、384 等多章 |
| 功能性 | 强 | 创业伙伴、恶作剧、反抗乌姆里奇 |
| **行动独立性** | **有** | 私下制裁蒙太（384） |
| **目标独立性** | **有** | "以后的工作指望不上家里，所以现在就开始为以后打算"（262） |
| **因果独立性** | **有（最典型）** | 蒙太失踪（384） |
| **关系反作用** | 部分 | 最初**拒绝**接受投资（262），迫使主角改条款说法 |

**关键样本一（262 章，2 页全读）：他们先拒绝**

主角拿出魔法合约要投一千加隆，双胞胎的第一反应不是感激，是怀疑：

> "别开玩笑了！"
> "你这么看好我们，我们很感激，但是你真的想清楚了！"

**主角被迫追加解释**——"不用妄自菲薄……我不是在施舍，我是真的觉得你们的创业前景值这个价钱"。**这就是"配角反作用"的微观形态**：主角原本只打算给钱，因为对方不接受，他必须把"为什么给"讲清楚，并调整成"原始股"而不是赠予。

**关键样本二（384 章，2 页全读）：他们闯了主角管不了的祸**

双胞胎制裁蒙太，比原著更狠：塞进废旧柜子 + 幻身咒 + 扔在废弃教室。结果：

> "所以，现阶段蒙太处于失踪状态。"

主角知道，但**没有干预**。这件事的后果（蒙太可能被找到、可能出事）**不由主角控制**。而且叙述点明"这一次消失柜早就被赛恩斯收起来了"——主角改变了一个条件，双胞胎仍然用别的方式造成了类似结果。

**这是全书最好的"因果独立性"样本**：主角移走了原著里的道具（消失柜），配角照样把事做成了，只是换了个方式。

### 2.3 安吉丽娜——唯一敢当面驳回主角的人

| 维度 | 判定 | 依据 |
|---|---|---|
| 存在感 | 中高 | 11、19、262、384 |
| 功能性 | 中 | 魁地奇队长、见证人、朋友 |
| **行动独立性** | **有** | 为球队荣誉公开怒斥双胞胎（384） |
| **目标独立性** | **有** | "对魁地奇的热情很高，以后很可能会想要进入正式俱乐部"（262） |
| **因果独立性** | 无 | 她的行动没有产生独立事件 |
| **关系反作用** | **有** | 主角替双胞胎说话，**她不接受** |

**关键样本（384 章）**

主角试图调解：

> "安吉丽娜，我这么说你可能会觉得我在偏向他们……他们被乌姆里奇禁赛几乎是注定的。"

她的回应是**怒气不减**：

> "你听！听听赛恩斯怎么说的"（对双胞胎）→ 然后"怒气不减，狠狠地瞪了双胞胎一眼"

**主角的调解失败了，而且作者没有让他再试第二次。** 这是"配角不服从主角"的清晰样本，也是本书少见的"主角说话不管用"的场面。

**要注意的分寸**：她驳回的是**态度**，不是主角的**安排**。她并没有做出与主角利益相反的决定。所以她的"关系反作用"是**局部的**。

### 2.4 艾丽娅——主角想帮却"不能直接帮"的人

| 维度 | 判定 | 依据 |
|---|---|---|
| 存在感 | 中 | 19、150、262、384 |
| **目标独立性** | **有** | 散场后"要回去想一想自己以后的就业方向"（262） |
| **因果独立性** | 无 | 无独立事件 |
| **关系反作用** | **有（隐性）** | 她的处境**改变了主角的投资方式** |

**关键样本（262 章第2页）**

主角盘算朋友圈时，唯独对艾丽娅没办法：

> "艾丽娅·斯平内特，父母全是麻瓜，她是除了双胞胎之外，自己的朋友之中唯一一个不好开局的……将来在找工作的时候会非常困难。"

他的处理方式很特别：

> "赛恩斯有心帮她一把，却也不会突兀地上门询问，'你需不需要帮助？'**那不是在帮人，那是在羞辱人！**"

**这一句是全书对"施恩"最清醒的判断**。它说明：艾丽娅的处境**约束了主角的行为方式**——他想帮，但不能用最直接的方式帮，只能绕道（投资双胞胎、创造合伙机会）。

**这就是"配角反作用"的第二种形态：不改变目标，改变手段。** 证据等级 B（单一章节，但论述完整）。

### 2.5 本与亚当——关系的发起方常常是他们

| 维度 | 判定 | 依据 |
|---|---|---|
| 存在感 | 高 | 16、19、25、167、263 |
| **目标独立性** | **有** | 本"求稳"（第一个结婚、辞去管理员开食品店）；亚当"不想被安排"（19 章埋线，509/511 兑现） |
| **关系反作用** | **有** | 由他们发起关系修复（167） |

**关键样本（167 章）**

学年开始回宿舍，先开口的是他们：

> "赛恩斯！我们还以为你不回来了！"
> "我们还以为你会换宿舍，你知道的，毕竟你已经是五年学生了！"
> "我们刚才在晚宴上都不敢问，唯恐得到一个令人尴尬的答案。"

主角的回应是被动式的：

> "他们确实有询问过我是不是要换寝室，但是我拒绝了，我和你们当室友还没当够呢！"

**关系戏由配角的焦虑发起，主角回应。** 这与"主角经营关系"的常见写法相反：本书里，关系的温度是**配角先在意的**。

**另一处（25 章）**：室友对主角的"努力"感到压力，也是他们先有情绪，主角才来做工作（带苹果派谈判）。

### 2.6 孔蒂与金铃——行动独立，目标依附

| 维度 | 判定 | 依据 |
|---|---|---|
| 存在感 | 中 | 272、367 |
| 功能性 | 强 | 后勤、照料、情报 |
| **行动独立性** | **有** | 自行组织生日会（272） |
| **目标独立性** | **无** | 一切以主角为中心 |
| **因果独立性** | 无 | — |
| **关系反作用** | 无 | 主角对她的评价是"不能当真" |

**关键样本（272 章）**

> "孔蒂和金铃**抬着一个巨大的蛋糕幻影显形在客厅里**。'先生，为了庆祝您成年！'"

**这件事主角没有安排**。她自行判断了日期（"今天是九月30日，明天就是您的生日"是她回答的）、自行准备、自行到场。

但同一章里，主角对她的态度是：

> "算了，小精灵的评价不能当真，自己一个被束缚在小小魔法界的小人物……绝对谈不上一个'伟大'！"

**这两段放在一起才准确**：她有行动能力，但在主角的认知里，她的判断**不被采信**。所以她的独立性是"行动层"的，不是"关系层"的。

**注意**：她的首次出场章节仍未定位。已知"谢谢你这五年的辛苦付出"（272），推算她在校第一年就已存在，但首次出场未确认——**列入待验证清单**。

### 2.7 日记本里的小伏——唯一"成功阻断主角计划"的对手

| 维度 | 判定 | 依据 |
|---|---|---|
| 行动独立性 | **有** | 拒绝交流、拒绝透露 |
| **关系反作用** | **有** | 主角拿不到厉火咒，遂放弃 |

**关键样本（184 章）**

> "魁地奇过后赛恩斯也研究了笔记本一回，与里面年轻的小伏有过一些交流，但是**并没有从他那里套出厉火咒**。他见里面的小伏**对自己防备颇深**，也就对它失去了兴趣。"

**这是全书目前唯一一处"主角的计划被明确挫败"的记录**——不是失败在战斗，而是失败在**信息获取**。而且主角的反应是**放弃**，不是硬来。

**两句之外还有一个后果**：他把日记本"关在了箱子里吃灰……把它扔了出去"。**这是一个未处理的隐患，由主角自己制造。** 在已读章节中没有交代扔到了哪里——**列入待验证**。

### 2.8 洛哈特——会推脱，主角要换三次话术

**关键样本（186 章）**

主角想拿图书馆条子，洛哈特连推两次：

> "这个，奥特姆，虽然我非常愿意继续训练你们，但是我太忙了……"
> "……嗯……这个……小巫师应该学会自己去找……"

主角改口（"我想着您能不能给我写一个让平斯夫人帮忙的条子"）才拿到。

**要点**：配角不是"被说服就照办"，主角需要**连续调整请求的形式**。这与书中大量"主角一开口别人就服"的场面形成对照。

### 2.9 弗立维——用规则反抗，主角只是旁观

**关键样本（384 章）**

乌姆里奇要他帮忙处理烟花，他的回答：

> "不，"弗立维教授坚定地说，"还是请你去处理一下吧，我不确定自己有没有施法的权利！"

**这是配角独立行动的一个漂亮样本**：他不正面冲突，用乌姆里奇自己的"教师资格审查"逻辑反制她。而主角在这场戏里的功能是**旁观者**，他甚至没说话。

## 三、配角能改变主角吗？——分四层回答

### 3.1 能阻断具体计划（A 级，3 个独立场景）

| 章 | 谁 | 阻断什么 | 主角的反应 |
|---|---|---|---|
| 184 | 日记本小伏 | 厉火咒的获取 | 放弃，把日记本扔了 |
| 374 | 海格 | 伤因信息 | 不再追问，改为观察推断 |
| 186 | 洛哈特 | 图书馆权限 | 换话术，第二次才成 |

**共性**：三次都是**信息/资源**层面的阻断，不是目标层面的。主角每次都**改路径而不改目标**。

### 3.2 能产生主角无法控制的后果（B 级，2 个场景）

| 章 | 谁 | 后果 | 主角是否预料 |
|---|---|---|---|
| 314 | 海格 | 误解提醒 → 身份被曝光 → 失去教职 | **否**，主角事后自我结算 |
| 384 | 双胞胎 | 蒙太失踪 | 知道，但未干预，后果未了 |

**314 章的原文很关键**（主角的自我结算）：

> "是因为赛某人提醒的不够明确吗？……估计我就是直接告诉他不要提这一茬，他也是不会听的。如此说来，赛某人仍然无愧于'朋友'，即便因此顶了他的位子，也不能说赛某人不够朋友。"

**这段是"主角被配角改变命运"的唯一明确记录**：他提醒 → 失败 → 海格失去教职 → **主角得到教职**。结果对主角有利，但**不是他设计的**。

### 3.3 能改变主角的做法（B 级，2 个场景）

- **262 章**：因为艾丽娅的处境，主角把"直接资助"改成"投资+合伙"，并明确"上门询问需不需要帮助=羞辱人"
- **381 章**：提醒 DA 之后，主角仍在放任，但把话说成了"说不说在我，听不听在你们"，并主动收手（"言尽于此"）

**这两处都是"手段调整"，目标未变。**

### 3.4 能改变阶段目标，改不了底盘（V2 修正）

> **【V2 修订】** 初版写"不能改变主角的目标（C 级，未观察到）"。**该结论被复核推翻**，反例如下。

| 章 | 配角/事件 | 主角的目标变化 |
|---|---|---|
| **469** | 邓布利多昏迷不醒 | 主角宣布："既然你们不愿意既定的规则运行，那就按照赛某人的规则来运行吧。**这个时代，该赛某人说了算了！**"——长期目标清单**新增"秩序主导权"** |
| **470** | 巴布吉的固执 | 主角改变行程去蹲守救人——**行动优先级被配角拉动** |
| **417** | 预知邓布利多"有一个差不多是死劫的一难" | 重新盘算是否干预；最终因"说不清怎么知道山洞的事"而放弃 |

**修正后的表述**：
- **阶段目标与行动排序：可被配角/事件推动**（B 级，2–3 个场景）
- **三项底盘（造容器、长生、不受制于人）：在已读范围内未被触动**
- **但"底盘不可动"这个说法要打折**：469 章新增的第四项"秩序主导权"，恰恰是配角处境催出来的。也就是说，**底盘不是不能加项，只是已读章节里没有减项**。

**主 Agent 保留的分歧**：469 章算"配角改变目标"还是"事件改变目标"？我倾向后者——邓布利多的昏迷是一个**状态事件**，而且这个状态部分源于主角自己选择不干预（417）。但复核 Agent 指出同类现象确实存在，故接受"阶段目标可被推动"的表述。此分歧记录于复核报告第六节 D1。

**这个空白本身的写作意义**：主角是**目标固定型**人物。他的变化集中在"手段"和"边界"上，不在"想要什么"上——直到 469 章才加了一项。这种人物适合长篇连载（读者永远知道他要什么），代价是**缺少内在转折**。

### 3.5 权力结构：配角的否决权有多硬（复核补充，主 Agent 未读章节）

**关键样本（第227章，复核 Agent 提供，主 Agent 未读）**

主角要留校，邓布利多连续两次拒绝：

> "那可不一定"／"我可不是个会心软的人"

主角的反应是直接掀桌：

> "若是我向魔法部捐献三万加隆……若是不行的话，五万也是可以的"／"学校不是有董事会吗，实在不行我就只能破财收购学校了"

邓布利多的回应只有一个字："**滚！**"

**这一章的分量**：它证明配角的"拒绝"在主角的资源面前**可以被碾过**。这与 374 章海格"这是机密"形成对照——

| 场景 | 配角拒绝 | 主角的处理 | 结果 |
|---|---|---|---|
| 374 海格 | 拒说伤因 | 不再追问 | **配角赢了** |
| 186 洛哈特 | 两次推脱 | 换话术 | 各让一步 |
| **227 邓布利多** | 两次拒绝 | **砸钱 + 威胁收购** | **主角赢了** |

**规律（B 级，3 场景）**：配角的否决权**取决于主角有多想要**。他想要的东西可以用钱和制度强行拿到；他不太想要的东西（海格的伤因），就让步。

**这条规律修正了我对"尊重"的理解**：他的"不强迫"不是原则，是**性价比判断**。

## 五、主角如何"给对方主体性"（这是本书最值得迁移的一点）

在已读章节里，主角有一个反复出现的做法：**在给别人好处时，刻意设计让人不失去尊严的形式。**

| 章 | 做法 | 原话 |
|---|---|---|
| 262 | 把"赠予"改成"投资原始股"，并强调"我不是在施舍" | "我完全可以用一百加隆购买你们百分之二十的股份……但是那样我会感到不安" |
| 262 | 要求对方**仔细阅读合约再签** | "我建议你们仔细阅读之后再下笔" |
| 262 | 加一行见证人签名，"让她们有一点参与感" | 原文直述 |
| 262 | 拒绝"上门询问需不需要帮助" | "那不是在帮人，那是在羞辱人！" |
| 190 | 替三人组解围（岩皮饼太硬），但**不点破**他们在装 | "我是因为个人爱好才直接吃的……你们正好可以试试" |
| 263 | 帮海格出考题，不邀功 | "不用说了，其他几个年级的考题我也都准备好了！" |

**统一规律（B 级，6 个场景）**：**给好处时，把"我给"包装成"你挣的"或"你自己想到的"。**

**这条规律为什么重要**：它让一个"算计型、强势、能力远超同龄人"的主角，不至于把身边所有人写成工具。**配角的主体性不是靠台词给的，是靠主角的行动形式给的。**

**反例（同一本书里）**：对乌姆里奇，主角用的是完全相反的形式——不解释、不给选择、不留尊严（362–365）。这说明"给主体性"是**按对象分层**的，不是普适美德。

## 五之五、道德边界：为什么"对朋友守边界"这个模型被推翻了（本阶段最大修正）

> **【本节为第四阶段新增，且是主 Agent 自我推翻的一节】**
> 我在 374 章读到一句"是否接受救治是海格的自由"，就把主角的伦理定性为"按对象分层：对朋友守界、对敌人无界"。复核 Agent 读了我没读过的 415–498 段，用六个场景把这个模型打穿了。**这是本项目第二次犯同一个错：拿一句好话当规律**（第一次是第三阶段的"与原轨别无二致"）。

### 5.5.1 反例（全部为主 Agent 未读章节，由复核 Agent 提供）

|---|---|---|

### 5.5.2 修正后的模型

**主轴不是"朋友／敌人"，是"有用性＋妨碍度"。**

| 对象类型 | 处理方式 | 依据 |
|---|---|---|
| 有用且不妨碍 | 走程序、给体面、给主体性 | 262（原始股+见证人签名）、273（与家养小精灵协商）、204（阻止孔蒂自罚） |
| 无用但不妨碍 | 忽略、不投入 | 露西娅等女生、罗杰·戴维斯 |
| 妨碍目标 | 走效率，不讲程序 | 330（抠眼）、362–363（钻心咒）、364（断杖）、365（颅内植入）、449（杀） |
| 妨碍目标且有用 | **强制但不摧毁**（留活口做实验/做筹码） | 415（两年期活体实验）、349 类型"给你个痛快" |

**一句话**：**伦理是成本函数的输出，不是对象的属性。**

**对 374 章的重新定性**（复核 Agent 最刺人的一句，我接受）：

> "374 明写'是否接受救治是海格的自由'这类句子，只能证明他在**自己不需要付出代价时**讲程序。一旦涉及核心利益（哈利的魂器身份、秘密基地坐标），这套程序立刻作废。"

### 5.5.3 保留的分歧

**关于 498 章**：复核 Agent 判定为"对朋友不守边界"，我部分同意，但保留另一种读法——主角强行告知哈利"你是魂器"，**仍可以读作"为他好"的极端形式**（让他知道自己是什么，以便自己选择），属于**善意与强制同源**，而不是纯粹的效率计算。

这个分歧很关键，因为它决定后续方法卡怎么写：
- 若采复核读法 → "守边界"不能写成原则，只能写成"低成本时的体面"
- 若采我的读法 → 可以写"强制性的善意"这一人物类型，但要标注它有道德风险

**两种读法都要留，不合并。**

### 5.5.4 这一节对写作的启示（谨慎表述）

本书示范了一件事：**一个"算计型主角"的伦理如果写成稳定原则，人物会假；写成成本函数，人物会冷但真。**

代价是**读者无法预期他的下限**。498 章那种"朋友哭求仍强行告知"的场面，会让一部分读者彻底失去对主角的认同。**这是本书的取舍，不是可以照搬的优点。**

## 七、可迁移的方法（附适用条件与副作用）

### 方法 C-1：用"主角推断配角动机"代替"配角自述动机"

**研究依据**：186（海格主动加班，"大概猜到了"）、374（海格拒说，"不能说"）
**解决的问题**：配角一旦主动交代心事，就变成主角的附属品
**具体机制**：让主角只看到行为，动机靠猜；猜对猜错都留着
**执行步骤**：
1. 写配角的**行为**（加班、受伤、隐瞒）
2. 让主角给出一个**推测**，用"大概""莫非"这类不确定词
3. 不安排配角来确认或否认
4. 后续章节再用行为验证（或不验证）
**副作用**：读者可能觉得"这条线没交代"。适合长篇，不适合短篇
**检查标准**：这个配角的动机，是不是只有读者从行为里推出来的？如果是主角问出来的，改掉

### 方法 C-2：让配角先拒绝一次

**研究依据**：262（双胞胎拒收投资）、186（洛哈特两次推脱）、384（安吉丽娜驳回调解）
**解决的问题**：主角一开口别人就服，人物全成纸片
**具体机制**：主角的提议必须经过至少一次**真实的阻力**，且阻力要有自己的理由
**执行步骤**：
1. 主角提出请求/给予
2. 对方用**自己的处境**为理由拒绝（不是矫情）
3. 主角**调整形式**（不是加钱、不是威胁）
4. 第二次才成，或者干脆不成
**副作用**：节奏变慢。每 10 章用 2–3 次即可
**检查标准**：删掉这次拒绝，剧情有没有变化？没有变化说明拒绝是假的

### 方法 C-3：给好处时，把"我给"包装成"你挣的"

**研究依据**：262（原始股、见证人签名、"不是施舍"）、190（不点破）、263（不邀功）
**解决的问题**：主角太强，帮人像施舍，读者反感
**具体机制**：改变**形式**，不改变**实质**
**执行步骤**：
1. 想清楚这份好处会让对方失去什么（尊严、平等感、自主权）
2. 设计一个形式，让对方付出某种"对价"（签字、出力、参与）
3. 主角明确说出"这不是施舍"
4. 不点破自己是在帮忙
**注意事项**：**只对"主角不需要付出代价"的场合用**。复核 Agent 用 498 章证明：一旦涉及核心利益，这套形式立刻作废（朋友哭求也照样强行告知）。所以它不是"主角的品德"，是"低成本时的体面"。写的时候如果把它当品德写，人物会在下一次利益冲突时崩掉

**检查标准**：受助者事后会不会觉得自己"被可怜了"？会，就还没写对。**另加一条**：这份体面，在主角付出重大代价时还保得住吗？保不住是正常的，但要写出他**自己知道保不住**

### 方法 C-4：让配角的行动产生主角管不了的后果

**研究依据**：384（蒙太失踪）、314（海格误解致曝光）
**解决的问题**：所有事都在主角掌控内，紧张感消失
**具体机制**：配角按自己的目标行动，行动撞上主线，留下一个**悬着的后果**
**执行步骤**：
1. 给配角一个与主角无关的目标
2. 让他为目标采取行动（不必通知主角）
3. 行动产生副作用
4. 主角知道，但**不立刻解决**（解决方式留到后面，或干脆不解决）
**副作用**：悬而不决会让读者不满。一本书 2–3 处是上限，且至少要有一处真的回收
**检查标准**：这个后果，主角能不能一句话抹平？能，就说明它不够硬

### 方法 C-5：让配角的否决权随主角的欲望强度浮动（复核后新增）

**研究依据**：374（海格拒说伤因 → 主角让步）、186（洛哈特推脱 → 各让一步）、**227（邓布利多两次拒绝 → 主角砸钱+威胁收购，配角完败）**
**证据等级**：B（3 个场景）
**解决的问题**：配角要么一味顺从、要么一味强硬，都不像活人
**具体机制**：配角的拒绝能否成立，取决于**主角有多想要这件事**。想要的东西可以用资源碾过；不太想要的，就让步
**执行步骤**：
1. 写清主角这次到底有多想要（可有可无 / 想要 / 非要不可）
2. 让配角拒绝一次
3. 按欲望强度决定结果：
   - 可有可无 → 主角让步，且不再提
   - 想要 → 换方式再试一次，各让一步
   - 非要不可 → 主角动用资源/制度/威胁，**配角完败**
4. 关键：**完败的那一次要写出来**，否则读者不知道主角的上限在哪
**注意事项**：如果主角每次都赢，说明你给的欲望全是"非要不可"；如果每次都输，说明主角没有筹码
**检查标准**：读者能不能说出"这件事他不会让步，那件事他会"？

### 方法 C-6：让"尊重"只在低成本时出现，并让读者看见它的价格（复核后新增，高风险）

**研究依据**：374（不强迫海格）vs 498（强行告知哈利）、460（拆壁炉、信息管控）、468（把朋友当情报渠道）
**证据等级**：B（4 个场景，但分属不同关系强度）
**解决的问题**：主角对所有人都"很尊重"，显得假；对所有人都冷酷，读者弃书
**具体机制**：给主角一套**分级程序**，并在跨级时让读者看见代价
**执行步骤**：
1. 定义"低成本"的边界：不花钱、不误事、不暴露秘密
2. 在边界内，给足选择权和体面（374 的治疗同意、262 的合约形式）
3. 越界时，程序立刻作废，且**主角自己知道**
4. 不要给他找理由（"我是为他好"只写一次，写多了就是洗白）
**副作用**：**这是本书最危险的一条**。498 章那种"朋友哭求仍强行告知"的处理，会让相当一部分读者彻底反感主角。想让读者喜欢主角的书，**不要用这条**
**检查标准**：把主角最不体面的那一次写出来，读者还愿不愿意跟他走下去？愿意，说明人物立住了；不愿意，说明你只是把他写冷了

## 九、本报告的自我限制

1. **本报告已被一次独立复核推翻过两次**：初版的"配角无方向盘"被 469/470 修正，初版的"分层伦理"被 498 等六章推翻。**现在的 V2 仍然只是 95 章范围内的判断。**
2. 本报告的**反例来自主动检索**（我把 374 章当成"是否对朋友也无情"的检验点去读），但**检索范围受我的假设限制**——我找的是"主角是否对朋友无情"，没去找"主角是否对朋友虚伪"。**498 章是被复核 Agent 找到的，不是我找到的。**
