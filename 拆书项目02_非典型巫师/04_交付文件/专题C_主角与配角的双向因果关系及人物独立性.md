## 一、分析框架：六个维度，不是一个等级

之前的报告用"核心圈/边缘人"这种单一维度分类，结果同一个人被放进三个不同位置。本报告改用**六个独立维度**，一个人可以同时在每个维度上取不同值。

| # | 维度 | 问的问题 | 取值 |
|---|---|---|---|
| 1 | **存在感** | 出场多不多 | 高／中／低 |
| 2 | **功能性** | 是否承担剧情或信息功能 | 强／弱 |
| 3 | **行动独立性** | 是否主动做自己的事（不是主角让他做的） | 有／无 |
| 4 | **目标独立性** | 是否有不依赖主角的目标 | 有／部分／无 |
| 5 | **因果独立性** | 能否产生主角无法完全控制的后果 | 有／无 |
| 6 | **关系反作用** | 能否改变主角的计划、判断或行为 | 有／无 |

**重要提醒**：这六个维度**不能加总**。"出场多 + 功能强"不等于"人物独立"。乌姆里奇出场多、功能强（她是五年级的主要冲突源），但**六个维度里只有前两个成立**——她从头到尾没有一次自主行动能改变任何事，到 365 章连身体控制权都失去了。

**维度重叠的自查（V3 新增，任务要求）**

第 3、4、5、6 四项确实存在概念邻接，不掩饰：

| 重叠嫌疑 | 实际区分 | 是否保留为独立维度 |
|---|---|---|
| 3 行动独立性 vs 4 目标独立性 | 一个人可以**有目标但不动手**（只说不做），也可以**一直动手但目标全是别人给的**（孔蒂：自行操办生日会，但目标依附主角）。二者可分离 | 保留 |
| 3 行动独立性 vs 5 因果独立性 | **做自己的事**不等于**做出主角控制不了的结果**。安吉丽娜（384）主动怒斥双胞胎，但未产生独立事件；双胞胎（384）则产生了蒙太失踪 | 保留 |
| 5 因果独立性 vs 6 关系反作用 | 因果独立性针对**世界状态**，关系反作用针对**主角本人**。前者是"事情变了"，后者是"他变了" | 保留 |
| 4 目标独立性 vs 6 关系反作用 | 目标独立是**状态描述**，关系反作用是**效果描述**。有独立目标的人不一定影响得了主角（艾丽娅有就业目标，影响主角的是她的**处境**而非目标） | 保留，但需注意：6 的证据常来自 4 的副产品 |

**结论**：六维保留，但 5 与 6 的边界最薄，实际判定时须写明"改变的是世界还是主角"，否则容易重复计数同一件事。**这六维是辅助分析框架，不是人物分类体系**，不得用它给人物排等级。

## 二、逐人判定（只写有正文依据的）

### 2.1 海格——独立性最高，且直接影响过主角

| 维度 | 判定 | 依据 |
|---|---|---|
| 存在感 | 高 | 12、186、190、263、314、374 等多章 |
| 功能性 | 强 | 禁林入口、神奇生物知识、教职更替 |
| **行动独立性** | **有** | 自行加班去围栏（186）；自行去找巨人（374） |
| **目标独立性** | **有** | 想当保护神奇动物课教授（186 主角只能"猜"）；想和巨人建交（374） |
| **因果独立性** | **有** | 不听劝 → 身份被斯基特曝光 → 失去教职（314–315） |
| **关系反作用** | **有** | 拒绝说明伤因，主角拿不到信息（374） |

**关键样本（374 章，2 页全读）**

主角追问伤因，海格的回答是明确拒绝：

> "不能说……即便是拿我的工作都抵不了这份责任，这是机密。"

**这是全书对"配角独立性"最硬的一段**：海格宁愿承担失去工作的风险，也不告诉主角。而且他不是被动沉默——他先否认（"什么巨人，哪里有巨人"），再怀疑是主角泄密（"他转头看向赛恩斯"），最后才给出"机密"这个理由。

**主角的反应同样重要**：

> "但是他却没想着因为这个就去强迫海格治疗，**是否接受救治是海格的自由**。既然海格同意了，他当然不介意在治疗的同时得到一些模糊的数据。"

一边是功利（测混血巨人魔法抗性），一边是边界（不强迫）。两者同段并存，作者没有做道德修饰。

> **【V2 修正，重要】** 我最初据这一句把主角的伦理定为"对朋友守边界"。**复核 Agent 用 498 章推翻了它**（赫敏哭求离开，主角仍强行公布"哈利是魂器"）。详见本报告 5.5 节。
> **374 章真正能证明的**：在这件**不花钱、不碍事**的事情上，他给了对方选择权。**不能**推广为"他对朋友守边界"。

**另一处（186 章）**：海格主动加班，主角只能推测动机——

> "赛恩斯心中一动，大概猜到了海格这么积极的原因。莫非保护神奇动物课教授已经透露出了他想退休的意思？"

**"大概猜到了"这四个字是写法要点**：配角的目标由主角**推断**得出，而不是由配角说出来。读者因此知道"主角并不掌握一切"。

### 2.2 双胞胎——独立性最高，且制造了主角无法控制的后果

| 维度 | 判定 | 依据 |
|---|---|---|
| 存在感 | 高 | 11、19、262、384 等多章 |
| 功能性 | 强 | 创业伙伴、恶作剧、反抗乌姆里奇 |
| **行动独立性** | **有** | 私下制裁蒙太（384） |
| **目标独立性** | **有** | "以后的工作指望不上家里，所以现在就开始为以后打算"（262） |
| **因果独立性** | **有（最典型）** | 蒙太失踪（384） |
| **关系反作用** | 部分 | 最初**拒绝**接受投资（262），迫使主角改条款说法 |

**关键样本一（262 章，2 页全读）：他们先拒绝**

主角拿出魔法合约要投一千加隆，双胞胎的第一反应不是感激，是怀疑：

> "别开玩笑了！"
> "你这么看好我们，我们很感激，但是你真的想清楚了！"

**主角被迫追加解释**——"不用妄自菲薄……我不是在施舍，我是真的觉得你们的创业前景值这个价钱"。**这就是"配角反作用"的微观形态**：主角原本只打算给钱，因为对方不接受，他必须把"为什么给"讲清楚，并调整成"原始股"而不是赠予。

**关键样本二（384 章，2 页全读）：他们闯了主角管不了的祸**

双胞胎制裁蒙太，比原著更狠：塞进废旧柜子 + 幻身咒 + 扔在废弃教室。结果：

> "所以，现阶段蒙太处于失踪状态。"

主角知道，但**没有干预**。这件事的后果（蒙太可能被找到、可能出事）**不由主角控制**。而且叙述点明"这一次消失柜早就被赛恩斯收起来了"——主角改变了一个条件，双胞胎仍然用别的方式造成了类似结果。

**这是全书最好的"因果独立性"样本**：主角移走了原著里的道具（消失柜），配角照样把事做成了，只是换了个方式。

### 2.3 安吉丽娜——唯一敢当面驳回主角的人

| 维度 | 判定 | 依据 |
|---|---|---|
| 存在感 | 中高 | 11、19、262、384 |
| 功能性 | 中 | 魁地奇队长、见证人、朋友 |
| **行动独立性** | **有** | 为球队荣誉公开怒斥双胞胎（384） |
| **目标独立性** | **有** | "对魁地奇的热情很高，以后很可能会想要进入正式俱乐部"（262） |
| **因果独立性** | 无 | 她的行动没有产生独立事件 |
| **关系反作用** | **有** | 主角替双胞胎说话，**她不接受** |

**关键样本（384 章）**

主角试图调解：

> "安吉丽娜，我这么说你可能会觉得我在偏向他们……他们被乌姆里奇禁赛几乎是注定的。"

她的回应是**怒气不减**：

> "你听！听听赛恩斯怎么说的"（对双胞胎）→ 然后"怒气不减，狠狠地瞪了双胞胎一眼"

**主角的调解失败了，而且作者没有让他再试第二次。** 这是"配角不服从主角"的清晰样本，也是本书少见的"主角说话不管用"的场面。

**要注意的分寸**：她驳回的是**态度**，不是主角的**安排**。她并没有做出与主角利益相反的决定。所以她的"关系反作用"是**局部的**。

### 2.4 艾丽娅——主角想帮却"不能直接帮"的人

| 维度 | 判定 | 依据 |
|---|---|---|
| 存在感 | 中 | 19、150、262、384 |
| **目标独立性** | **有** | 散场后"要回去想一想自己以后的就业方向"（262） |
| **因果独立性** | 无 | 无独立事件 |
| **关系反作用** | **有（隐性）** | 她的处境**改变了主角的投资方式** |

**关键样本（262 章第2页）**

主角盘算朋友圈时，唯独对艾丽娅没办法：

> "艾丽娅·斯平内特，父母全是麻瓜，她是除了双胞胎之外，自己的朋友之中唯一一个不好开局的……将来在找工作的时候会非常困难。"

他的处理方式很特别：

> "赛恩斯有心帮她一把，却也不会突兀地上门询问，'你需不需要帮助？'**那不是在帮人，那是在羞辱人！**"

**这一句是全书对"施恩"最清醒的判断**。它说明：艾丽娅的处境**约束了主角的行为方式**——他想帮，但不能用最直接的方式帮，只能绕道（投资双胞胎、创造合伙机会）。

**这就是"配角反作用"的第二种形态：不改变目标，改变手段。** 证据等级 B（单一章节，但论述完整）。

### 2.6 孔蒂与金铃——行动独立，目标依附

| 维度 | 判定 | 依据 |
|---|---|---|
| 存在感 | 中 | 272、367 |
| 功能性 | 强 | 后勤、照料、情报 |
| **行动独立性** | **有** | 自行组织生日会（272） |
| **目标独立性** | **无** | 一切以主角为中心 |
| **因果独立性** | 无 | — |
| **关系反作用** | 无 | 主角对她的评价是"不能当真" |

**关键样本（272 章）**

> "孔蒂和金铃**抬着一个巨大的蛋糕幻影显形在客厅里**。'先生，为了庆祝您成年！'"

**这件事主角没有安排**。她自行判断了日期（"今天是九月30日，明天就是您的生日"是她回答的）、自行准备、自行到场。

> "算了，小精灵的评价不能当真，自己一个被束缚在小小魔法界的小人物……绝对谈不上一个'伟大'！"

**这两段放在一起才准确**：她有行动能力，但在主角的认知里，她的判断**不被采信**。所以她的独立性是"行动层"的，不是"关系层"的。

### 2.7 日记本里的小伏——"拒绝之后主角自己走开"的对手

> **V3 更正**：本小节原题为「唯一"成功阻断主角计划"的对手」。按第三节的机制分类，这**不是阻断（R2），是拒绝（R1）+ 主角主动放弃（R4）**。标题与结论已改。

| 维度 | 判定 | 依据 |
|---|---|---|
| 行动独立性 | **有** | 拒绝交流、拒绝透露 |
| **关系反作用** | **有** | 主角拿不到厉火咒，遂放弃 |

**关键样本（184 章）**

> "魁地奇过后赛恩斯也研究了笔记本一回，与里面年轻的小伏有过一些交流，但是**并没有从他那里套出厉火咒**。他见里面的小伏**对自己防备颇深**，也就对它失去了兴趣。"

**准确的说法**：小伏**明确拒绝**（R1），主角**判断套不出来后自行收手**（R4）。失败发生在**信息获取**，而且**中止者是主角，不是小伏**——他有时间转换器、有邓布利多、有斯内普可问，一个都没用。

这个区别很要紧：写成"小伏挡住了他"，主角是个被难住的人；写成"他觉得不值就放下了"，主角是个**随时算账的人**。本书是后者。

**两句之外还有一个后果**：他把日记本"关在了箱子里吃灰……把它扔了出去"。**这是一个未处理的隐患，由主角自己制造。** 在已读章节中没有交代扔到了哪里——**列入待验证**。

## 三、配角能改变主角吗？——按五种机制分开回答

> **V3 重写**。本节 V2 标题为"分四层回答"，3.1 写"能阻断具体计划（A 级，3 个独立场景）"。
> 收尾修订时自查发现：那三个"阻断"案例里，**主角全部是自行放弃或改路径，没有一次是被外力真正挡住**。
> 按任务要求重新区分五种机制，原 3.1 的 A 级表述**撤回**。

**五种机制的定义（互斥，同一事件只能归一类）**

| 编号 | 机制 | 判定问题 |
|---|---|---|
| **R1** | 配角主动拒绝 | 配角是否明确表达了不愿/不给/不配合？ |
| **R2** | 配角实际阻断 | 主角**继续尝试也拿不到**吗？（即失败是否与主角的选择无关） |
| **R3** | 配角提供信息导致主角改决策 | 配角是否给了主角原本没有的信息，从而改变其判断？ |
| **R4** | 主角主动放弃 | 主角是否在**仍有其他手段**的情况下选择收手？ |
| **R5** | 主角因突发事件调整计划 | 触发点是**事件/状态**而非配角的意志吗？ |

### 3.1 R1 配角主动拒绝（A 级，一手 5 个场景）

### 3.2 R2 配角实际阻断（C 级，一手样本为零）

**在已读 75 章里，找不到一个"主角想尽办法仍然拿不到"的案例。**

最接近的三处都不是：

- 184：主角判断"套不出来"就放弃，但**他有时间转换器、有邓布利多、有斯内普**，未尝试
- 374：主角不追问，但**可以用摄神取念/吐真剂**（365 章他给乌姆里奇植入装置时并不忌讳手段），未尝试

**这条空白很重要，但不能反推**：**没有在已读章节中发现，不等于全书不存在。** 402–489 段只有 3 章抽样，那里完全可能有真正的阻断。**列为待验证 P1。**

## 五、主角如何"给对方主体性"（这是本书最值得迁移的一点）

在已读章节里，主角有一个反复出现的做法：**在给别人好处时，刻意设计让人不失去尊严的形式。**

| 章 | 做法 | 原话 |
|---|---|---|
| 262 | 把"赠予"改成"投资原始股"，并强调"我不是在施舍" | "我完全可以用一百加隆购买你们百分之二十的股份……但是那样我会感到不安" |
| 262 | 要求对方**仔细阅读合约再签** | "我建议你们仔细阅读之后再下笔" |
| 262 | 加一行见证人签名，"让她们有一点参与感" | 原文直述 |
| 262 | 拒绝"上门询问需不需要帮助" | "那不是在帮人，那是在羞辱人！" |
| 190 | 替三人组解围（岩皮饼太硬），但**不点破**他们在装 | "我是因为个人爱好才直接吃的……你们正好可以试试" |
| 263 | 帮海格出考题，不邀功 | "不用说了，其他几个年级的考题我也都准备好了！" |

**统一规律（B 级，6 个场景）**：**给好处时，把"我给"包装成"你挣的"或"你自己想到的"。**

**这条规律为什么重要**：它让一个"算计型、强势、能力远超同龄人"的主角，不至于把身边所有人写成工具。**配角的主体性不是靠台词给的，是靠主角的行动形式给的。**

**反例（同一本书里）**：对乌姆里奇，主角用的是完全相反的形式——不解释、不给选择、不留尊严（362–365）。这说明"给主体性"是**按对象分层**的，不是普适美德。

### 5.5.2 候选解释模型："有用性＋妨碍度"（**不是定论**）

> **V3 重要限定**：V2 在此处直接断言"**伦理是成本函数的输出，不是对象的属性**"。该句过于确定，现降格为**候选解释模型**。它只是目前解释力最强的一个，不是作者创作规律。

**模型内容**：主角对某人的处理方式，主要取决于两个变量——**这个人对他有多大用处**、**这个人妨碍他多少**。

| 对象类型 | 处理方式 | 依据 | 来源 |
|---|---|---|---|
| 有用且不妨碍 | 走程序、给体面、给主体性 | 262（原始股+见证人签名）、190（不点破）、263（不邀功） | 【一手】 |
| 无用但不妨碍 | 忽略、不投入 | 露西娅等女生、罗杰·戴维斯 | 【一手】 |
| 妨碍目标 | 走效率，不讲程序 | 330（抠眼）、362–363（钻心咒）、364（断杖）、365（颅内植入）、449（杀） | 330/362–365【一手】；449【转引】 |
| 妨碍目标且有用 | 强制但不摧毁（留活口做实验/做筹码） | 415（两年期活体实验）、273（与小精灵协商） | 均为【转引】 |

**该模型能解释的**

1. 为什么他对朋友客气、对敌人粗暴——朋友大多"有用且不妨碍"
2. 为什么 374 章肯放手——海格的伤因对他"不太有用"
3. 为什么 227 章直接砸钱——留校是"非要不可"
4. 为什么 415 章不杀反养——活体比尸体有用

**该模型不能充分解释的（必须写明）**

| 反例/难点 | 章节 | 为什么解释不了 |
|---|---|---|
| 对朋友也强行 | 498（赫敏哭求仍公布魂器） | 哈利知道自己是魂器，对主角的**用处存疑**，更像"我认为他该知道"，接近价值判断而非成本核算 【转引】 |
| 杀人写成给面子 | 449（"到时候给你个痛快，也算赛某人的一点儿心意"） | 成本模型不产生"心意"这种东西，这里有**仪式性/尊严性**的成分 【转引】 |
| 连带杀伤 | 472（厉火焚庄园，近二十人死亡，含非目标） | 成本模型可以解释"烧"，但解释不了**为什么不精确控制**——前期他是极重精确的人 【转引】 |
| 对非人角色的情感 | 272（成年生日，"这满院的'怪物'就是对自己魔法界之行最好的奖励"） | 造物对他**没有工具价值增量**，但他在此处出现了明确的情绪反应 【一手】 |

**其他可能的解释（都未排除）**

1. **关系分层说**（V2 旧模型）：对朋友/敌人两套规则。被 498 削弱，但对 262/374 仍解释得通。
2. **权力落差说**：他对**无法反抗他的人**（乌姆里奇、被绑黑巫师）手段最狠，对**能反制他的人**（邓布利多、董事会）走程序。这比"有用性"更贴合 227 与 362 的对照。
3. **叙事节奏说**：后期手段变狠，可能部分源于连载到后期需要更强刺激，而非人物逻辑演化。

**结论**：**"成本函数"是目前最好用的一个候选模型，不是结论。** 上述四类反例中，498 与 472 两处最硬，且**均为主 Agent 未一手读过的章节**——这意味着该模型的检验本身还不完整。

**对 374 章的重新定性**（复核 Agent 最刺人的一句，我接受）：

> "374 明写'是否接受救治是海格的自由'这类句子，只能证明他在**自己不需要付出代价时**讲程序。一旦涉及核心利益（哈利的魂器身份、秘密基地坐标），这套程序立刻作废。"

### 5.5.3 保留的分歧：498 章不能被写成一个结论

**关于 498 章**（【转引】，主 Agent 未一手读），复核 Agent 判定为"对朋友不守边界"，我部分同意，但拒绝把它压成单一结论。按四个层面分开看：

| 层面 | 可确认的内容 | 不能由此推出的 |
|---|---|---|
| **行为动机** | 主角认为哈利"应该知道自己是魂器"，句中有"现在正是最佳的时刻" | 不能仅因动机含"为他好"就判定行为合理——**善意的动机不豁免强制** |
| **实际后果** | 哈利被告知；赫敏当场哭求失败；斯内普阻拦被顶回 | 不能仅因赫敏难受就判定主角"恶意"——**后果伤害不等于动机伤害** |
| **权力关系** | 主角掌握信息与实力，赫敏/哈利**没有阻止他的能力** | 这是本节最关键的一层：**在这种权力落差下，"我为他好"无法被对方拒绝，因此不能作为正当性来源** |
| **人物边界** | 主角对"朋友该不该有拒绝权"给出的是**单向判断** | 不能由此断言他"对所有人都无边界"——262/374 显示低成本场合他会让路 |

**两种读法都保留，不合并**

- **读法甲（复核）**：这是效率计算压过关系边界的样本，"守边界"只是低成本时的体面。
- **读法乙（主 Agent）**：这是"强制性的善意"——让他知道自己是什么，才能自己选。属于人物类型，不属于道德辩护。

**分歧为什么必须留着**：它直接决定后续方法卡怎么写。

- 采甲 → "守边界"只能写成"低成本时的体面"，且必须写出它随时会作废
- 采乙 → 可以写"强制性的善意"这一人物类型，但**必须标注道德风险**，且要写出被强制者的痛苦

**两种都不能写成"作者在赞美这种行为"**——本项目没有任何作者意图方面的证据（访谈、感言、评论区均未获取）。

### 5.5.4 这一节对写作的启示（谨慎表述）

本书示范了一件事：**一个"算计型主角"的伦理，如果写成稳定原则，人物会假；写成随代价浮动的变量，人物会冷但真。**

> **限定**：这是"成本函数候选模型"推出的写作判断，**不是本书已被证实的创作规律**。模型本身的检验尚未完成（见 5.5.2 的四类反例）。

代价是**读者无法预期他的下限**。498 章那种"朋友哭求仍强行告知"的场面，会让一部分读者彻底失去对主角的认同。**这是本书的取舍，不是可以照搬的优点。**

## 六、主角自己制造的风险（配角独立性的另一面）

已读章节里，有三处主角留下的**未处理隐患**，都由他自己的行为产生：

| 隐患 | 章节 | 状态 |
|---|---|---|
| 日记本被"扔了出去"，下落不明 | 184 | 未交代 |
| 蒙太失踪，主角知情但未处理 | 384 | 未了 |
| 乌姆里奇颅内的装置 | 365 | 只读了第1页，后续未读 |

**这三处合起来说明一件事**：本书的主角**不是全知全能的**——他会漏、会懒、会判断失误。但他的失误**不产生代价**（至少已读章节里没有）。这是本书的一个结构性问题，也是"算计型主角"最难处理的地方：**如果没有代价，算计就只是表演。**

## 七、可迁移的方法（附适用条件与副作用）

### 方法 C-1：用"主角推断配角动机"代替"配角自述动机"

**研究依据**：186（海格主动加班，"大概猜到了"）、374（海格拒说，"不能说"）
**解决的问题**：配角一旦主动交代心事，就变成主角的附属品
**具体机制**：让主角只看到行为，动机靠猜；猜对猜错都留着
**执行步骤**：
1. 写配角的**行为**（加班、受伤、隐瞒）
2. 让主角给出一个**推测**，用"大概""莫非"这类不确定词
3. 不安排配角来确认或否认
4. 后续章节再用行为验证（或不验证）
**副作用**：读者可能觉得"这条线没交代"。适合长篇，不适合短篇
**检查标准**：这个配角的动机，是不是只有读者从行为里推出来的？如果是主角问出来的，改掉

### 方法 C-2：让配角先拒绝一次

**研究依据**：262（双胞胎拒收投资）、186（洛哈特两次推脱）、384（安吉丽娜驳回调解）
**解决的问题**：主角一开口别人就服，人物全成纸片
**具体机制**：主角的提议必须经过至少一次**真实的阻力**，且阻力要有自己的理由
**执行步骤**：
1. 主角提出请求/给予
2. 对方用**自己的处境**为理由拒绝（不是矫情）
3. 主角**调整形式**（不是加钱、不是威胁）
4. 第二次才成，或者干脆不成
**副作用**：节奏变慢。每 10 章用 2–3 次即可
**检查标准**：删掉这次拒绝，剧情有没有变化？没有变化说明拒绝是假的

### 方法 C-3：给好处时，把"我给"包装成"你挣的"

**研究依据**：262（原始股、见证人签名、"不是施舍"）、190（不点破）、263（不邀功）
**解决的问题**：主角太强，帮人像施舍，读者反感
**具体机制**：改变**形式**，不改变**实质**
**执行步骤**：
1. 想清楚这份好处会让对方失去什么（尊严、平等感、自主权）
2. 设计一个形式，让对方付出某种"对价"（签字、出力、参与）
3. 主角明确说出"这不是施舍"
4. 不点破自己是在帮忙
**注意事项**：**只对"主角不需要付出代价"的场合用**。复核 Agent 用 498 章证明：一旦涉及核心利益，这套形式立刻作废（朋友哭求也照样强行告知）。所以它不是"主角的品德"，是"低成本时的体面"。写的时候如果把它当品德写，人物会在下一次利益冲突时崩掉

**检查标准**：受助者事后会不会觉得自己"被可怜了"？会，就还没写对。**另加一条**：这份体面，在主角付出重大代价时还保得住吗？保不住是正常的，但要写出他**自己知道保不住**

### 方法 C-4：让配角的行动产生主角管不了的后果

**研究依据**：384（蒙太失踪）、314（海格误解致曝光）
**解决的问题**：所有事都在主角掌控内，紧张感消失
**具体机制**：配角按自己的目标行动，行动撞上主线，留下一个**悬着的后果**
**执行步骤**：
1. 给配角一个与主角无关的目标
2. 让他为目标采取行动（不必通知主角）
3. 行动产生副作用
4. 主角知道，但**不立刻解决**（解决方式留到后面，或干脆不解决）
**副作用**：悬而不决会让读者不满。一本书 2–3 处是上限，且至少要有一处真的回收
**检查标准**：这个后果，主角能不能一句话抹平？能，就说明它不够硬

### 方法 C-5：让配角的否决权随主角的欲望强度浮动（复核后新增）

**研究依据**：374（海格拒说伤因 → 主角让步）、186（洛哈特推脱 → 各让一步）、**227（邓布利多两次拒绝 → 主角砸钱+威胁收购，配角完败）**
**证据等级**：B（3 个场景）
**解决的问题**：配角要么一味顺从、要么一味强硬，都不像活人
**具体机制**：配角的拒绝能否成立，取决于**主角有多想要这件事**。想要的东西可以用资源碾过；不太想要的，就让步
**执行步骤**：
1. 写清主角这次到底有多想要（可有可无 / 想要 / 非要不可）
2. 让配角拒绝一次
3. 按欲望强度决定结果：
   - 可有可无 → 主角让步，且不再提
   - 想要 → 换方式再试一次，各让一步
   - 非要不可 → 主角动用资源/制度/威胁，**配角完败**
4. 关键：**完败的那一次要写出来**，否则读者不知道主角的上限在哪
**注意事项**：如果主角每次都赢，说明你给的欲望全是"非要不可"；如果每次都输，说明主角没有筹码
**检查标准**：读者能不能说出"这件事他不会让步，那件事他会"？

### 方法 C-6：让"尊重"只在低成本时出现，并让读者看见它的价格（复核后新增，高风险）

**研究依据**：374（不强迫海格）vs 498（强行告知哈利）、460（拆壁炉、信息管控）、468（把朋友当情报渠道）
**证据等级**：B（4 个场景，但分属不同关系强度）
**解决的问题**：主角对所有人都"很尊重"，显得假；对所有人都冷酷，读者弃书
**具体机制**：给主角一套**分级程序**，并在跨级时让读者看见代价
**执行步骤**：
1. 定义"低成本"的边界：不花钱、不误事、不暴露秘密
2. 在边界内，给足选择权和体面（374 的治疗同意、262 的合约形式）
3. 越界时，程序立刻作废，且**主角自己知道**
4. 不要给他找理由（"我是为他好"只写一次，写多了就是洗白）
**副作用**：**这是本书最危险的一条**。498 章那种"朋友哭求仍强行告知"的处理，会让相当一部分读者彻底反感主角。想让读者喜欢主角的书，**不要用这条**
**检查标准**：把主角最不体面的那一次写出来，读者还愿不愿意跟他走下去？愿意，说明人物立住了；不愿意，说明你只是把他写冷了

## 九、本报告的自我限制

1. **本报告已被两次独立复核修正过**：初版"配角无方向盘"被 469/470 收敛，初版"分层伦理"被 498 等六章推翻，V3 又撤回了"配角能阻断主角计划"的 A 级表述。**每次修正的方向都是"往回收"，没有一次是"往外扩"。**
2. **覆盖范围**：一手 75 章 + 转引约 20 章。**约 85% 的章节未接触。** 因此本报告的一切判断都只适用于"已读样本内"，不构成全书结论。
3. **转引证据占关键结论的比重偏高**：与"长期目标""伦理模型"直接相关的 469、470、417、498、472 全部是转引。**主 Agent 没有亲手核对过这些原文**，只能采信复核 Agent 的引述。这是本报告最实质的方法论弱点。
4. **反例检索受假设限制**：我找的是"主角是否对朋友无情"，没去找"主角是否对朋友虚伪"。498 章是复核 Agent 找到的，不是我找到的。**下一次复核应换一个我不知道的方向提问。**
5. **最容易被误用的一条**：方法 C-3（给好处包装成"你挣的"）。它在本书里之所以成立，是因为主角**确实在给真东西**（一千加隆、真考题、真治疗）。如果只是话术包装而实质是空头承诺，这套写法会变成 PUA 教程。**这是它最大的副作用。**
6. **第二容易被误用的一条**：方法 C-6（尊重只在低成本时出现）。它写出来的人物会让人**不喜欢但相信**。如果你的目标是让读者喜欢主角，**不要用这条**。
7. **本报告的六维框架是分析工具，不是评价体系。** 不得用维度得分给人物"独立性"排高低，也不得把框架本身当成作者的写作方法。
