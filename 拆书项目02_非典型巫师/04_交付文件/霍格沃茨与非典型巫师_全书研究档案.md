### 3.2 主源缺陷的明确记录

使用 8novel 意味着：

1. **文本为繁体**，引用时需转简体，且不能宣称等同番茄官方简体原文
2. **夹带水印**，出现在段间，可能切断句子
3. **存在 OCR 类错字**，如人名中的分隔符被渲染为 `?`（"賽恩斯?奧特姆"，原文应为"赛恩斯·奥特姆"）
4. **无法核验完整性**：8novel 不标章节字数，无法与官方比对

> 结论：**"读过某章"可以确认；"读到的是官方完整原文"不能确认。** 这与前一个项目遇到的问题性质相同，不隐瞒。

**结论：`?ID` 是「目录位置序号」，不是章号。位置 1–465 满足 `ID = 244512 + 位置`；466–517 无公式，须查表。**

完整映射与跳变点清单见 `05_原始资料/章节ID映射表.md`。

**为什么 ID 是"位置"而不是"章号"**：官方目录自身把「第21章 草藥課」排在第24章之后，8novel 照录该顺序，因此位置 21 装的是第22章。

**必须记录的更正（前批错误）**：前批台账写「第21章 草藥課 = 244533」，**错误**。244533 实为**第22章 圖書館與皮皮鬼**；第21章 的真实 ID 是 244536。前批所谓"已读第21章"，实际读到的是第22章。台账已更正并保留痕迹。

**466 之后为什么跳号**：8novel 的章节 ID 是全站共享的流水号，其他书的章节插入其间，造成跳号（如 465→466 从 244977 跳到 247074，510→511 从 271507 跳到 583195）。凡是遇到 ID 不连贯的章节，一律查表，不推算。
