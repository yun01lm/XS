## 二、专题研究成果

### 2.1 学生主角的独立故事线

**结论（B 级）：这不是"另一条冒险线"，是一条"建设线"。**

主角在原著主线之外修的四样东西：**能力（魔法研究）→ 资产（空间柜、游船、基地一号）→ 空间（有求必应屋、霍格莫德的家）→ 组织（家养小精灵、造物、朋友的事业）**。

原著主线对他只有两个用处：**风险源**（伏地魔、摄魂怪、战争）和**时间刻度**（哪一年会发生什么）。

**证据**

| 层 | 内容 | 章节 |
|---|---|---|
| 目标 | 不是"打败伏地魔"，是"不再受制于任何人和任何环境" | 2、27、101 |
| 行动 | 四种：准备型（主力）、暗中操纵型、规则内诉讼型、私刑型（后期） | 9、181、211／328、329、330／24、26、315／362 |
| 独立剧情来源 | 研究课题、造物、朋友的事业 | 181、211、358、367／166、367、511／265、509、511 |

**为什么"建设线"这个判断值得信**：它解释了一个现象——**删除原著人物，主角仍然有故事**。第 358、367 章（基地建设与出航）里哈利、赫敏一次都没出现，但章节照样成立。这是"独立故事线"最硬的判据。

**但同时要承认它的代价（B 级）**：建设线天然缺少"必须解决的双重压力"。原著线和原创线大部分章节是**要么这条、要么那条**，两者同时推进的只有第 314–315 章这样一个完整样本。这很可能是读者评价本书"水"的结构性原因。

### 2.2 原著剧情因果改写：改了什么，没改什么

**这是本阶段修改最多的一节——因为初稿的框架被复核推翻了。**

**初稿框架**："改代价，不改结局"。**已撤回。** 撤回理由：支撑它的原句"现场的情况与原轨别无二致"，上下文**只限定取血仪式这一环节**，被升格成了全局判断。

**修正后按环节分项列出**（第 328–330 章，同一场战役，故整体只能给 B 级）：

| 环节 | 本书处理 | 与原著差异 |
|---|---|---|
| 哈利被选为勇士 | 同（主角知道是阴谋，不阻止） | 无 |
| 塞德里克是否到达奖杯 | **未到达**：被主角遥控的怪兽拖住 + 备用混淆咒 | **大** |
| 伏地魔复活 | **照常复活**，主角隐身旁观取骨/取肉/取血 | 无（这是唯一的"没改"） |
| 哈利是否独自面对 | **否**：主角全程隐身跟随，切割咒救下 | **大** |
| 食死徒 | **三名被石化**（主角自陈是有意克制，不然"肯定不只是被石化"） | **大** |
| 穆迪 | 主角抢先石化、缴械、**抠出魔眼** | **大** |
| 主角自身 | **挖掉自己一只眼睛，植入魔眼** | 原著无此事件 |

**一句话**：本书的改写偏好是——**保留读者记忆最深的那一个动作（复活仪式），其余全部重写**，且重写部分**隐蔽执行、事后不解释**。

**必须同时记录的反证（初稿漏掉的三条，复核补出）**：

1. **护身符不是专属保护**：它是主角的通用装置（定位+门钥匙+护盾），塞德里克和哈利各一枚；**哈利戴着同一装置照样被传送走**。所以"护身符导致塞德里克存活"这条因果不成立。
2. **同章给出更高优先级**："若是现在把哈利救走……这不符合赛某人的谋划……就是为了让他成功复活"。即"救塞德里克"是**控制变量的副产品**。
3. **全章没有一句提到"死亡"或"原著结局"**。"避免原著死亡"是研究者用自己的原著知识补的。

### 2.3 原创剧情与原著剧情的交织方式

**结论（B 级）：交织密度偏低，只有三个接口。**

1. **原著事件成为原创剧情的推力**：斯基特的报道（原著）→ 海格失职 → 主角接任教授（原创）
2. **原创能力改变原著事件的处理方式**：钛合金变形 → 蛇怪被"作业化"；遥控迷宫 → 塞德里克未到中心
3. **原著人物进入原创空间**：朋友来霍格莫德的家（301）、生日会（502）、参观基地（367 之后未读）

**唯一一个两条线同时推进的完整样本**：第 314–315 章。主角劝海格别说漏嘴 → 海格误解（以为是"别说非法养危险生物"）→ 斯基特利用 → 海格失职 → **主角接任**。原著事件（报道）与原创剧情（接任）在同一条因果链上，且主角**因别人的失败而获益**。

**这个样本为什么重要**：它证明本书有能力写"双重压力"，只是大部分章节没这么写。

### 2.4 人物关系网络

**结论（B 级）：五层结构，核心圈靠"制度化的动作"维持，不靠情感事件。**

| 层 | 成员 | 建立方式 | 章节 |
|---|---|---|---|
| 核心圈 | 本、亚当、孔蒂、金铃 | 食物 + 固定社交动作 + 团体口号 | 19、25、150、292、495 |
| 同学圈 | 赫奇帕奇全院、秋·张 | 学院归属 + 记名字 | 19、21、26 |
| 师长辈 | 斯普劳特、邓布利多、海格 | 试探 → 互相评估 → 有限信任 | 193、314、315 |
| 原著主角团 | 哈利、赫敏、罗恩 | **始终停在"认识"层，未入核心圈** | 306、330、495 |
| 造物 | 汤姆、杰瑞、旻学 | 造出来就有性格，作为人的替代 | 166、367、511 |

**五种关系建立机制**（按证据强度）：食物（A 级，6 场景）、记名字（A 级，3 场景）、团体口号（B 级，2 场景）、礼物（B 级，3 场景）、共同秘密（B 级，2 场景）。

**关系分化不写好坏，写物理位置**：第 80 章用座位、同框频率、交谈对象交代"谁跟谁更近了"，然后作者直接给出一条规律（"关系靠共同经历 + 兴趣相近"）。这是本书**唯一一次作者自己下场总结规律**。

**三个结构性问题（不可照搬）**：

1. **主角没有亲密关系**：全书没有一个人是他会**主动去找**的。第 80 章他自己称之为"平等冷漠"。
2. **原著主角团始终在圈外**：主角与哈利的关系是"我照看你但不加入你"，这让他避免了同人常见的"抢戏"问题，但也让他失去了最强的戏剧关系。
3. **造物承担了情感需求**：会成长的画像、船灵、智能核心，一次性解决了"长生者的陪伴"。这是设定外挂。

### 2.5 校园日常与支线

**校园日常的可读性来源（B 级，三个机制）**：

| 机制 | 说明 | 章节 |
|---|---|---|
| 信息差 | 读者知道主角在算计，同学不知道 | 25、101 |
| 游戏化框架 | 城堡跑图"打卡/点亮地图" | 18 |
| 微型摩擦 | 皮皮鬼、楼梯、占座、室友打呼 | 22、16 |

**课堂场景的七拍**（点名→威慑→示范→讲原理→实操→点评→作业，24、26）：**这只是观察，不是模板**。本书自己也没有每节课照做（第 28 章就只有作业与惩罚两拍）。

**支线的两个层次**：

- **有独立价值的支线**：空间基地（358、367）——它有自己的工程量、失败与修正，不依赖原著事件
- **依附主线的支线**：乌姆里奇线（358、362）——基本是"主角如何应对审查"，缺少独立目标

**证据缺口**：五年级支线只读了 358、362、367 三章，中间 363–366、368–400 全空。**东方线（孔蒂、金铃）只在 367 出现，来源与建立过程完全不明。**

### 2.6 魔法研究、资源建设与独立活动空间

**结论（B 级，本阶段新增证据）：研究型主角的续写机制是"能力 → 立刻暴露新漏洞"。**

第 367 章的样本最干净：

1. 给基地一号加赤胆忠心咒 → 所有人开始遗忘它
2. **立刻**抛出问题："它在地图上是不可测绘的，卫星看不见，但**舰艇经过之后的水波怎么解释**？"
3. 主角的解决方式是不解决："嘿嘿，留着其他人头痛去吧"

**这个机制的价值**：不需要外部敌人，主角自己的成果就会生产下一个问题。这是"日常成长文"能写到 500 章的核心动力。

**可迁移，但有一个硬条件**：漏洞必须是**读者自己能想到的**（水波、卫星、目击者）。如果漏洞是作者为了造麻烦硬编的，读者会觉得主角在自找苦吃。

**资源建设的写法（A 级，4 个样本）**：

| 章 | 资源 | 写法要点 |
|---|---|---|
| 9 | 破釜酒吧闭关 | 设定推演，不写打斗 |
| 181 | 蛇怪捕获 | 盯地图一整天 → 双人守走廊 → 箱子变形 → 收网 |
| 211 | 摄魂怪捕获 | 先否掉现成方案（守护神只能驱赶）→ 改造（一整团银光当布袋）→ 压缩成弹珠 |
| 358 | 空间基地雏形 | 定量规格（面积/体积）+ 失败与修正 |

**共性**：每个资源都有"要解决的具体不便"，都经过"检索已知做法 → 找缺口 → 改进 → 当场验证"。**胜利的爽感来自设计被验证，不来自力量对撞。**
