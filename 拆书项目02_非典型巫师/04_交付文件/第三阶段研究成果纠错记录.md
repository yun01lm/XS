### 纠错 06｜孔蒂、金铃的分类前后矛盾

| 项 | 内容 |
|---|---|
| **原始问题** | 专题B 把孔蒂/金铃放在"第0层 造物与非人"，5.2 又列为"只为主角服务的配角"；而《第三阶段执行总结》2.4 把她们放在"核心圈" |
| **错误原因** | 专题B 按"物种/关系亲疏"分类，执行总结按"关系层级"分类，两套维度混用，同一人被放进三个位置 |
| **修改方式** | 改用**多维标签**，允许一人多标签：身份维度（家养小精灵）／关系层级（服务型近侍）／功能维度（后勤+情报）／独立性维度（行动独立、目标部分独立） |
| **修改后结论** | 孔蒂/金铃 = 家养小精灵 + 服务型近侍 + 后勤功能 + **行动上独立**（272 章自行组织生日会）+ 目标不独立（以主角为中心） |
| **正文复核** | ✅ 272 章："孔蒂和金铃抬着一个巨大的蛋糕幻影显形在客厅里"——未经主角安排 |

## 三、绝对化判断类（6 项）

### 纠错 09｜"全书没有一个人是主角会主动去找的"

| 项 | 内容 |
|---|---|
| **原始问题** | 专题B 第八节："没有一个人是主角会**主动去找**的。他所有的关系都是'别人来找他，他回应'" |
| **错误原因** | 把"不主动寻求情感依赖"和"不主动接触"混成一件事 |
| **反例（已读章节）** | ① 193 章："赛恩斯**再次找到**校长先生"——主动去找邓布利多 ② 190 章："赛恩斯**再次与斯普劳特教授正式谈论**"——主动去找院长 ③ 186/190/374 章：他**反复在傍晚去海格小屋**（186："有几次赛恩斯傍晚过来竟然都没见到人"）④ 272 章：主动把冥想盆还给邓布利多 |
| **修改方式** | 拆成两层判断 |
| **修改后结论** | **主动接触：有，且频繁**（邓布利多、斯普劳特、海格、洛哈特都被他主动找过）。**主动寻求情感依赖：在已读 75 章内未见**。原表述把后者说成了前者 |
| **正文复核** | ✅ 四条反例章节均已读 |

### 纠错 10｜"没有背叛、没有决裂、没有和解戏"

### 纠错 11｜"孔蒂/金铃全书没有独立目标"

| 项 | 内容 |
|---|---|
| **原始问题** | 专题B 5.2 表格："无条件服务、因被使唤而幸福、磕头请罪。全书没有独立目标" |
| **错误原因** | 把"目标不独立"和"没有行动"混为一谈 |
| **反例** | 272 章：孔蒂与金铃**自行**抬蛋糕幻影显形到客厅、自行张罗生日会；272 章孔蒂主动承担 5 年照料 |

### 纠错 12｜"没有一位女性角色拥有与主角无关的剧情线"

| 项 | 内容 |
|---|---|
| **原始问题** | 专题B 5.2 末段，用于定性"女性角色处理是本书最弱一环" |
| **错误原因** | 把"有目标""有行动""能独立推动剧情""有不围绕主角的生活"四个不同层级压成一句 |
| **反例** | ① 262 章：安吉丽娜"对魁地奇的热情很高，以后很可能会想要进入正式俱乐部"——职业目标独立 ② 262 章：艾丽娅与安吉丽娜散场后"要回去想一想自己以后的就业方向"——主动规划 ③ 384 章：安吉丽娜为球队荣誉**当面怒斥双胞胎、并驳回主角的调解** ④ 262 章：艾丽娅的麻瓜出身就业困境，是主角**无法直接解决**的结构性问题 |
| **修改方式** | 按四个层级分别判断 |
| **修改后结论** | **有自己的目标：有**（安吉丽娜的魁地奇职业、艾丽娅的就业）。**主动采取行动：有**（384 章安吉丽娜的质问、262 章两人清点钱袋并签见证）。**能独立推动剧情：在已读章节中较弱**——她们的线没有产生独立事件。**有不围绕主角的生活：部分有**（魁地奇队内矛盾、就业焦虑），但都在主角视野内被叙述。原"没有一位"的判断**撤回** |

### 纠错 14｜"配角始终服从主角"

| 项 | 内容 |
|---|---|
| **原始问题** | 这一判断散见于专题B 的多个段落（如 5.2 的表述倾向） |

### 纠错 19｜备用方案被写成已执行手段（塞德里克相关）

|---|---|
