## 零、先给结论

**这本书的主角的"独立故事线"，不是另一条与原著并行的冒险线，而是一条"建设线"。**

他在原著主线之外修的东西是：**能力（魔法研究）→ 资产（空间柜、游船、基地一号）→ 空间（有求必应屋、霍格莫德的家、可自持的空间柜）→ 组织（家养小精灵、造物、朋友的事业）**。

原著主线对他的意义只有两个：**风险源**（伏地魔、摄魂怪、战争）和**时间刻度**（哪一年会发生什么）。

**他对原著的影响是点状的、延迟的、不公开的：**

| 他改变的 | 他未改变的 |
|---|---|
| 塞德里克·迪戈里没有到达迷宫中心（**是否"为救他"存疑，见 2.2 与复核意见**） | 伏地魔的复活（照常发生） |
| 赫敏·格兰杰的行动路线（SPEW 改目标） | 魔法部的腐败结构（被推翻，但方式粗暴） |
| 海格是否保住教职（失去，由主角接任） | 霍格沃茨之战的发生（照常发生） |
| 穆迪被抓的时机与方式（提前、无伤、由主角完成） | 战争的规模（甚至被主角放大到两千人死亡） |
| 金妮与日记本（提前解决，未伤人） | 哈利的成长路径（主角有意不干预） |

**本报告初稿曾把这件事概括为"他改的是代价，不是结局"。经独立复核（见 `03_子代理报告/第三阶段独立复核报告.md` C2），这个概括被撤回**，理由有三：

1. 支撑它的原文"现场的情况与原轨别无二致"，上下文只限定**取血仪式**这一环节，不是对全局的判断
2. 本场战役的实际改动很大：三名食死徒被石化、哈利被救走、穆迪被无程序处置并植入魔眼
3. "结局"这个词本身是研究者的框架，原文没有这层表述

**修正后的表述**：主角改变的是**具体事件的处理方式与代价分配**，且改动集中在"可以被隐蔽地处理"的部分；原著的主线骨架（伏地魔复活、战争爆发）保留不动。

这个判断的证据链在下面五层里逐层展开。

## 一、第一层：主角自身的目标

### 1.1 长期目标：不是"打败伏地魔"，是"不再受制于任何人和任何环境"

**【事实】** 主角的目标在文本中被反复表述为"研究魔法"与"活下去"，且这两者被同一套机制绑定：

- 他要研究魔法，是因为**只有理解魔法才能延长寿命**（第9章：闭关读完一到三年级必修课；第27章：决定"老老实实学标准咒语"，不越级）
- 他要活下去，是因为**中了黑魔法诅咒**（第2章，来自本项目中已读并记录的早期设定）

**【观察】** 从第9章的"读完一到三年级课本"，到第358章的"3.2 亿立方米土壤、80 米厚填土、自建降雨系统"，到第367章的"99 米长、巡航 100 km/h、赤胆忠心咒藏进灵魂"，到第517章的"飞向银河中心"——**同一件事做了 500 章：他在给自己造一个不受任何人控制的容器。**

容器清单（按出现顺序）：

| 阶段 | 容器 | 章节 |
|---|---|---|
| 一年级 | 有求必应屋（当实验室） | 24、27、28 |
| 二年级 | 霍格莫德的家（买房） | 70–72（目录层，未读正文） |
| 三年级 | 空间柜（消失柜改造） | 161、247（目录层）；358 为正文 |
| 四年级 | 冥想盆（自制品） | 271、299（目录层） |
| 五年级 | 空间柜二号（580m×2000m×2000m） | 358 |
| 六年级 | 基地一号（99 米船，赤胆忠心咒） | 367 |
| 战后 | 游船、飞船二号 | 266、513（目录层） |
| 终局 | 飞向银河中心 | 517 |

**【观察】** 这条线**完全不需要哈利波特存在**。把 HP 人物全部删掉，主角仍然会读书、造房子、造空间、造飞船。这是本书"独立故事线"的真正形态：**不是另一条剧情线，是一条资产线。**

> **【证据口径说明】** 上表中标注"目录层"的几行（70–72、161、247、271、513）**只有章节标题，未读正文**，仅用于说明"容器清单的顺序"，**不构成内容证据**。凡结论依赖具体内容的，只用已读章节：24、27、28、299、358、367、517（其中 **299 仅读第1页**，见档案 4.1 部分阅读清单）。

**【推断，B 级】** 这种设计对长篇日常文有效，因为它给"无事发生"的章节提供了进度条：读者看到的不是"他又过了一天"，而是"他的容器又大了一圈"。进度可量化（面积、体积、速度），所以不显得水。

**目标在后期增加了一项（V2 补入，复核 Agent 提供，主 Agent 未读）**

第469章，邓布利多昏迷不醒后，主角的目标从"造容器自保"扩展到**支配秩序**：

> "既然你们不愿意既定的规则运行，那就按照赛某人的规则来运行吧。**这个时代，该赛某人说了算了！**"

**这一项的重要性**：它说明"三项底盘（容器/长生/自主）"的说法不完整。第 469 章之后要加第四项——**秩序主导权**。而这一项是由一个配角的处境催出来的（详见专题C 3.4）。

**注意**：469 章是复核 Agent 读的，主 Agent 未读。本报告引用它时标明来源，**不冒充自己读过**。这一项在后续方法卡里若要使用，必须先补读 469 全文。

### 1.2 阶段性目标：由"风险"驱动，不由"使命"驱动

**【事实】** 主角每一次主动出手，前置条件都是"这件事会威胁到我"：

| 行动 | 触发理由（原文意思） | 章节 |
|---|---|---|
| 提前解决日记本与蛇怪 | 蛇怪在城堡里，**会威胁到他自己** | 181、193 |
| 捕获摄魂怪 | "机会难得，可不能让它给跑喽"——顺便完成研究任务 | 211 |
| 跟去墓地救哈利 | 哈利身上有他的护身符，且"你能进入比赛，怎么感觉都像是个阴谋" | 329、330 |
| 把塞德里克挡在迷宫中心外 | "塞德里克，不要怪我使手段，**我这是在救你**" | 328 |
| 对乌姆里奇动私刑 | 她正在审查他、威胁他的教职 | 362 |
| 决战屠杀两千人 | 他们已经来围攻霍格沃茨 | 492、494 |

**【观察】** 没有一次是"为了正义"或"为了救某人"而出手。作者甚至在第306章把这条原则写成明文：

> "如今的自己已经可以很自信地面对所有事了，对付老伏已经不是优先度最高的事情了，既然老邓头想要静观其变自己也没有理由非得上赶着去一线。"

**【推断，B 级】** 这是"非英雄型主角"能长期维持逻辑自洽的关键：**把出手理由全部降级为自保**。代价是主角无法承担"道德感召"类的剧情，全书也因此没有任何一次"为了别人牺牲自己"的桥段。

## 二、第二层：主角的行动方式——四种，且有明确边界

### 2.1 准备型（主力方式，A 级证据）

**【事实】** 三个跨年份的样本，结构完全一致：

| 章 | 目标 | 准备 | 动手 |
|---|---|---|---|
| 101 翻倒巷 | 采购违禁材料 | 踩点→判断风险→夜行衣+隐形衣+幻身咒+增高鞋+面具→选"常来但无人熟识的老女巫" | 夺魂咒采购→**消除魔杖痕迹** |
| 181 蛇怪 | 捕捉蛇怪 | 盯活点地图一整天→汤姆与杰瑞各守走廊一头→钛合金箱变成走廊模样→戴不透光眼镜留一道窄缝 | 蛇头进箱→收网→包住头→长杆锁链锁身 |
| 211 摄魂怪 | 捕获摄魂怪 | 想通"驱赶=放虎归山"→参考麦格的多守护神→发现"多个之间有空隙"→改用整团银光当布兜 | 罩住→压缩成玻璃弹珠 |

**【观察】** 三次的行动逻辑是同一句话：**问题定义 → 检索已知做法 → 找它的缺口 → 改进 → 当场验证**。这不是"战术"，是**工程思维**。胜利的爽感来自"设计被验证"，不来自力量对撞。

**原文锚点（181）**："预先做好计划，捉住一条大蛇，就是这么简单！"
**原文锚点（211）**："赛恩斯曾经就想过，用守护神去顶撞神魂怪只能把它们驱赶走，那岂不是在放虎归山。"

### 2.2 暗中操纵型（争议最大，但最有效）

**【事实，第328章】** 主角为了不让塞德里克跟去墓地，做了三件事，且**一件都没告诉塞德里克**：

1. 塞德里克身上有主角送的护身符（"遇险时会撑起一个铁甲咒"）
2. 远程启动迷宫内的魔法，**"塞德里克遇到怪兽的几率大大增加"**
3. 备有后手："若是那些怪兽不能阻挡他的话……**说不得就得**用混淆咒伺候了"（**备而未定**，不是已定方案）

原文："**塞德里克，不要怪我使手段，我这是在救你。**"

**【必须同时记录的三个反证（复核 Agent 指出，本报告初稿遗漏）】**

**反证一：护身符不是给他的专属保护，是主角的通用装置，而且是门钥匙。**

- 第328章主角"用手摸了一下脖子"，**塞德里克和哈利都点头会意**——两人各有一枚
- 第329章明说："赛恩斯送给哈利的那个护身符**也是一个门钥匙**"
- 第330章主角当场"接过来消除了它门钥匙的用途"
- **哈利戴着同一装置，照样被抓走。** 所以"护身符保护了塞德里克"这个读法，与"哈利戴着它仍被传送"直接冲突

**反证二：同章第2页给出了主角的真实优先级，与"救人"不同。**

> "若是现在把哈利救走，伏地魔要肯定要裂开，但是**这不符合赛某人的谋划**……就是为了让他成功复活。"

**反证三：328 全章没有一句提到"死亡"或"原著结局"。**"避免其原著中的死亡"是研究者用自己的原著知识补的。

**【修正后的分析】** 主角确实提高了塞德里克的存活率（这是事实），但"救你"是他**对手段的事后合理化**，不是唯一动机。同章明写的更高优先级是：**让墓地现场只有哈利一个勇士，以便复活按他的剧本走**。

因此本报告初稿"S1 是因果改写的核心动作"的定性需要下调：**它是"控制变量"的副产品，不是"救人"的主动设计。** 两种读法并存，本报告保留分歧不强行统一（见复核报告第四节）。

**【观察】** 无论动机如何，这个动作在伦理上都是最可疑的：他让塞德里克在迷宫里遭遇更多危险，**以降低他死亡的概率**；两个人的风险都被他单方面重新分配，没有征询任何一方。

**【推断，B 级（复核后降级）】** 初稿给 A 级，理由是"4 个独立场景（328、329、330、13）"。复核指出 328、329、330 是同一场战役的连续叙事，**不能互证**，13 章只是预叙。故降为 **B**。

它的写作价值仍然存在："不告知、不请求、单方面重新分配风险"比"直接拦住某人"高明，因为它保住了原著的紧张感（塞德里克确实在受苦），同时完成了改写（他没到中心）。但代价是主角的道德形象受损——而作者**没有为此设置任何后果**。

### 2.3 规则内交易型（少，但有效）

> **【纠错记录】** 本节原名"规则内**诉讼**型"。回查原文后改名：主角做的不是申诉/裁决，而是**用合规行为换资源**。见纠错记录 17。

**【事实】** 三个样本，全部是"交换"而非"申诉":

| 章 | 他做了什么 | 换到了什么 |
|---|---|---|
| 24 | 被麦格问"你是第一次施展变形术吗"，**如实承认**开学前已练习 | 换来警告而非惩罚 |
| 26 | 课堂提问 | 20 分 + 课后通道 |
| 315 | 用"给其他教授减负"的**公共理由**申请合班 | 实际动机是给自己省时间 |

**【观察】** 主角在**低风险场合**（课堂、教务）不做违规，而是**用遵守规则的行为去兑换资源**；在**高风险场合**（蛇怪、墓地、乌姆里奇）才走规则外路线。两条路线不混用。

**这个区分的写作价值**：它让主角的"算计"有了层次——不是"什么都敢干"，而是**先算清楚这件事该在哪套规则里解决**。学生对教授用规则内交易，对敌人用规则外手段，这条界线本身就是人物逻辑。

### 2.4 私刑型（后期出现，与前期自我约束冲突）

**【事实，第362章】** 主角审查结束后，当晚去乌姆里奇办公室：关门、定身（"如同被捏住脖子的鸭子"）、缴械（"首先当然是缴了她那短短的魔杖"），然后——

**不是威胁，是实际动手**：他挑出一根顺手的魔杖"麻花"，默念"钻心剜骨！"，乌姆里奇"被定住的身体开始剧烈颤抖……缩成一团，同时身下传来一股恶臭"。

口头部分只是前奏："我本意其实想看看把你一只胳膊放进火里烧焦的……恭喜你，乌姆里奇教授，你的手保住了。"

**【修正记录】** 本报告初稿写成"威胁烧手"，**失真**。复核 Agent 读到第2页，指出主角**实际施展了不可饶恕咒**。此处已改。

**【观察】** 同一章里，罗恩转述双胞胎的判断，点出主角的行为模式：

> "弗雷德和乔治说……赛恩斯从来不做没把握的事……你昨天把老蛤蟆赶出去都不一定是真生气，很可能是故意的。"

**【推断，B 级（复核后修正）】** 初稿把第362章定为"全书风格断裂的第一个可定位节点"。复核指出这个排序站不住：

- **更早的越界在 330 章**：主角石化穆迪后"变出一个夹子粗鲁地伸进眼眶把那只魔眼抠了出来"，洗清后**挖掉自己一只眼睛、把魔眼装进眼眶**，并自陈"我早就想这么干了"——无程序、无第三方、对活体不可逆处置
- **更早的前兆在 328 章**：遥控迷宫、给勇士配自制非法门钥匙、明知奖杯是门钥匙仍放任哈利被传送、在墓地按兵不动看着取血
- **第27章的自我约束本身带条件**：原文是"**在自己确实有一定水平之前**，还是老老实实的学习教材上的标准咒语"。它是一条临时性规矩，不是一个恒定逻辑

**修正后的判断**：不是"某章突然断裂"，而是**伦理阈值单调下移**：27（限用标准咒语，附条件）→ 328（隐蔽操控、放任）→ 330（无程序处置 + 自我身体改造）→ 362（私刑 + 钻心咒）→ 494（规模屠杀）。中间没有拐点。

**【保留的分歧】** 主 Agent 认为 330 的处置对象是敌人与自身，362 的对象是**同事**，性质不同，不宜简单按时间排序；复核 Agent 认为阈值是连续的。此分歧**不强行统一**，记录在复核报告第四节。

## 三、第三层：对其他人物的影响

### 3.1 改变他人选择的三个样本

**样本一：赫敏（第297章）——"从解放到改善待遇"**

**【事实】** 主角拆掉赫敏的 SPEW 路线，用的是"**先否定、再给方案**"，不是提问引导：

1. 先下判断："你的这个 SPEW 是**注定要失败的**！"
2. 中间插两句形式提问（"你有没有考虑过妖精发动过叛乱，但为什么小精灵从来没有叛乱过？"）
3. 但随后全部是单向讲授——他先给出"打破血脉魔法"这道无法逾越的门槛，再直接规定立场与目标："帮助他们获得魔杖使用权利什么的绝对不能说""保证家养小精灵获得合理的工钱和良好的工作环境"

**【修正记录，复核后改】** 本报告初稿把这一章写成"提问链说服"的典型样本。复核 Agent 逐段核对后指出：**全章只有两句形式提问，之后是单向讲授，且结论由主角直接给出**，与"不给结论"相反。此处已改。

**【观察】** 赫敏此后在本书中的路线确实改变了（后续章节未读，无法验证执行情况）。这是**主角改变原著人物行动方向**最清晰的一例，而且改的是"方法"不是"信念"——她的善意保留，路线被换掉。

**【反例记录】** 主角的话造成实际情绪伤害（"面色苍白""像是失去了精神支柱"），作者写出来了，但没有让主角因此收敛。

**样本二：海格（第314–315章）——"好意失效，主角接手"**

**【事实】**

1. 主角劝海格不要在马克西姆面前点破"混血巨人"身份（第314章）
2. 海格不听，且主角发现**自己的提醒被误解了**：他以为提醒的是"别说自己的私事"，海格理解成"别说小时候非法养危险生物"
3. 主角自我结算："是因为赛某人提醒的不够明确吗？……估计我就是直接告诉他不要提这一茬，他也是不会听的。如此说来，赛某人仍然无愧于'朋友'，即便因此顶了他的位子，也不能说赛某人不够朋友。"
4. 斯基特报道出街（1995年1月1日《邓布利多的重大失误》）
5. 海格失去教职，**主角接任保护神奇动物课教授**（第315章）

**【观察】** 这是全书**唯一一次完整的"主角计划失效"链条**：行动 → 沟通失败 → 第三方利用 → 结果恶化 → **主角反而获益**。因果方向对主角有利，对海格不利。作者没有回避这个尴尬，但也没有追究。

**【推断，B 级】** 这个链条比"主角救人成功"有价值得多，因为它让主角的"算计"有了成本。可迁移的写法：**让主角的好意因为信息差而失效，并让失效的后果落到别人头上**——这比"主角判断失误害了自己"更真实，也更难写。

**样本三：塞德里克（第328章）——"被挡住但不知情"**

**【事实】** 主角用暗中手段把塞德里克挡在迷宫中心外（见 2.2）。原文预叙（第13章）：

> "完美者大多都结束的不怎么完美，他在三强争霸赛最后结束的时候中了一发阿瓦达啃大瓜。"

第328章之后，这个预叙**没有兑现**：塞德里克没有到达奖杯。但**注意两点**：
- 328 全章没有一句提到"死亡"或"原著结局"，"救他命"是研究者根据第13章预叙做的推定
- 主角自陈的动机（"我这是在救你"）与同章给出的更高优先级（让墓地里只有哈利一人）并存

**【观察】** 主角与塞德里克的关系在第301章有一处细节：塞德里克在公开场合统一改称"奥特姆助教"，主角纠正"你以前都叫我赛恩斯的"，塞德里克当场改回"对不起，赛恩斯"。**关系表面没变远，只是职衔在公开场合产生了语用摩擦**；而主角在暗中为他改命这件事，没有任何一方知道，也没有在第328章之后被处理。

### 3.2 没有被他影响的人

**【事实，第306章】** 主角明知课堂上的"穆迪"（正文未点明其为小巴蒂·克劳奇，"假"为研究者据原著补的外部信息）会在课堂上用纳威演示钻心咒、会借课堂满足施虐快感，仍然选择不管：

> "既然老邓头不准备动他，赛恩斯也乐得轻松，有那时间研究一下冥想盆的缩小项目岂不是更好。"

**【事实，第306章】** 主角对"不干预"的三重理由：尊重邓布利多的判断、自己已无迫切需求、**"救世主少了几次锻炼机会，现在让他多一些锻炼也好，有些事情注定是要他亲自去面对的"**。

**【观察】** 这三条理由是全书解释"同人主角为什么不改原著"最关键的文本。它的结构是：
- 把"不干预"包装成**对他人的尊重**（邓布利多的判断、哈利的成长）
- 把"干预"限定在**自己不受损**的范围内

**【推断，B 级】** 这套逻辑在写作上极其有用（它让主角可以合理地在场而不动手），但它有一个代价：**主角的道德主动性被严格限价**。

**【纠错记录】** 本段第三阶段原文写"全书因此没有任何一次'主角为了别人冒自己不愿冒的险'"。该表述绝对化，且与已读章节冲突，**已撤回**。反例：

| 章 | 他做了什么 | 风险 |
|---|---|---|
| 329 | 隐身进入墓地，在伏地魔与虫尾巴面前救走哈利 | 被发现即正面冲突（他当时没有必胜把握） |
| 314 | 主动提醒海格，等于插手邓布利多的人事 | 得罪海格，也可能得罪邓布利多 |
| 262 | 出资一千加隆，"即便真的亏本了……算是对朋友的一点帮助" | 金钱损失（对他不大，但是真实支出） |

**修正后的表述**：他**愿意承担风险，但风险上限被严格计算**——救哈利前先确保"不给魔法部留把柄"、备好护身符、有退路；提醒海格用的是"暗示"而不是"明说"，保留了不认账的余地。已读章节里未见的是**无退路、无收益的纯粹利他冒险**，而不是"不作任何冒险"。

## 四、第四层：对事件因果的影响

### 4.1 三强争霸赛这条线：改了什么，没改什么

**【事实】** 按事件顺序列出（全部为本项目实读章节）：

| 环节 | 原著 | 本书 | 章节 |
|---|---|---|---|
| 哈利被选为勇士 | 有人做手脚 | 同（主角知道是阴谋，不阻止） | 292、295 |
| 学生站队 | 徽章、孤立 | 同（主角只做了本宿舍的思想工作） | 295、292 |
| 第一个项目 | 各显其能 | 同（主角在观众席做技术分析，未干预） | 304 |
| 第二项目 | （未读） | （未读） | — |
| 第三个项目 | 塞德里克与哈利同抓杯，同去墓地，塞德里克被杀 | **塞德里克被怪兽与铁甲咒拖住，未到中心；哈利独自被传送** | 328 |
| 墓地 | 哈利独自面对，塞德里克尸体被带回 | 主角全程隐身跟随，**提前通知邓布利多**，切割咒救下哈利，石化三名食死徒 | 329 |
| 伏地魔复活 | 复活 | **照常复活**（"现场的情况与原轨别无二致"） | 329 |
| 返回 | 哈利带尸体回校 | 主角带哈利幻影显形回禁林，**顺手把奖杯召唤走** | 330 |
| 穆迪（正文未点明其为小巴蒂，"假"为研究者外部信息） | 被邓布利多一方揭穿，差点逃走 | **主角提前藏在门厅拐角，一个石化咒放倒，加绳索与锁舌咒；随后抠出其魔眼并植入自己眼眶** | 330 |

**【观察】** 这是全书**最完整的一次因果改写**，且改写方式极有讲究：

- **主事件不动**：伏地魔照样复活
- **人命被改写**：塞德里克没到中心
- **执行者被替换**：抓穆迪的人从"邓布利多一方"换成"主角一个人，提前，无伤"
- **代价被增加而非减少**：三名食死徒被石化、穆迪被无程序处置并致残

**【推断，B 级（复核后由 A 降级）】** 初稿给"A 级（4 个独立场景：328、329、330、13）"。复核指出 328/329/330 属**同一场战役的连续叙事，按规则不能互证**，13 章只是预叙，故降为 **B**。

保留下来的判断是：本书处理同人因果的**偏好**是——保留原著主事件的骨架，把改动集中在"可以被隐蔽处理"的部分（某个人的生死、某个人的处置方式），而**放弃**"公开改变历史走向"。这个偏好在 328–330 三个连续章节内成立，是否贯穿全书未验证。

### 4.2 二年级蛇怪线：改了什么

**【事实，第181章】** 主角在万圣节当晚用活点地图盯金妮，用钛合金箱诱捕蛇怪，"预先做好计划，捉住一条大蛇，就是这么简单"。

**【事实，第193章】** 章名"不装了，摊牌了"，但**摊牌的内容不是"日记本来历"**——全章前 2/3 是寒暄、斗嘴、申请跳级，第 2 页才由主角抛出一句反问：" **教授，您觉得，那个日记本真的只有这一个吗？** "邓布利多"一下站了起来，挤的办公桌往前移动了一大截"。

**【修正记录】** 本报告初稿写"第193章他向邓布利多摊牌，说明日记本来历"，**与正文不符**，已改。日记本的来历在本章并未交代，主角抛出的只是"还有别的"这一暗示。

**【事实，第495章（回述）】** 主角在战后向朋友复盘：

> "说（他）如何发现了金妮韦斯莱的不对，如何发现城堡里有一条蛇怪潜伏，如何从金妮身上找到了一件邪恶非常的日记本，又是如何确认了日记本的身份，继而如何推测出伏地魔没有死的真相。"

**【观察】** 蛇怪线被完整改写：**没有学生被石化、金妮没有被掳进密室、哈利没有下去、洛哈特没有被记忆咒反噬**。主角把一次"校园危机"降级为"一次捕获作业"。

**【事实，第184章（本阶段新读）】** 具体受益人第一次被点名：

> "蛇怪已经被赛某人团成团了，也就不存在后续的科林被石化事件了。**救下了一个有可能在'不巧合情况'下丧命的小巫师**，他表示自己功德无量。"

同章还写下了一句被作者反复援引、但**并未贯彻**的说法："没有外力干涉，后续的事情仍如原轨迹一般发展。哈利·波特……仍然暴露了他蛇佬腔的身份！"

**【V2 修正】** 初版把这句当"总规则"。复核 Agent 用 463/464（邓布利多没死、伏地魔断手）、472（马尔福庄园被烧、近二十人死亡）证明它不成立，且同一章内作者自己就在质疑"剧情修正力"。详见 5.3 节"总规则？——不成立"。

**【事实，第263章（本阶段新读）】** 主角改写带来的**二级后果**被叙述者直接说明：

> "去年赛恩斯早早解决了密室里的蛇怪，魁地奇比赛没有被取消，格兰芬多已经夺过一次冠军了。"

**这条链完整且可追溯**：捕蛇怪（181）→ 无石化事件（184）→ 魁地奇未取消 → 格兰芬多夺冠 → **伍德的毕业履历改变**（263）。这是全书目前最干净的"主角→原著"因果链，不需要任何推断。

**【推断，B 级】** 这条线的改写比三强线更彻底（连过程都换了），但也更"无痛"：因为没有任何人受伤，读者失去了原著的恐怖感。**改写越彻底，原著的张力损失越大**——这是同人写作的核心取舍。

### 4.3 若删除主角，哪些事不会发生

按项目已读章节可确认的清单：

| 若没有主角 | 依据章节 | 证据性质 |

## 五、第五层：独立剧情是如何形成的

### 5.1 独立剧情的三种来源

**来源一：研究课题（最常见）**

**【事实】** 主角的每一个研究课题都会长成一个事件：

| 课题 | 已验证的部分（有正文） | 章节 | 未验证的延伸（无正文，**不得当证据**） |
|---|---|---|---|
| 蛇怪的生理结构 | 捕获蛇怪 → 科林未被石化 → 与邓布利多摊牌 | 181、184、193 | 魂器线的完整处理 |
| 摄魂怪的本质 | 捕获摄魂怪（用一整团银光当布袋压缩成弹珠） | 211 | 研究灵魂 → 魂器处理技术（440 未读，引用已删除） |
| 空间拓展 | 两个消失柜 → 空间柜 → 基地一号（99 米）→ 空间柜接入船上研究室 | 180、186、358、367 | 飞船（511 只提到"旻兵"） |
| 记忆抽取 | 自制冥想盆：卡点 → 推翻前提 → 换问题 | **272、299**（299 只读第1页） | 记忆宫殿、记忆备份 |

> **【纠错记录】** 本表在第三阶段曾把"440（未读）""299（未读）"并列进证据栏。第四阶段实读 299 第1页，证实"自制冥想盆"这条线存在，同时把"记忆宫殿/记忆备份"移入未验证栏；440 章仍未读，引用**删除**。详见 `第三阶段研究成果纠错记录.md` 纠错 15、16。

**【观察】** 这是本书"独立剧情"的生成机制：**研究课题 → 技术能力 → 更大容器 → 更高层级的冲突**。它不依赖原著事件驱动，所以能一直写下去。

**来源二：造物与非人角色**

**【事实，第166章】** 主角画了两个画像：汤姆（管家型）与杰瑞（剑客型），并用一场"误会斗剑"让他们认识。第367章出现了"旻学"（基地一号的船灵）。第511章提到"旻兵"（飞船二号的智能核心）。

**【观察】** 主角的人际需求被**部分转移到了造物身上**：他给画像安排工作、给船安排性格、给智能核心安排后路（"旻兵就是他的后路"）。番外评论（第4条搜索结果，非正文）中也提到读者对此的评价："主角让一些自己做的魔法生物叫自己老爷……感觉就像主角一个好好七情六欲的人脱离情感"。

**【推断，B 级】** 这是本书**最不可复制**的设定：主角能造出有性格、能成长、能陪他几百年的造物。它解决了"长生者的孤独"这个主题，但也让主角与真实人物的关系始终停留在表层。

**来源三：朋友的事业**

**【事实】** 主角出资一千加隆给双胞胎开店（265）；本辞职开食品店（509、511）；亚当开书店（509）；艾丽娅管魔法灯事业并嫁给乔治（511）；主角把朋友的孩子都收作证婚人（511）。

**【观察】** 主角对朋友的支持方式是**投资 + 不干涉**：他对双胞胎说"我只负责出钱，其他的一概不管"（265）。这让他既维持了关系，又不必投入时间。

### 5.2 两条线如何交织

**【观察】** 交织点只有三个：

1. **原著事件成为原创剧情的推力**：斯基特的报道（原著事件）→ 海格失职 → 主角接任教授（原创剧情）
2. **原创能力改变原著事件的处理方式**：主角的钛合金变形 → 蛇怪被"作业化"处理；主角遥控迷宫 + 自制门钥匙 → 塞德里克未到中心（**不能写成"护身符保护了他"：护身符是通用装置且是门钥匙，哈利戴同一装置仍被抓走**）
3. **原著人物进入原创空间**：朋友来霍格莫德的家做客（301）、来参加生日会（502）、来参观基地（367 之后的章节未读）

**【推断，B 级】** 交织密度**偏低**。在已读 75 章里，两条线大部分是**互斥推进**（这一章要么推进原著、要么推进原创），同时推进的完整样本只有第 314–315 章一处。

**这带来的结构后果**（对文本的客观描述，非读者反馈）：单章的**压力源只有一个**。读者不会在同一章里同时操心"海格会不会完蛋"和"基地会不会出问题"，于是每章的张力上限被压低。这是节奏问题，不是文笔问题。

> **【纠错记录】** 本段第三阶段原文写"这也是本书被读者说'水'的结构性原因"。本项目**未采集任何读者评论**，该表述无据，已删改为对文本结构的陈述。见纠错记录 18。

### 5.3 反向：原著线如何影响原创线（本阶段新增）

第三阶段只写了"主角→原著"。本阶段补反向，按可信度分三层。

**第一层：正文明确写出的（A 级）**

| 原著事件/人物 | 对原创线的具体影响 | 章节 |
|---|---|---|
| 蛇怪被提前解决 | **魁地奇比赛未被取消** → 格兰芬多多拿一次冠军 → 伍德的毕业履历改变 | 263（叙述者直述） |
| 乌姆里奇任校长并派调查组 | 双胞胎被禁赛 → 决定辍学 → 把恶作剧材料运进学校 → 皮皮鬼有了"供货商" | 384 |
| 乌姆里奇审查教职 | 主角对她动手（362–365），**这条原创暴力线完全由原著人事引发** | 361–365 |
| 海格被斯基特曝光 | 主角接任保护神奇动物课教授 → 获得教职身份 → 后续 315、362 的"教授"身份合法性来源于此 | 314–315 |
| 食死徒越狱 | 主角把注意力从 DA 转向"神秘事务司一网打尽"的计划 | 381 |

**第二层：可从正文合理推断的（B 级）**

- **原著事件给主角提供了"时间表"**：他反复以"哪一年会发生什么"来安排研究进度（如"神秘事务司一战是很确定的"，381）。
- **原著人物的存在改变了他的成本计算**：因为要和邓布利多共事，他克制了杀意（329："若非想着以后还得与老邓头共事，刚才那三个人肯定不只是被石化"）。

**第三层：不能确认的（C 级）**

- 原著事件是否**推迟或取消了**他的某些研究计划——已读章节里没有明确记录，只能说"他的计划里有为原著事件预留的档期"。

**一条总规则？——不成立（V2 修正）**

第184章第2页，叙述者确实写下了这句话：

> "**没有外力干涉，后续的事情仍如原轨迹一般发展。**"

我初版把它当作"本书处理同人因果的总规则"。**复核 Agent 证伪了这个提法**：

| 章 | 事实 | 打穿了什么 |
|---|---|---|
| **463／464** | 邓布利多**没死**（原著里死了），伏地魔被切掉一只手、丢了魔杖 | "原轨回归"不成立，偏差**不可逆** |
| **472** | 马尔福庄园被厉火烧毁、近二十人死亡 | 同上，且规模巨大 |
| 184（同章内） | 叙述者先断言"根本就没什么'剧情修正力'"，几页后又惊问"怎么地？'剧情修正力'这么牛逼的吗？" | **作者自己没把这句话当法则** |

**修正后的模型：单向套利。**

复核 Agent 的提法（接受）："原著线提供**时间表和信息差**，主角据此下注；他不动的地方看起来'照原轨迹'，他动过的地方（岩洞、马尔福庄园、邓布利多的命）就永久分叉。"

**这个解释的证据非常硬**（两章，主 Agent 此前未读）：

- **209 章**：主角**刻意维护**原著节点——"之所以没在前些年把老鼠揭破……就是想着要等小天狼星越狱，好让摄魂怪跟出来"
- **417 章**：明知邓布利多会去岩洞喝药，仍决定"且不去管它"，理由是"实在说不清赛某人是怎么知道山洞的事情的"

**这两条合起来给出一个更冷的结论**：原著之所以"照原轨"，**不是宇宙有修正力，而是主角捂着信息不动手**。所谓"历史惯性"，是他的策略，不是世界的规律。

> **【纠错记录】** 初版把 184 章一句叙述者议论升级成"全书总规则"。复核推翻，已改。这是本项目**第二次**犯"拿一句好话当规律"的错（第一次是第三阶段的"与原轨别无二致"）。见复核报告 C4。

## 六、可直接迁移的方法（附适用条件）

### 方法 A-1：给主角一条"资产线"，而不是第二条"冒险线"

**研究依据**：第9、27、358、367、517章（同一件事做了 500 章：造容器）
**解决的问题**：日常章没有进度感，读者觉得"又水了一天"
**具体机制**：把主角的长期目标物化为**可量化、可扩建、有明确规格**的东西（面积、体积、速度、容量），每章推进一小格
**执行步骤**：
1. 给主角一个"容器"需求（实验室／住所／藏身处／交通工具）
2. 明确定量规格（如"580 米高、2000×2000 米底"）
3. 每 5–10 章推进一个子系统（土壤→水源→天气→热源）
4. 每个子系统都要写一次**失败与修正**（"因为计算错误，导致局部土壤液化"）
**注意事项**：规格数字必须有上限感，否则会滑向"无限变强"
**常见错误**：只写"他又扩建了"，不写工程量与失败，读者无感
**检查标准**：读者能不能说出"他的基地现在多大、还缺什么"？

### 方法 A-2：复刻骨架，重写代价（初稿称"改变代价，不改变结局"，已修正）

**研究依据**：第328、329、330章（塞德里克未到中心、伏地魔仍复活、食死徒被石化、穆迪被无程序处置）
**证据等级**：**B**（328/329/330 是同一场战役的连续叙事，按规则不能互证）

**解决的问题**：同人改写要么不敢动原著（主角成旁观者），要么改得太多（原著失去意义）

**具体机制——按 329–330 实读内容分项列出，不再作整体概括**：

| 环节 | 本书处理 |
|---|---|
| 取血仪式 | **复刻原著**（"现场的情况与原轨别无二致"，指虫尾巴只取了一点血） |
| 哈利是否独自面对 | **改变**：主角全程隐身跟随，用切割咒救下哈利 |
| 食死徒 | **改变**：三名被石化（主角自陈"刚才那三个人肯定不只是被石化"是有意克制） |
| 穆迪 | **改变**：主角抢先石化、缴械、抠出魔眼并植入自己眼眶 |
| 邓布利多到场时机 | **改变**：被提前叫来 |
| 塞德里克是否到达奖杯 | **改变**：被怪兽与障碍拖住 |

**执行步骤**：
1. 列出原著场景里的每一个环节，而不是只有"结局"
2. 决定哪些环节必须复刻（通常是**读者记忆最深的那一个动作**），其余全部重写
3. 重写部分要隐蔽执行（暗中手段、事后不解释），避免大段说明
4. 被改动的人**不必知道**自己被改动

**注意事项**：不能宣称"结局没变"——本书 329–330 除了取血环节，其余几乎全部被改。把一句**局部限定语**推广成"改代价不改结局"的框架，是本项目初稿犯过的错误，此处留作警示。

**常见错误**：让主角当众宣布"我救了你"，把隐蔽改写变成公开功绩

**检查标准**：能否逐项列出"哪些环节复刻、哪些被重写"？只能回答"结局没变"说明拆得不够细。

### 方法 A-3：让主角的"不干预"有三重理由

**研究依据**：第306章（邓布利多的判断／自己无需求／救世主需要成长）
**解决的问题**：主角明明有能力却不出手，读者会觉得作者在拖
**具体机制**：给"不作为"配三层理由——**尊重他人判断 + 自身利益无关 + 对方需要成长**
**执行步骤**：
1. 先让主角确认"主导者"的态度（邓布利多要静观其变）
2. 再让主角确认自己没有迫切需求
3. 最后给"对方需要亲自面对"一个具体理由
4. **同时写出这套逻辑的漏洞**（主角明知纳威会被当众演示钻心咒而不管）
**注意事项**：三层理由不能只写两层，否则像偷懒
**常见错误**：用"主角相信命运"一句话带过
**检查标准**：读者能否复述出主角不插手的三个理由？

### 方法 A-4：好意因信息差而失效，代价落到别人头上

**研究依据**：第314章（提醒被误解 → 海格曝光 → 主角接任）
**解决的问题**：主角的算计永远成功，人物失真
**具体机制**：让主角的提醒**指向模糊**，被对方按自己的焦虑解释，再由第三方利用
**执行步骤**：
1. 主角给出一个"正确但不具体"的警告
2. 对方按自己最在意的事去理解
3. 第三方（记者、对手）利用这个误解
4. 后果落到对方身上，主角**反而获益**
5. 主角自我免责，但免责过程被完整写出（让读者自己判断）
**注意事项**：这种失败不能太多，一部书 2–3 次足够
**常见错误**：让主角事后反省并道歉，把复杂性抹平
**检查标准**：读者会不会觉得"主角有责任但他不承认"？会，就写对了

### 方法 A-5：把研究课题长成事件

**研究依据**：第181（蛇怪）、211（摄魂怪）、358（空间）、28（记忆）
**解决的问题**：研究型主角的章节全是设定，没有事件
**具体机制**：每个课题都必须有一个**可捕获／可建造／可测量的产物**，产物再引出下一层冲突
**执行步骤**：
1. 课题必须有"要解决的具体不便"（蛇怪威胁安全／摄魂怪抓不住／空间不够）
2. 研究过程要写出**检索已知做法 → 找缺口 → 改进**
3. 结果必须是一次**可验证的现场测试**
4. 测试成功后立刻给出**新问题**（抓到了摄魂怪，然后研究灵魂）
**注意事项**：一个课题不要跨超过 20 章，否则读者忘记前因
**常见错误**：写成"他研究出了新咒语，威力很大"，没有过程
**检查标准**：能不能用三句话说清"他要解决什么、卡在哪、怎么绕过去"？
