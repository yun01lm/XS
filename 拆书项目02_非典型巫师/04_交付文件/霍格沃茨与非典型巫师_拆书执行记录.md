## 四、子 Agent 使用说明

**本次未启用子 Agent。** 原因：

1. 六类子 Agent 需要基于**同一份正文**工作，而正文获取本身是瓶颈（分批抓取、繁体、ID 映射未打通）
2. 子 Agent 返回的是**摘要**，会丢失可引用的原文片段，反而削弱证据链
3. 若派子 Agent 各自抓取，会产生大量重复请求，且彼此无法核对同一段落

**替代方案**：主 Agent 统一直读、统一记证据笔记，保证"结论—章节—原文"三者可追溯。

**代价**：缺少第二方独立核验。此风险已写入研究档案第七节第 5 条。
