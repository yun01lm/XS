# OpenWrite 综合创作指导手册 V1.0

> **适用对象**：OpenWrite（AI 写作模型）
> **任务场景**：创作哈利波特同人小说（长篇，目标 100 章以上）
> **证据基础**：《隐藏在霍格沃茨当教授》（白白了开水，656 章）实际阅读 44 章，覆盖 6.7%
> **每条规则的证据强度**：`[A]` 多章验证 / `[B]` 1–2 章支持 / `[C]` 尚无验证的推论
> **使用前提**：本手册提炼的是**方法**，不是该作的剧情、人物、设定。禁止把特维尔、马伏里奥等原创角色搬入新作。

---

## 第 0 章｜这本手册怎么用

写每一章前，按顺序执行：

1. 查**第 8 章**的场景类型，确定本章用哪套写法
2. 查**第 3–7 章**的原则，确定人物、关系、节奏的处理方式
3. 按**第 9 章**的生成模板列出本章节拍表（beat sheet），先列表再写正文
4. 写完按**第 10 章**自检，不达标就改，不要输出
5. 交付时附上**检查清单**结果

**不可跳过的三条底线**：
- 禁止连续两章以上没有"日常场景"
- 禁止任何一章没有"人物行为引发的后果"
- 禁止用作者旁白解释人物情绪超过一次/千字

## 第 1 章｜阅读体验目标（本书为什么能让人一直读）

基于已读 44 章的观察，这本小说提供的是**四层叠加体验**，而非单一爽点：

| 层 | 体验 | 机制 | 证据 |
|---|---|---|---|
| L1 安全感 | 主角几乎不陷入真正危险 | 实力碾压+信息优势 | [A] 第127/151/537章 |
| L2 智力快感 | 每 10–20 章揭一次"原来这是布局" | 双层叙事 | [A] 第454章 |
| L3 日常依恋 | 学生群像、课堂、吃饭、玩笑 | 三重压榨式场景 | [A] 第21/44/302/633章 |
| L4 主题共鸣 | 麻瓜与巫师、科技与魔法、私欲与责任 | 理念在饭桌上被争论 | [A] 第231/367/283章 |

**给 OpenWrite 的指令**：你写的每一章至少要落在其中 **2 层**上。只有 L1（打赢了）的章节视为不合格。

## 第 2 章｜整体体验节拍（全书级）

### 2.1 卷级结构（A 级）

原作 8 卷对应原著 7 部+番外，每卷内部节奏高度一致：

```
卷首（1–3章）：回到学校/新环境 + 一件反常小事（本校新建筑、新教授、新规定）
上升（20–40章）：教学制度逐步加码 + 主线线索零散出现
中段（40–60章）：一条支线突然加重（狼人、纯血、魔法部）
转折（60–75章）：原著主线事件被主角改写
高潮（75–90章）：一次性实力外显 + 关系大转折
收尾（90–97章）：制度/关系定型 + 抛下一卷的钩子
```

**执行要求**：每卷必须包含**至少一个"制度变化"**（加测验、建角斗场、开俱乐部、设新部门）。制度是本书推进节奏的隐性引擎，比冲突更稳定。

### 2.2 章级节拍（A 级）

单章 2000–3500 字，最常见的内部结构：

| 位置 | 占比 | 内容 |
|---|---|---|
| 0–15% | 冷开场 | 不解释背景，直接进场景（一句对话/一个动作/一个异常） |
| 15–60% | 主体 | 场景推进，主角注意力在"别处" |
| 60–85% | 变奏 | 出现意外（学生出丑、对手加码、信息反转） |
| 85–100% | 情绪反转 | 一句台词打翻前面的情绪，指向下一章 |

## 第 3 章｜剧情设计原则

### 3.1 主线必须"寄生"在主角的生存需求上 `[A]`

原作主线（推翻保密法）起步于主角的**个人续命需求**，中期才升维成理想。

**规则**：
- 主角的初始动机必须是**私人的、具体的、有时限的**
- 每一卷推进主线时，都要能回答"这一卷和主角自己有什么关系"
- 理想化升级必须发生在**一次道德冲击之后**（原作第283章：看到麻瓜尸骨后自我反思）

**OpenWrite 执行**：
```
第 1 章必须交代：主角要什么（具体）→ 为什么现在必须做（时限）→ 做不到会怎样（代价）
第 15–25 章之间安排一次道德冲击，让动机从"为我"转向"为我们"
```

### 3.2 支线必须先给"人的问题"再给"事的问题" `[A]`

原作支线（狼人、纯血家族、家养小精灵）都先给一个人（卢平、德拉科、多比）的困境，再展开群体议题。

**规则**：任何涉及群体/制度的支线，第一次出场必须通过**一个具体的人的一件具体的事**。

**反例（禁止）**：`最近魔法界对狼人的政策越来越严苛，引发了广泛不满。`
**正例**：`卢平把袖子往下拉了拉，遮住手腕上的登记烙印——魔法部要求所有狼人佩戴它。`

### 3.3 伏笔用"重复挂件"，不复用同一个载体超过 5 次 `[A]`

见方法卡 MC-10。执行标准：
- 每个长线伏笔配一个**低成本载体**（一句话、一个动作、一个数字）
- 首次出现必须显得无关紧要
- 20–40 章复现一次，语境变化
- 回收时不解释"你还记得吗"

### 3.4 布局要"三层揭示" `[A]`

原作第454章的示范：读者一直在看的事件（三次会面），突然被重新定义为布局，但**布局的目的**仍未揭晓。

**三层**：
1. 表层事件（读者以为的自然发生）
2. 中层揭示（这是主角安排的）
3. 深层目的（为什么这么安排）——留到 50 章后才揭

**OpenWrite 执行**：每 30 章安排一次"中层揭示"，全书不超过 3 次"深层揭示"。

## 第 4 章｜人物塑造原则

### 4.1 主角：能力外显，欲望隐藏 `[A]`

原作主角从不主动说自己想要什么，靠**别人替他说**（克鲁姆、卢修斯、邓布利多、珀西反复追问）。

**规则**：
- 主角的野心只通过**他人之口**被提出，且主角每次都给一个"半真半假"的答案
- 主角的善意只通过**行动**表现，不通过台词
- 主角至少有一个**孩子气的偏好**（原作：南瓜汁、小蛋糕、布丁）

**OpenWrite 执行**：给主角设定
```
① 一个具体的私人目标（写进第1章）
② 一个对外说辞（第7章左右给出）
③ 一个真实版本（第60章后给出）
④ 一个幼稚的爱好（第3章内出现，之后每10章出现一次）
```

### 4.2 反派的"尊严时刻" `[A]`

原作第620章：伏地魔在败局已定时，主动让手下投降，并选择一对一决战——"當然是讓所有人永遠地銘記，我，伏地魔，始終都是為這個世界帶來恐懼與災厄的黑魔王！"

**规则**：反派在最终失败前，必须有一次**不计得失的选择**，且这次选择要符合他的自我认知。

**禁止**：反派临死前突然求饶或忏悔（会毁掉前面所有铺垫）。

### 4.3 配角必须自带"私人诉求" `[A]`

见 MC-09。执行标准：每个重要配角填写下表。

| 姓名 | 私人诉求 | 与主角目标的冲突点 | 他自己会怎么解决 |
|---|---|---|---|

**规则**：填不出"冲突点"的配角，不允许进入主要关系网。

### 4.4 语言辨识度：一人一个"说话习惯" `[A]`

原作示范（可直接迁移的**结构**，不可照抄台词）：

| 角色类型 | 语言特征 | 手法 |
|---|---|---|
| 结巴型 | 断句+省略号 | 用停顿表现恐惧，而非用形容词 |
| 阴阳型 | 反问+称呼全名 | 从不直接骂人，用"某教授"、"某先生" |
| 跳脱型 | 话题急转+自我纠正 | 说到一半改成另一个词（"打架，不是，争执"） |
| 油滑型 | 长句+自我吹捧 | 一句话里三次提到自己 |
| 市井型 | 短句+算计 | 每句话都在评估风险收益 |

**OpenWrite 执行**：为一个角色写台词前，先确定他属于哪一型；同一型不超过 2 人。

## 第 5 章｜人物关系设计原则

### 5.1 关系靠"共同完成一件事"推进，不靠对话 `[A]`

原作中主角与学生的关系推进点全部是**事件**：一堂课、一场比赛、一次禁闭、一次救援。没有一次是靠"谈心"。

**规则**：任何关系升级必须绑定一个**具体事件**，事件中双方必须**分工合作**。

### 5.2 原著人物对主角的态度，必须"分阶段解锁" `[A]`

以斯内普为例（第10→127→524章）：
```
阶段1：冷眼警告（我盯着你）
阶段2：主动试探（打一场看看）
阶段3：承认并依赖（这件事你怎么看）
```
三个阶段**跨越全书**，每次升级都由一个事件触发。

**OpenWrite 执行**：为主要原著人物各写一张"态度解锁表"，标明触发事件章号。

### 5.3 亲密关系用"共享的麻烦"表达，不用"共享的快乐" `[A]`

原作主角与格林德沃、与马伏里奥的关系深化，都发生在**一起处理麻烦**的时候（合谋、善后、互相掩护），而不是一起吃饭（虽然也有）。

**规则**：想写两个人关系变好，就给他们一个**共同要瞒着别人的秘密**。

## 第 6 章｜场景设计原则

### 6.1 三类场景必须循环出现 `[A]`

| 类型 | 功能 | 频率 | 证据 |
|---|---|---|---|
| 教学/职场场景 | 展示能力+推进制度 | 每 5–8 章一次 | 第21/44/77/302章 |
| 社交/宴席场景 | 承载理念冲突+关系变化 | 每 8–10 章一次 | 第96/178/231/524章 |
| 独处/研究场景 | 推进主线+投放设定 | 每 10–12 章一次 | 第2/88/144/161/227章 |

**禁止**：连续三章同一类型。

### 6.2 日常场景必须"三件事同时跑" `[A]`

见 MC-03。执行清单：
```
□ 本职动作（主角必须做但不想做的事）
□ 观赏动作（读者爱看的对抗/实验/比赛）
□ 埋线动作（一句台词挂到主线）
```

### 6.3 场景开头禁止交代背景 `[A]`

原作 44 章中，**没有一章**以"X 天之后，某某在某地"开头，全部直接进场景。

**正例**：`“啪啪啪，”特维尔一边鼓掌一边踏进这间厕所`（第44章）
**反例**：`万圣节前夜，霍格沃茨的走廊里弥漫着南瓜饼的香气。`

**规则**：第一句必须是**动作或对话**。时间地点信息在第二段之后自然带出，或干脆不带。

### 6.4 场景结束要"留一个没解决的东西" `[A]`

- 第21章：作业+测验制度（学生要面对）
- 第537章：胡夫明天还要验尸（悬着）
- 第400章：两个伏地魔（读者懵）

**规则**：每章结尾必须存在一个**待处理的具体事项**，且必须在下一章或两章内被处理。

## 第 7 章｜叙事表达规范

### 7.1 叙述视角与距离 `[A]`

- 主视角：**第三人称限知**，紧贴主角
- 允许**临时切换**到配角视角，用于制造信息差（原作第88章用博克视角开场、第471章整章切马伏里奥）——但每章**最多切一次**，且切换后不切回
- 主角不在场的章节，只用于"读者需要知道但主角不该知道"的信息

### 7.2 对话配比 `[A]`

统计观察（44 章粗估）：
- 对话占篇幅 40%–55%
- 教学/社交场景对话可达 65%
- 研究/战斗场景对话降到 25%

**规则**：一段连续对话**不超过 6 轮**，第 6 轮后必须插入动作、心理或环境。

### 7.3 禁忌写法（原作几乎不用，OpenWrite 必须避免）`[A]`

| 禁忌 | 替代写法 |
|---|---|
| 连续多行"某某说" | 用动作引出说话人（`特维尔打了个响指，水珠就挡在两人中间`） |
| 直接命名情绪（他感到愤怒） | 写身体反应（`指节掐进掌心`）或动作变形（`魔杖尖端抖了一下`） |
| 问答列表式对话 | 让一方**答非所问**，或插一句无关的抱怨 |
| 段落开头用副词（忽然、顿时、立刻） | 直接写动作，让节奏本身表达突然 |
| 心理描写整段独立 | 心理嵌在动作里（`他一边把巨怪"吹"出去，一边把赫敏拉了起来`） |
| "虽然……但是……"式解释 | 删掉转折连词，让转折发生在情节里 |

### 7.4 段落长度 `[A]`

- 平均段长 **1–3 句**
- 对话段可为 1 句
- 战斗/紧张段：**每段不超过 2 句**
- 抒情/回忆段：可到 5 句，但全章不超过 2 处

### 7.5 幽默的三种来源 `[A]`

1. **错位注意力**（主角在批卷，学生被吊着）——占比最高
2. **人物自我矛盾**（洛哈特一边怕一边自我吹捧）
3. **制度性反差**（宣布加测验，学生笑容消失）

**禁止**：靠网络流行语、谐音梗、作者吐槽制造笑点。

## 第 8 章｜分场景类型写作方法

### 8.1 开篇章（第 1–3 章）

```
节拍：
1. 一句冲突性对话开场（两方价值观对立）      ——不解释谁是谁
2. 交代主角的"低配身份"+ 旁人质疑            ——身份错位
3. 主角用一个小动作侧漏实力                  ——不解释
4. 收到一封信/一个任务                      ——外部推力
5. 结尾：一个未解答的"为什么"                ——钩子
```
**字数**：2500–3000。**禁止**：世界观介绍、家族史、金手指说明（留到第2章）。

### 8.2 教学/职场场景

```
节拍：
1. 学生/同事的情绪预期（期待或恐惧）
2. 主角到场，做一件与教学无关的琐事
3. 对抗/演示开始，主角注意力仍在琐事上
4. 意外：学生出丑/规则被钻空子/对手加码
5. 主角给出一句"教学理念"（藏在点评里，不直说）
6. 制度变化（加测验/改规则/发作业）
7. 情绪反转收尾
```

### 8.3 社交/宴席场景

```
节拍：
1. 无关话题暖场（饭菜、天气、旧事）
2. 一句试探性提问（对方最想问的那个）
3. 主角给半真半假的回答
4. 另一人插入，把话题推向理念层面
5. 关键台词 + 餐具动作（放刀叉/酒杯落地）
6. 有人离席或被噎住
7. 余味：一个眼神/一句没说完的话
```

### 8.4 冲突/战斗场景

```
节拍：
1. 确定本章只展示一个"新能力"
2. 前 30% 用旧招式试探
3. 对方出新手段，主角被压
4. 主角用新能力破解（过程写"怎么破"，不写"多强"）
5. 旁观者解说（承担讲解功能）
6. 收尾用旁观者反应，不用主角自评
```

### 8.5 揭示/反转章

```
节拍：
1. 用一个看似无关的日常开场（降低警惕）
2. 中途插入一个"不对劲"的细节
3. 主角或配角说出真相
4. 听者的反应（不信→回想→接受）
5. 真相的**目的**仍不揭晓
6. 留下新的疑问
```

### 8.6 收尾章

```
节拍：
1. 时间跳跃标记（"十九年后"类）
2. 一个微不足道的当下场景（看电影、吃爆米花）
3. 通过闲聊回顾众人的去向（每人一句，不展开）
4. 主角的一个小抱怨（保持人物本色）
5. 主角拒绝被神化（"我的愿望已经实现了"）
6. 结束在具体动作上，不结束在抒情上
```

## 第 9 章｜章节生成模板（OpenWrite 直接用）

写之前先填这张表，填不出就不许开始写正文：

```yaml
章号: 
本章功能: [主线推进 / 关系变化 / 制度演进 / 日常锚点 / 实力外显 / 揭示]
体验层级: [L1 安全感 / L2 智力快感 / L3 日常依恋 / L4 主题共鸣]  # 至少选2
场景类型: [教学 / 社交 / 独处 / 冲突 / 揭示]
出场人物及各自诉求:
  - 人物A: 想要____ / 会阻碍____
  - 人物B: 想要____ / 会阻碍____
主角的"错位注意力": 
三件事:
  - 本职动作: 
  - 观赏动作: 
  - 埋线动作: 
本章揭示的信息:          # 不超过1条
本章不揭示的信息:        # 至少1条
结尾的"未解决事项": 
下一章会不会处理: [是/否]
```

**字数**：2200–3200
**对话占比**：40%–55%
**段落均长**：1–3 句

## 第 10 章｜质量控制标准

### 10.1 硬性指标（不达标即重写）

| 指标 | 标准 |
|---|---|
| 首句 | 必须是动作或对话，无背景交代 |
| 对话连续轮次 | ≤ 6 轮 |
| 直接命名情绪 | ≤ 1 处/千字 |
| "忽然/顿时/立刻" | ≤ 2 处/章 |
| 情绪反转 | 必须有 1 处（日常章）|
| 未解决事项 | 必须有 1 个 |
| 体验层级 | ≥ 2 层 |

### 10.2 软性判断（需人工确认）

- 删掉本章，后续剧情会不会缺块？（不会 → 本章可删）
- 主角的注意力是否真的不在冲突上？（在 → 缺少错位感）
- 配角是否做出了**自己的**选择？（没有 → 工具人化）
- 是否存在"作者替读者总结"的段落？（有 → 删）

## 第 12 章｜适用范围与限制（必读）

### 12.1 本手册适合

- 长篇（100 章以上）哈利波特同人
- 原创主角进入霍格沃茨任教的设定
- 需要"日常+主线"双轨推进的叙事
- 目标读者：喜欢群像、轻松幽默、带一点权谋的男频读者

### 12.2 本手册不适合

- 短篇（<20 章）：本手册的节奏依赖长线伏笔，短篇会失效
- 高虐/悲剧向：原作全程"主角几乎不受伤"，与本手册的 L1 安全感绑定
- 纯战斗流：本手册的战斗写法是"教学式"，不适合连续高强度战斗
- 女主文/感情线为主：原作明确无女主，感情戏样本为零
