# 章节写作检查清单 V1.2

> **V1.1 的核心变化**：只有**硬性逻辑约束**能阻断交付。文学质量只给建议，风格选择只做记录。
> **不评分。** 评分会诱导"及格就好"，而且无法定位问题。
>
> **V1.2 的定点修订**：
> ① 修复结论判定歧义——三种结论改为**互斥优先级**（见"使用流程"与"结论判定"）
> ② 新增 A7「章节内容与已确认剧情目标冲突」
> ③ A 类增加"待作者确认"这一中间状态，不确定时不得判不通过
> ④ 新增「使用边界」与「修改建议的处理方式」两节
> ⑤ C 类明确写死：风格选择不影响合格判定
> ⑥ B1 生活感措辞放宽，不再暗示"缺失态就是问题"
>
> **使用原则**：这份清单是**事后诊断工具**，不是写作时的约束清单。
> 如果写的时候一直在想着"不能违反第几条"，写出来的东西会是僵的。

---

## 使用流程

```
第 1 步  A 类逐项检查 —— 只回答"是 / 否 / 待确认"，不解释
          └─ 任一项＝"是"        → 结论＝「需修正」，定位并给修改动作，流程结束
          └─ 全部＝"否"或"待确认" → 进入第 2 步

第 2 步  B 类通读建议 —— 逐项判断，可采纳可不采纳
          └─ 统计"值得改但未采纳"的项数

第 3 步  C 类记录 —— 只填数值/类型，不判断好坏

第 4 步  按优先级输出唯一结论（三种结论互斥，见"结论判定"）
```

## 结论判定（V1.2 核心修订）

按**从上到下**的顺序判定，命中一条即停止，不再往下判断：

| 优先级 | 结论 | 触发条件 | 是否可以交付 |
|---|---|---|---|
| 第 1 优先 | **需修正** | A 类存在任一项＝"是" | 否，改完重检 |
| 第 2 优先 | **建议优化** | A 类全部通过（"否"或"待确认"），且 B 类有 ≥3 项值得改但未采纳 | **是**。修改与否由作者决定，不强制 |
| 第 3 优先 | **可交付** | A 类全部通过，且 B 类未达上述条件 | 是 |

**三条必须记住的规则**：

1. **三种结论互斥**：一次检查只能输出一个结论，不存在"A 全过所以可交付，同时 B 又不达标"这种并列情况。
2. **"建议优化"等于可以交付**，只代表"如果你愿意，这几处还能更好"。它不代表要重写整章。
3. **C 类不参与判定**。风格选择没有对错，不能因为没采用某种风格或技巧就判章节不合格。

> V1.1 的原文是"A 类全部通过 → 可交付；A 类全过且 B 类 ≥3 项未采纳 → 建议优化"，两条可以同时成立，导致结论不明确。V1.2 改为有序判定。

# A 类｜硬性逻辑约束（唯一阻断项）

> **判定标准**：这七项属于"读者会发现故事讲不通、或前后自相矛盾"的范畴。
> 它们不是审美问题，是**错误**。只有这七项能阻断交付。

### A0 前置规则：不确定时不要判"不通过"

A 类每一项只有三种判定结果：

| 判定 | 含义 | 后果 |
|---|---|---|
| **是** | 能指出具体的冲突依据，且能说清冲突在哪 | 判「需修正」 |
| **否** | 找不到冲突 | 通过 |
| **待确认** | 有疑点，但无法确定是否构成错误（可能是作者有意为之，或缺上下文） | **通过**，但在「保留意见」中写明疑点 |

**"待确认"不是偷懒的挡箭牌，也不是不通过。** 它的用途是：把判断权交回作者，而不是由检查者替作者定案。

### A1 世界观/规则冲突

**检查**：本章是否出现了与已建立设定矛盾的魔法规则、能力上限、组织制度、地理设定？

**判定方法**：
1. 列出本章使用的每一条规则（魔法、制度、生物）
2. 逐条对照已有的规则清单
3. 若本章**扩展或突破**了规则，检查本章内是否给出了解释

**不算冲突的情况**：主角学会了新能力（只要本章或前文有学习过程）、规则被反讽性地打破并有人指出（如第2章"不违反点法律，还算是巫师吗"）。

**不通过时的处理**：改情节，或补一句规则解释。**不要改已建立的设定。**

---

### A2 人物行为与已建立动机严重不一致

**检查**：本章是否有重要角色做出了与其性格/动机/立场**明显矛盾**的行为，且文中**没有任何交代**？

**判定方法**：
1. 列出本章每个角色的关键决定
2. 对每个决定问："他为什么这么做？"
3. 答案必须能在**本章或前文**找到依据
4. 找不到依据 → 不通过

**重要区分**：
- ✅ **允许**：角色做出让读者意外的行为，只要**有依据**（如第471章马伏里奥救人——前面已有"他不愿对孩子撒谎"的铺垫）
- ✅ **允许**：角色成长/转变，只要有**触发事件**
- ❌ **不允许**：反派突然变善良、谨慎的人突然鲁莽、忠诚的人突然背叛，且无交代

**不通过时的处理**：补一个触发事件，或把行为改回符合动机的版本。**不要用旁白强行解释。**

---

### A3 时间线错误

**检查**：本章的时间设定是否与前文矛盾？

**判定方法**：
1. 标出本章的时间点（季节、学年、距上一章多久）
2. 标出本章内的时间跨度
3. 对照主角年龄、学年、原著事件年份、已建立的倒计时/期限

**常见错误**：学期错位、季节错乱、角色年龄与学年不符、倒计时数字前后不一致。

**不通过时的处理**：改时间标记，不改事件。

---

### A4 因果断裂

**检查**：本章是否存在**无因之果**或**无果之因**？

分两项：

**A4-a 无因之果**：本章某个事件发生了，但读者看不出为什么会发生。
→ 处理：补一个前因（可以是一句伏笔、一个被忽略的细节）。

**A4-b 无果之因**：前文埋下的事件/承诺/威胁，在本章应当有进展却完全没提。
→ 处理：本章处理，或明确延后（"他打算明天再说"）。

**注意**：不是每个伏笔都要马上回收。**"明确延后"也算处理。** 完全不提才算断裂。

---

### A5 连续性错误

**检查**：人物状态、关系、持有物、所在地，是否与上一章衔接？

| 子项 | 检查内容 |
|---|---|
| A5-a 关系状态 | 上一章刚吵完架，本章是否还在吵架状态？（或已交代和好） |
| A5-b 人物状态 | 受伤、疲惫、被通缉、失势等状态是否延续 |
| A5-c 持有物 | 魔杖、道具、文件、钥匙等是否还在手上 |
| A5-d 所在地 | 位置移动是否有交代 |

**不通过时的处理**：补一句过渡，或调整本章开头。

---

### A6 事实性错误

**检查**：本章引用前文信息时，是否准确？

**包括**：角色姓名、称呼、过往事件的细节、已公布的规则、已死/在场的人物。

**不通过时的处理**：直接订正。

---

### A7 章节内容与已确认的剧情目标冲突（V1.2 新增）

**检查**：本章写出来的内容，是否与开写前已确定的本章目标／大纲冲突？

**判定方法**：
1. 找出本章开写前的目标（例如"主角第一次进课堂，学生不服"）
2. 对照本章实际写出来的内容
3. 若偏离，判断是**失控**还是**更好的选择**：
   - 更好的选择 → 判"否"，并把章目标更新掉
   - 失控（写丢了目标、写了不打算写的东西） → 判"是"

**不算冲突的情况**：写作过程中发现更好的发展方向并主动调整。**剧情目标不是合同，可以改。** 只有当偏离是"无意识的跑偏"，才算问题。

**不通过时的处理**：补回缺失的内容，或正式修改章目标。

```markdown
| 项 | 判定（是/否/待确认） | 定位 | 问题 | 修改动作 |
|---|---|---|---|---|
| A1 世界观冲突 | 否 | — | — | — |
| A2 人物动机 | 是 | 第14段，斯内普主动示好 | 前文三次交锋均敌对，无过渡 | 补一个触发事件，或改回冷淡回应 |
| A3 时间线 | 否 | — | — | — |
| A4 因果断裂 | 是 | 第22段"他突然有了钥匙" | 无来源 | 前一章补一句"他从博克那里拿的" |
| A5 连续性 | 否 | — | — | — |
| A6 事实错误 | 待确认 | 第31段称"麦格是副校长" | 与原著设定一致，本书未改过，但未复核 | 交作者确认 |

```

**判定为"是"的项数 ≥1 → 结论「需修正」。**
**判定为"待确认"的项不计入不通过，但必须写入「保留意见」。**

# B 类｜文学质量建议（不阻断）

> 这一类的每一项都**可以在有理由的情况下不采纳**。
> 输出时必须写清：采纳 / 不采纳 + 一句理由。
> **不允许只写"已检查"或打分。**

---

## B1 生活感：人物有没有犯小错

**观察**：本章是否有一处人物的轻微失态（说错话、衣着问题、吃相、被道具绊到、记错事）？

**建议**：日常章、社交章最好有。严肃章、告别章可以没有。

**原作样本**：德拉科拉链没拉（第96章）、主角给巨怪加泡泡挡臭并给自己加鼻泡（第44章）、凯瑟琳拿多味豆捉弄母亲（第554章）。

**如果没有，不需要刻意补。** 生活感也可以来自习惯、对话默契、环境痕迹。只有当你本来就想让这个人物显得更活一些时，才考虑加一处失手；失态要能说明性格，不能是纯搞笑。

---

## B2 错位注意力：主角是否在冲突中分心

**观察**：本章的冲突里，主角的注意力是否全在冲突本身上？

**建议**：如果主角实力远超场景需求，给他一件无关琐事，可以同时产生幽默、合理性和人物描边。

**不适合**：情感章、揭示章、高潮决战章（这些需要单一焦点）。

**原作样本**：第21章批卷、第105章挑试题毛病、第302章吃瓜。

---

## B3 三件事结构：日常场景是否需要多线并行

**观察**：本章如果零主线推进，是否只有一条线在跑？

**建议**：可以试试"本职动作 + 观赏动作 + 埋线动作"叠在同一场景（第21章模型）。

**但**：也可以只做一件事，**做透**。第607章（死后见前世自己）只做情感，依然是全书最好的章节之一。

---

## B4 收束方式：结尾有没有"结束之后的东西"

**观察**：读完最后一句，读者知道接下来该期待什么吗？

**五种可选方式**（任选，可叠加）：
- 悬念（第400章"有两个伏地魔"）
- 反转（第21章"以后每节课前都要测验"）
- 情绪余韵（第607章病床道谢）
- 人物决定（第283章"我要保护他们，和他们无关"）
- 信息揭示（第454章三次会面都是安排的）

**若缺失，建议**：加一个具体动作或一句话，指向尚未处理的事。

**不适用的情况**：本章是全书最后一章，或下一章切换视角/时间。

---

## B5 幽默：本章需不需要

**观察**：本章的情绪基调是什么？

**建议**：
- 日常章、社交章 → 建议有
- 战斗章、揭示章 → 可选
- 告别章、死亡章、决战章 → 通常不需要

**判断依据是人物**：如果一个角色本身不会开玩笑，不要让他开玩笑；让**别人**逗他，效果更好。

---

## B6 对话：是不是在交换新信息

**观察**：任取一段对话，问：这轮对话改变了什么？（认知、判断、关系、处境）

**判断方法**：
- 双方在**交换新信息** → 可以继续
- 双方在**改变彼此判断** → 可以继续
- 双方在**确认已经知道的事** → 可以停

**参考数值**（仅供事后对比，不作为截断线）：
| 指标 | 原作抽样参考 |
|---|---|
| 对话占比 | 40%–55%（教学/社交可达 65%，研究/战斗约 25%） |
| 平均段长 | 1–3 句 |
| 连续对话 | 常见 4–8 轮 |

**不要因为数到第 6 轮就插入风景。** 该断的地方是信息交换结束，不是轮数达标。

---

## B7 情绪表达：是否直接命名

**观察**：搜"愤怒""惊讶""尴尬""紧张""松了口气""心中一喜"。

**建议**：能换成身体反应就换（`指节掐进掌心` / `魔杖尖端抖了一下` / `把杯子放下的动作重了点`）。

**例外**：喜剧场景可以直接命名情绪，本身就是一个笑点（第105章"洛哈特的笑容顿时凝滞"）。

---

## B8 描写：是否写了不影响任何人的东西

**观察**：本章的环境描写，有没有哪一段删掉之后，读者完全不受影响？

**建议**：环境只写**妨碍或帮助行动**的部分（雨让人湿透、臭味熏得流泪、走廊太窄过不去）。

**原作样本**：第180章暴雨"冷入骨髓"是为了让摄魂怪的压抑感落地；第44章巨怪的臭味直接让一年级学生流泪——**臭味是攻击手段**。

---

## B9 主角是否被过度神化

**观察**：本章有没有"全员惊叹/佩服"的段落？主角有没有犯过任何错误？

**建议**：
- 质疑者保留一个（第10章布巴吉全程冷脸、第7章邓布利多不客气）
- 给主角一次腹诽、一次狼狈、一次判断失误

**说明**：原作在 44 章实读样本中**主角几乎无实质失败**，所以这一项**没有正面范例**，只作为提醒，不作为标准。

# C 类｜风格选择（只记录，不评判）

> 这一类的数据**没有对错**。记录下来，是为了让作者知道"我这一章是什么样子"，以及在跨章对比时发现自己无意中的惯性。
>
> **C 类不参与合格判定。** 不能因为没采用某种风格、某种视角、某种收束方式，就判定章节不合格或要求重写。

```markdown
## 第 X 章 风格记录

- 章节字数：
- 视角：第三人称限知 / 配角视角 / 混合
- 叙事距离：贴身 / 中距 / 远观
- 场景类型：教学 / 社交 / 独处 / 冲突 / 揭示 / 家庭
- 收束方式：悬念 / 反转 / 余韵 / 决定 / 揭示 / 无
- 对话占比：__%（粗估）
- 平均段长：__ 句
- 最长连续对话：__ 轮
- 幽默密度：无 / 轻 / 中 / 重
- 情绪强度：低 / 中 / 高
- 时间跨度：__（本章内）
```

**跨章对比建议**（每 10 章做一次）：
- 最近 10 章的收束方式是否重复？
- 对话占比是否一直在同一区间（可能说明节奏单一）？
- 是否连续 3 章以上同一场景类型？
- 时间跨度是否长期都是"一天内"（可能缺少跨度感）？

# 使用边界（V1.2 新增）

这份清单是**事后诊断工具**，不是正文生成模板。

1. **不要求在生成正文前逐项套用**。写的时候按故事走，写完再查
2. **不要求每章满足所有 B 类建议**。B 类是选项池，不是待办清单
3. **不要求每章采用相同的叙事结构**
4. **不要求为了通过检查而添加原本不存在的冲突、幽默、反转或人物行为**
5. 发现问题后，**先诊断原因，再决定改不改**。原因不明就动手，通常会把本来好的部分改坏
6. **不得因为某项 C 类风格未采用，就要求重写章节**

一句话原则：**不能为了让检查清单通过，而让小说本身变得更机械。**

# 修改建议的处理方式（V1.2 新增）

发现问题时，先分清它属于哪一类。不同类别有不同的**举证要求**：

| 类别 | 举证要求 | 处理方式 |
|---|---|---|
| **事实错误** | 必须指出具体冲突依据：哪一章、哪一句、按哪条设定它错了 | 直接改。拿不出依据，不得判为事实错误 |
| **逻辑问题** | 必须说明前因后果在哪一环断了 | 补缺失环节，或改情节 |
| **文学质量问题** | 说明阅读体验受到什么影响（读起来卡在哪、哪里像说明文、哪里人物像工具） | 提建议，作者决定 |
| **风格差异** | 无需举证 | **只记录，不要求修改** |

**如果无法确定某项属于"错误"还是"选择"，不要判不通过。** 标注「待作者确认」，写清疑点即可。

# 输出格式（强制）

```markdown
## 第 X 章检查结果

### 结论（三选一，互斥）
**需修正 / 建议优化 / 可交付**

判定顺序，命中即停：
1. A 类有任一项＝"是" → **需修正**
2. 否则，B 类有 ≥3 项值得改但未采纳 → **建议优化**（仍可交付，是否改由作者决定）
3. 否则 → **可交付**

C 类不参与判定。

### A 类（硬性逻辑）
```

# 关于"不评分"的说明

V1.0 曾设"阻断项通过率 100%、非阻断项 ≥80%"的标准。V1.1 取消百分比，原因：

1. 百分比会诱导为了达标而凑数
2. "文学质量 80% 合格"这个说法本身没有意义
3. 真正需要守住的是**逻辑不自相矛盾**，其余交给作者的判断

**唯一保留的量化**：A 类 7 项，不得有任一项判为"是"。
