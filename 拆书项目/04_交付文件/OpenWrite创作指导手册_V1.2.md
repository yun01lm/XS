## 第 0 章｜先读这一章：怎么用这本手册

### 0.1 三类处理方式

| 类型 | 标识 | 处理方式 |
|---|---|---|
| **要求** | 「要求」 | 少数、不可违背。全书只有 4 条，见 0.4 |
| **建议** | 「建议」 | 默认做法，但你判断不适合本章时可以不用，用了要能说出理由 |
| **参考** | 「参考」 | 只用于事后对比，不作为写作时的约束条件 |

### 0.2 内容的四种性质

V1.2 起，每条方法都归入以下四种性质之一。**性质决定怎么用，等级决定有多可信，两者不要混用。**

| 性质 | 含义 | 怎么用 |
|---|---|---|
| **已验证规律** | 在多个独立场景中被观察到，且实际现象与描述一致 | 可作创作参考，但仍需结合本章情境判断 |
| **局部观察** | 只在部分章节或特定情境下成立 | 不推广为普遍规则。用前先问"我的情境是否与之相同" |
| **创作建议** | 可选方法，无对错 | 按本章目标自由选择 |
| **待验证假设** | 证据不足，或样本中根本没有正面案例 | **不得作为稳定依据**，只能当作提问方向 |

标注方式：条目后加〔规律〕〔局部〕〔建议〕〔假设〕。
本章以下各条已尽量标注；未标注的是叙述性说明，不构成创作规则。

### 0.3 遇到冲突时，优先考虑以下问题

不要先查手册，先问自己四个问题：

1. **这一章，读者合上页面时会记住什么？**（一个画面？一句话？一个人？）
2. **这一章里，谁想要什么，谁拦着？**
3. **这一章结束后，什么东西变了？**（关系、认知、处境、规则，至少变一个）
4. **如果删掉这一章，后面的哪一章会塌？**

四个问题里，第 3、4 题答不上来，说明本章没有存在价值——这比任何格式规则都重要。

### 0.4 全书仅有的 4 条要求

1. **人物不能做出与其已建立动机相冲突、且没有交代原因的行为。**
2. **不能违反已建立的魔法规则与世界设定；若要扩展规则，必须在本章内给出解释。**
3. **时间线、地点、人物状态必须与前文一致。**
4. **一个事件的后果，必须在后续被处理（哪怕只是被提及）。**

除此之外，本手册其余内容都是建议或参考。

> **V1.2 删除的第五条**：V1.1 曾把"不能出现作者替读者总结人物心理的成段文字"列为要求。该条过于绝对，已删除，改为 7.3 节的心理描写使用原则。删除理由：心理描写本身不是错误，只有**重复解释已经表达过的东西**才是问题。

### 0.5 这本手册是什么

它是帮你理解"怎么写可能更好"的材料，不是必须逐条执行的格式规范。

- 创作方法是工具，不是任务
- 不同章节可以有不同的节奏和表现方式
- 不是每章都要有幽默、反转、冲突、伏笔或人物成长
- 不是所有场景都必须同时承担多个功能
- 人物可以有不同的表达习惯和情绪表现方式
- 文学效果服务于故事，而不是故事服务于检查指标

这段话只在开头出现一次，后续各章不再重复免责声明。

## 第 1 章｜体验目标：这本小说靠什么留住读者

### 1.1 四层体验（作为设计取向，不是考核指标）

| 层 | 体验 | 怎么产生 | 证据 |
|---|---|---|---|
| **L1 安全感** | 主角不会真的崩盘 | 实力/信息优势，读者可以放松地看 | [A] 第127/151/537章 |
| **L2 智力快感** | "原来这是早就安排好的" | 布局在中后期被重新解释 | [A] 第454/537章 |
| **L3 日常依恋** | 想再看他们上一节课、吃一顿饭 | 群像互动中的小失误、小默契 | [A] 第21/44/302/633章 |
| **L4 主题共鸣** | "这话说得对" | 理念冲突发生在具体的人身上 | [A] 第231/283/367章 |

**建议**：写每一章时，心里明确"这一章主要给读者哪一层"，**一层也可以**。
**不建议**：为了凑层数，在紧张章节里硬插日常。

> V1.0 曾要求"每章至少两层"，这条已取消。实际观察：原作第400章（墓地复活）几乎纯 L1+L2，没有任何日常成分，仍是全书最好的章节之一。[A]

### 1.2 这本书真正稀缺的东西：生活感

（V1.1 新增，V1.2 修订）原作最有辨识度的不是爽点，是**人物在做事时会留下的小痕迹**。以下全部是实读到的细节：

| 细节 | 章节 | 作用 |
|---|---|---|
| 德拉科紧张到裤子拉链没拉好，被母亲当场指出 | 第96章 | 一个动作写完"他有多重视这次会面" |
| 特维尔被巨怪熏得给自己加了个鼻泡，才继续讲课 | 第44章 | 强者的狼狈，比强者的从容更可爱 |
| 马尔福把防护徽章别在胸口（因为好看），被要求改别腰腹 | 第44章 | 虚荣心+服从，两笔写完 |
| 凯瑟琳拿多味豆捉弄母亲，母亲吃到"鼻屎味" | 第554章 | 日常喜剧，与主线无关但让世界活了 |
| 罗恩说"也就只有教授才这么清闲" | 第643章 | 学生长大后的平等调侃，关系变化的证据 |
| 学生被吊在天花板还嘴硬"我只是自己摔倒的啊喂" | 第21章 | 惨状中的自尊心 |

**〔建议〕生活感可以有多个来源，轻微失态只是其中之一**

1. **习惯**：某人每次坐同一个位置、每次都点同一样东西、进门先看一眼窗户
2. **互动**：不用说完就懂的默契、只有他们两人听得懂的称呼、一个眼神就换了话题
3. **环境反馈**：房间因为谁常来而发生变化、桌角被磨亮、某个抽屉总是坏的
4. **琐事**：找东西、算账、抱怨天气、修一个修不好的东西
5. **细微变化**：口头禅变了、开始提前到、不再吃某样东西

**关于"人物的轻微失态"**：
- 它是一个可选选项，**不设频率要求**，不需要按固定章节数安排
- 是否使用，由人物性格、情境、章节目标决定
- 不要为了体现生活感，给人物添加不符合性格的行为——一个极度自持的人不会当众出丑
- 如果要用，最好发生在**他在意的事情**上，这样失态本身在说话（第44章：主角在意的是课堂效率，所以他的狼狈是"给自己加个鼻泡，继续讲课"）
- 强者的失态宜限定在**无关实力的领域**（口味、洁癖、衣着、记性）

**明确一点**：生活感不是搞笑，也不是定期让人物出丑。它是"这个世界在人物不在场的时候也在运转"的感觉。

## 第 2 章｜结构

### 2.1 卷级结构（参考，非模板）

原作 8 卷的节奏大致是：

```
卷首：回到熟悉场景 + 一件反常小事
上升：制度逐步加码 + 主线线索零散出现
中段：一条支线突然加重
转折：原著主线事件被改写
高潮：一次性实力外显 + 关系大转折
收尾：制度/关系定型 + 抛下一卷的钩子
```

**建议**：每卷有一个**能被一句话说出的变化**（"这一卷他当上了正式教授"）。
**参考**：原作每卷都会引入一项**新制度**（加测验、建角斗场、开俱乐部、设联合办公室）。这是它推进节奏的隐性引擎，但不是唯一解。

### 2.2 章级结构（可选模板）

以下是最常见的内部走向，**不是必须**：

| 位置 | 占比 | 常见内容 |
|---|---|---|
| 开头 | 10–20% | 直接进场景 / 或一个反常细节 |
| 主体 | 40–60% | 场景推进，人物各有诉求 |
| 变奏 | 15–25% | 意外出现（人说错话、规则被钻空子、信息反转） |
| 收束 | 10–20% | 留下某种"结束之后的东西" |

### 2.3 结尾要"具有结束价值"，而不是"必须有反转"

> V1.0 曾要求"每章必须有情绪反转"，已取消。反转只是五种收束方式之一。

**五种收束方式，任选其一（也可以叠加）**：

| 方式 | 是什么 | 举例 |
|---|---|---|
| **悬念** | 抛出一个未解答的问题 | 第400章末："有两个伏地魔？！" |
| **反转** | 用一句话打翻前面的情绪 | 第21章：学生欢呼→"以后每节课前都要测验" |
| **情绪余韵** | 不推进，停在一个画面或感觉上 | 第607章：前世自己在病床上道谢 |
| **人物决定** | 角色做出一个明确的选择 | 第283章："我要保护他们，和他们无关！" |
| **信息揭示** | 给读者一块新拼图 | 第454章：三次会面都是安排的 |

**判断标准（唯一一条）**：读完最后一句，读者是否知道"接下来该期待什么"——哪怕这个期待只是"我想再看看他们上课"。

**提醒**：连续多章使用同一种收束（尤其连续用反转），读者会预判，效果衰减。原作在紧张章节多用悬念、日常章节多用反转、情感章节多用余韵。[A]

## 第 3 章｜剧情设计

### 3.1 主线要"挂在主角自己的问题上"

原作主线（推翻保密法）从主角的**私人续命需求**起步，中期才升维成理想。

**建议**：
- 主角的初始动机应当是具体的、有时限的、做不到会有明确损失的
- 动机升级最好由**一次亲眼所见的伤害**触发（原作第283章：看到麻瓜尸骨后自我反思）
- 升级之后，主角仍应保留那个最初的、自私的动机（他不是圣人）

**不必强求**：不是每个故事都需要"从自私到崇高"的弧线。如果你的主角一开始就是理想主义者，就要给他**理想与现实的具体摩擦**，效果等同。

### 3.2 支线从一个人开始

**建议**：任何涉及群体/制度的支线，第一次出场都通过**一个具体的人的一件具体的事**。

- ❌ `最近魔法界对狼人的政策越来越严苛，引发了广泛不满。`
- ✅ `卢平把袖子往下拉了拉，遮住手腕上的登记烙印。`

### 3.3 胜利是否过于轻易——检查，而不是加代价

> V1.0 曾要求"每次胜利必须付出代价"，已改为检查项。

**判断问题**（答"是"就要处理，答"否"就不用改）：

1. 读者在开打前就知道结果了吗？如果是，**这一场的看点是过程还是结果**？如果两者都不是，就删掉它。
2. 主角赢完之后，有没有任何**新的不便**？（暴露了实力、欠了人情、被更高层注意、消耗了资源、伤了关系）
3. 对手有没有做出**符合其智力的**应对？如果对手明显变笨，问题不在主角太强，在对手被写坏了。
4. 这场胜利是否**改变了某个关系的性质**？

**说明**：原作并非每场都付代价。第127章与斯内普的决斗、第537章与胡夫的交锋，主角都没有损失，但都改变了关系性质（斯内普承认实力、胡夫被逼入死角）。**关系变化可以替代代价。** [A]

### 3.4 伏笔：埋设与回收要成对出现

> 证据复审：本作我实际读到的**回收样本为 0**，只有埋设没有回收（见附录 B）。因此本条降为**建议**，不标等级。

**建议**：
- 每个长线伏笔配一个低成本载体（一句话、一个动作、一个数字）
- 首次出现要显得无关紧要，最好被更重要的信息盖过去
- 回收时不要写"你还记得吗"，直接让它生效
- 埋了又不收，读者会记着——如果他记得，说明这个伏笔在起作用；如果他不记得，那这个伏笔本来也没必要埋

**判断问题**：这个伏笔我打算在第几章回收？答得出来就埋；答不出来，可以只当氛围细节写着，不给它"伏笔"的身份。

### 3.5 布局：可以分层揭示，但要留一个不揭的

原作第454章的做法：把读者一直当"自然发生"的三次会面，重新解释为主角安排——但**安排的目的**未揭。

**建议**：布局揭示分三层（表层事件 → 这是安排的 → 为什么这么安排），最后一层留到很后面，甚至永远不揭（只留暗示）。

**注意**：揭示本身是消耗读者信任的动作。全书揭示次数不宜过多，且每次揭示后要立刻抛出一个新疑问，否则读者会觉得"作者在耍我"。

## 第 4 章｜人物

### 4.1 动机的表达方式，由性格和情境决定

> V1.0 曾要求"主角必须隐藏真实欲望"，已取消。有些主角就该直说。

**先判断你的主角属于哪一类**：

| 类型 | 表达方式 | 适用 |
|---|---|---|
| **谋算型** | 只让**别人**替他说出野心，他自己给半真半假的答案 | 权谋、幕后流 |
| **直率型** | 当面说出目标，冲突来自"别人不信"或"别人不让" | 热血、成长流 |
| **回避型** | 被问到就转移话题、开玩笑、装傻 | 喜剧、日常流 |
| **不自知型** | 说的和做的相反，由旁人点破 | 群像、成长流 |

**原作主角是谋算型**，所以四次被追问（第1/7/96/151章）给了四个版本的答案。**这是角色的选择，不是普遍规律。**

**如果你的主角是直率型**，正确的写法是：他说出目标，然后**没有人当回事**，直到他做出来。张力来自"不被相信"，而不是"藏起来"。

### 4.2 反派需要一个"尊严时刻"

原作第620章：伏地魔在败局已定时让手下投降，并说"當然是讓所有人永遠地銘記，我，伏地魔，始終都是為這個世界帶來恐懼與災厄的黑魔王！"

**建议**：反派在最终失败前，有一次**不计得失的选择**，且符合他的自我认知。
**避免**：临死前突然求饶或忏悔——会毁掉前面所有铺垫。

**这条也适用于"非最终反派"**：中层反派退场时，给他一个体现专业能力或原则的瞬间，比让他跪地求饶更有分量。

### 4.3 配角要有自己的事

**建议**：给每个重要配角一个**与主角目标不一致的私人诉求**，并让这个诉求在某个节点**给主角制造麻烦**。

**判断问题**：删掉主角，这个配角今天会去做什么？答得出来，他就活了。

**参考**：原作配角的诉求类型——活命（小矮星彼得）、功劳与自我证明（马伏里奥）、面子（马尔福一家）、清静（主角父母）。[A]

### 4.4 语言辨识度：一人一个"说话方式"

**建议**：为每个常驻角色确定一种说话方式，并保持一致。

**可用的方式（结构，不是原文）**：

| 类型 | 特征 | 注意 |
|---|---|---|
| 结巴 | 断句、省略、重复词 | 只给一个角色用，用多了变成滑稽 |
| 阴阳 | 反问、称呼全名、不直接骂 | 每句都在下判断，但不下结论 |
| 跳脱 | 说到一半换词、自我纠正 | 体现思维速度，不体现愚蠢 |
| 油滑 | 长句、自我吹捧、偷换话题 | 关键时刻会突然诚实一下 |
| 市井 | 短句、算计、反复确认风险 | 每句话都在评估得失 |

**避免**：所有角色说话都"完整、礼貌、有逻辑"。真实对话里有打断、答非所问、说半句。

## 第 5 章｜人物关系

### 5.1 关系靠共同经历推进

**建议**：任何关系升级都绑定一个**具体事件**，事件中双方必须有**分工**。
**参考**：原作主角与所有学生的关系推进点都是事件（一节课、一场比赛、一次禁闭、一次救援），几乎没有"谈心"。[A]

### 5.2 原著人物对主角的态度要分阶段

以斯内普为例（第10→127→524章）：

```
阶段1 冷眼警告：我盯着你
阶段2 主动试探：打一场看看
阶段3 承认并依赖：这件事你怎么看
```

**建议**：为主要原著人物写一张"态度解锁表"，标明触发事件。
**关键**：升级不能只发生一次。一次证明换来的应当是"有限的尊重"，不是友谊。

### 5.3 关系变好，可以靠共享的麻烦 〔建议〕

**建议**：想写两个人关系变好，可以考虑给他们一个**共同要瞒着别人的秘密**，或一次**必须互相掩护的善后**。

共同秘密的好处是它会持续产生张力——每次见面都得提防漏嘴。但这只是一种可选做法；一起吃很多次饭、一起过很多个普通的下午，同样能写出亲近感，只是更慢。

## 第 6 章｜场景

### 6.1 场景类型：一个关于"新鲜感"的提醒 〔局部〕

原作抽样中大致存在三类反复出现的场景：

| 类型 | 功能 | 在 44 章样本中的出现频率（**观察值，非要求**） |
|---|---|---|
| 教学/职场 | 展示能力 + 推进制度 | 约每 5–8 章出现一次 |
| 社交/宴席 | 承载理念冲突 + 关系变化 | 约每 8–10 章出现一次 |
| 独处/研究 | 推进主线 + 投放设定 | 约每 10–12 章出现一次 |

**这是对参考小说的观察结果，不是排期表。** 你的故事如果不需要教学场景，就不要写教学场景。为了"每隔 5–8 章来一次"而硬塞场景，比缺场景更糟。

**唯一值得留意的是**：如果连续很多章都是同一类场景，读者可能产生"怎么又是一样"的疲劳感。这只是一种**可能的**疲劳，不是错误——有些题材（探险、战争、密室、逃亡）本来就该连续同类型。

### 6.2 "三件事同时跑"是日常场景的一种设计方法，不是普遍要求

> V1.0 曾把它当成所有场景的标准，已收窄为**日常/教学场景的可选设计**。

原作第21章的示范：
- **本职动作**：主角在批卷（必须做、不想做）
- **观赏动作**：假人对抗赛（读者爱看）
- **埋线动作**：作业"如何围绕强者战斗"（挂到后续主线）

**这种方法适合**：需要同时完成"展示能力 + 制造趣味 + 埋线"且不想写三场戏的时候。

**不适合**：
- 情感章（情感需要单一焦点，分心会稀释）
- 悬疑揭示章（注意力必须集中）
- 战斗高潮章（读者要看打斗本身）

**替代方案**：如果不用三件事，也可以让一个场景只做一件事，但**做透**。原作第607章（死后见前世自己）只做了一件事——情感——依然是全书最好的章节之一。[A]

### 6.3 场景开场：推荐而不强制

> V1.0 曾要求"第一句必须是动作或对话"，已改为推荐。

**推荐**：以动作、对话、或一个反常细节开场。理由是读者进入场景最快。

原作 44 章中绝大多数如此，例如：
- 第44章：`"啪啪啪，"特维尔一边鼓掌一边踏进这间厕所`
- 第88章：`博克面无表情地感受着旁边房子传来的灵魂颤动`

**但以下情况，其他开场更好**：
- 需要**时间跨度**时：一句简短的时间标记 + 一个画面（第643章"七月，伦敦"）
- 需要**氛围压迫**时：先给环境，再给人（第180章暴雨与摄魂怪）
- 需要**陌生视角**时：先给一个读者不认识的人在做事（第471章的咖啡店）

**唯一要避免的**：用一段**解释性文字**开场（"自从……之后，……已经……"）。

### 6.4 场景结束：留一点没处理完的东西

**建议**：结尾存在一个**待处理的具体事项**。什么时候处理由你决定，但读者应当知道它还在。

原作例：第21章的测验制度、第537章"明天再验一次尸"、第400章"两个伏地魔"。

**注意**：不要每章都留钩子。连续十章"欲知后事"，读者会疲劳。有些章节可以干净地结束（第633章父母上门，收在主角的自我怀疑上，没有指向下一章）。

## 第 7 章｜叙事表达

### 7.1 视角

- 主视角：第三人称限知，贴近主角
- **允许**临时切到配角视角，用于制造信息差（原作第88章用邻居视角开场、第471章整章切配角）
- **建议**：一章内最多切一次，且切换后不切回

### 7.2 对话与段落：参考指标，不是截断线

> V1.0 曾给出"连续对话 ≤6 轮""段落 1–3 句""对话占比 40–55%"等硬指标，V1.1 全部降为**参考**。

**参考值**（用于事后对比，不用于写作时截断）：

| 指标 | 原作抽样参考值 |
|---|---|
| 对话占篇幅 | 40%–55%（教学/社交场景可到 65%，研究/战斗场景约 25%） |
| 平均段长 | 1–3 句 |
| 连续对话 | 常见 4–8 轮 |

**真正要关注的是"这段对话为什么还在继续"**：

- 如果双方在**交换新信息**，可以继续
- 如果双方在**改变彼此的判断**，可以继续
- 如果只是在**确认已经知道的事**，就该停了

**不要因为数到第 6 轮就强行插入风景描写**。该断的地方是"信息交换结束"，不是"轮数达标"。

### 7.3 描写

**〔建议〕环境**
- 只写**影响角色行动**的部分（雨让人湿透、臭味熏得流泪、走廊太窄过不去）
- 判断问题：删掉这段环境，读者会不会看不懂人物在干什么？不会 → 它可以删

**〔建议〕情绪**
- 能换成身体反应就换（`指节掐进掌心` 而非 `他感到愤怒`）
- 但不必把每一处情绪都身体化。情绪强度本身有差异：轻微的烦躁可以直接说，剧烈的震动才需要动作来承载

**〔建议〕心理描写：判断标准是"有没有新东西"**

心理描写不是缺陷。真正要避免的只有一件事：**在人物已经通过行为、对话、情境表达了某种心理之后，再用叙述重复解释一遍。**

| 应当保留 | 应当删掉 |
|---|---|
| 提供新信息（读者此前不知道的事） | 重复上一段动作已经说清的情绪 |
| 展现认知变化（他改变了看法） | 把读者已经看懂的反应再解说一遍 |
| 深化人物关系（他怎么看待另一个人） | 用旁白替读者下结论 |
| 形成叙事节奏（紧张后的静场、长段独白后的爆发） | 与当前场景无关的自我分析 |

**允许并鼓励的形式**：反思、回忆、内心独白、情绪分析、价值判断、对某人的评价。

原作的示范：第2章几乎是整章内心独白，用来交代金手指与死亡倒计时；第607章用大段告解式对话完成情感落点。这两章都没有因为"心理太多"而失效。[A]

**不要为了"只写动作"而强迫自己删掉必要的心理。** 动作不是万能的——有些东西只能想，不能做。

**判断问题（问两遍）**：
1. 这段心理，读者从前面已经知道了吗？知道 → 删
2. 删掉后读者会失去什么？什么都不失去 → 删；失去一层理解 → 留

### 7.4 幽默

> V1.0 曾要求"每章必须有幽默"，已取消。幽默应服从场景与人物。

**判断**：这一章的情绪基调是什么？悲剧章、告别章、决战章通常不需要幽默；日常章、社交章通常需要一点。

**原作幽默的三种来源**（可用，不必全用）：
1. **错位注意力**：主角在批卷，学生被吊着
2. **人物自我矛盾**：一边害怕一边吹嘘
3. **制度性反差**：宣布加测验，学生笑容消失

**避免**：网络流行语、谐音梗、作者跳出来吐槽。

### 7.5 副词与转折

**参考**：`忽然/顿时/猛地/瞬间` 这类副词用得越少，动作本身越有力。
**但不要机械删**。判断方法：删掉副词后，句子是否还有节奏？有 → 删。没有 → 保留，或换个动词。

## 第 8 章｜分场景类型的写法（可选模板）

> 以下全部是**可选模板**。你的场景如果不属于这些类型，或者有更好的走向，直接写，不用套。

### 8.1 开篇章

```
1. 一个正在发生的小冲突（两个人观点对立，读者还不知道他们是谁）
2. 交代主角的位置——最好低于他的实际能力
3. 一个不解释的小动作，露出实力的一角
4. 一个外部推力（信、任务、命令、意外）
5. 一个没有答案的问题
```
**参考**：原作第1章用"毕业日等一封信"作骨架，事件量极小。

### 8.2 教学/职场场景

```
1. 学生/同事的情绪预期（期待或恐惧）
2. 主角到场，注意力在别的地方
3. 演示/对抗开始
4. 意外：人说错话、规则被钻空子、有人不按常理
5. 主角给出一句理念（藏在点评里，不直说）
6. 制度或关系发生变化
7. 收束（五种方式任选）
```

### 8.3 社交/宴席场景

```
1. 无关话题暖场（饭菜、天气、旧事）
2. 一句试探性提问
3. 半真半假的回答
4. 第三人插入，把话题推向理念
5. 关键台词 + 一个手上动作（放餐具、洒酒、推盘子）
6. 有人离席、被噎住、或沉默
7. 余味：一个眼神、一句没说完的话
```

### 8.4 冲突/战斗场景

```
1. 确定这一场要让读者看到什么（一个新能力？一种新处境？还是关系变化？）
2. 前段用已知手段试探
3. 对方出新东西，主角被压
4. 破解过程写"怎么破"，不写"多强"
5. 旁观者承担讲解与震撼反应
6. 收尾用旁观者的状态，而非主角自评
```

**说明**：第 1 步的答案不一定是"新能力"。第127章的看点是"两个互相看不顺眼的人终于打起来了"，能力展示是附带的。

### 8.5 揭示/反转章

```
1. 用一个日常场景降低警惕
2. 中途插入一个"不对劲"的细节
3. 有人说出真相
4. 听者的反应：不信 → 回想 → 接受
5. 真相的目的仍不揭
6. 留下新的疑问
```

### 8.6 收尾章

```
1. 时间刻度（"十九年后"）+ 一个具体画面
2. 一件微不足道的当下小事（看电影、吃爆米花、等客人）
3. 通过闲聊交代众人去向（每人一两句，不展开）
4. 主角的一个小抱怨或小毛病（保持本色）
5. 拒绝被神化
6. 停在具体动作上，不停在抒情上
```

## 第 9 章｜写之前的思考提示（不是填空表）

> V1.0 的 YAML 填空表容易被机械填写，V1.1 改为**问题清单**。答不上来的问题，就是本章的隐患。

写之前，用几句白话回答：

1. 这一章发生的事，用一句话怎么说？
2. 谁在场？他们各自想干什么？谁挡着谁？
3. 主角的注意力在哪？为什么在那？
4. 这一章读者会记住哪一个画面或哪一句话？
5. 这一章结束时，什么变了？
6. 哪一章会因为这一章的存在而成立？
7. 这一章有没有一处"只有这个世界里才会出现"的细节？（习惯、琐事、默契、环境痕迹，都可以）
8. 结尾读者会期待什么？

**如果能顺畅回答前 6 个问题，直接开始写。**
如果第 3、4、5 题答不上来，先别写，把场景重想一遍。

## 第 10 章｜写完之后怎么判断好坏

### 10.1 三个层次，不要混在一起评判

| 层次 | 性质 | 处理 |
|---|---|---|
| **硬性逻辑** | 错了就是错了 | 必须改（详见检查清单 A 类） |
| **文学质量** | 有好有坏，无绝对标准 | 提出建议，作者决定 |
| **风格选择** | 不存在对错 | 只记录，不评判 |

### 10.2 四个真正重要的判断问题

1. **删掉这一章，后面会不会塌？**（不会 → 本章可删或需重写）
2. **人物的每个决定，能不能回溯到他的动机？**（不能 → 补交代）
3. **有没有哪一段在重复解释已经表达过的心理？**（有 → 删掉重复的那一段，不是删掉全部心理描写）
4. **这一章有没有一个"只有这本书里才会有"的细节？**（没有 → 补生活感）

### 10.3 不要用分数评价章节

分数会诱导"及格就好"。用**定位 + 具体修改动作**代替评分。

## 第 11 章｜常见问题与对策

| 问题 | 表现 | 对策 | 证据 |
|---|---|---|---|
| 解释性开场 | "自从……之后，……已经……" | 换成动作/对话/反常细节 | [A] |

# 附录 B｜方法卡与章节证据对应表（V1.2 复核版）

> 复审标准：**A = ≥3 个独立场景**；B = 1–2 个独立场景；C = 无验证。

### B.0 判定"独立"要看四个维度

不能因为三个章节出现了相似关键词，就认定为三个独立场景。

| 维度 | 问题 | 为什么重要 |
|---|---|---|
| **独立章节数** | 证据分布在几个章节？ | 同一章内的多处相似只算一次 |
| **独立场景数** | 是否发生在不同时间、不同场合、不同对手之间？ | 同一场戏的上下半段不是两个场景 |
| **是否属同一剧情弧** | 是否服务于同一个连续事件？ | 同一弧内的重复只算一次。第1、2章的"降格任教"是一条弧，只能计一次 |
| **现象是否真被验证** | 该章实际写的，是否就是卡片描述的那个现象？ | 关键词相似 ≠ 同一方法。第400章出现打斗字样，但主体是复活仪式，不计入 MC-14 |
