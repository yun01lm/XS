# XS · 网络小说拆书研究档案

两部长篇哈利波特同人的**拆书研究产出**，目标是提炼可迁移、可执行、可验证的小说创作方法。

> 本仓库是研究分析，不是小说转载。**不收录正文原文**，只保留为论证所需的少量引文。
> 所有结论标注章节出处与证据等级；未读章节明确标为未读，**不以推测补齐**。

---

## 目录结构

```
XS/
├── 拆书项目/                  项目A · 教授主角
└── 拆书项目02_非典型巫师/      项目B · 学生主角
```

两个项目**立项独立、互不引用**：项目B 的研究结论未使用项目A 的任何观察、方法卡或章节证据，项目A 的文件在项目B 执行期间未打开、未修改。

| 正文来源 | 8novel（繁体）／58小说网（简体）／56书库·书书网（结局章） |

**产出**

| 文件 | 说明 |
|---|---|
| `04_交付文件/专题A_学生主角独立故事线与原著因果改写.md` | 五层模型：目标→行动→影响他人→影响因果→形成独立剧情 |

| `03_子代理报告/第三阶段独立复核报告.md` | 5 条结论复核，0 条完全成立 |
| `03_子代理报告/第四阶段独立复核报告.md` | 反例检索式复核，推翻 2 条新结论 |
| `04_交付文件/第三阶段研究成果纠错记录.md` | 22 项纠错，20 项经正文复核 |
| `04_交付文件/第四阶段待验证问题清单.md` | 17 条待验证判断 |
| `05_原始资料/章节ID映射表.md` | 镜像站 `?ID` 实为**目录位置序号**，非章号 |

**方法论要点**

- **三级证据**：A（多独立场景验证）／B（有限样本）／C（待验证假设）。同一次战役拆成多章不算多个独立证据。
- **三种状态分离**：章节 ID 已验证 ≠ 正文已读取 ≠ 正文完整性已核验。本项目只确认前两项。
- **独立复核**：每个阶段交独立 Agent 复核。复核员不看研究笔记，只读正文，且被要求**主动找反例**。
- 结论被推翻时保留原记录与修正痕迹，不覆盖历史日志。

## 已知限制（不隐藏）

1. **覆盖率低**：A 6.7%、B 12.6%。所有结论均为"已读样本内成立"，不作全书断言。
2. **正文非官方原文**：番茄网页端有字体反爬（正文缺字约 30–40%），正文只能取自第三方镜像。繁体转码、水印、OCR 错字均可能存在。
3. **完整性未与官方互校**：只能说"读过这一章"，不能说"读到的是完整官方原文"。
4. **样本空白**：A 缺"主角失败"与"伏笔回收"样本；B 缺 402–489 段（仅抽读 3 章）。
5. **一次复核覆盖不全**：B 的 24 条观察中，经独立复核的只有 9 条。

## 使用建议

- 手册与清单是**判断框架**，不是格式规范。里面每一条都标了性质：硬性逻辑约束／推荐方法／可选技巧／待验证假设。
- 不要为了通过检查清单而添加原本不存在的冲突、幽默或反转。**清单是事后诊断工具，不是生成模板。**
- 引用结论时请连同等证据等级与其适用章节范围一起引用，脱离范围单独使用会失真。
